## v0.15.0：刷流懂得让路，看片少受打扰

这一版让刷流只用剩余下载带宽，上行受压时及时退让。媒体库监听更轻，网络挂载可以关闭实时监控，手机网页也更顺手。

✅ 已使用 v0.10.0 对应镜像的用户无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 刷流会看带宽，不再一味往下拉

后台定期检查下载器速度，上行掉出健康区时给刷流种子限速，只调整刷流任务。也会逐步学习这台机器的安全下载速度，避开低收益、并发过多和免费窗口内下不完的资源。

#### 网络挂载不适合实时监听，可以按库关掉

编辑媒体库时，可以关闭「实时监控目录变化」。SMB、CIFS、NFS 收不到远端文件事件时，不必继续承担监听成本；新文件通过定期对账或手动扫描发现。

### 其他新功能与改进

- **目录变化后少扫一遍全库**：监听扫描只遍历变动区域，慢盘遍历放到后台，启动也更轻。
- **手机 PWA 更顺手**：长按按钮和导航不再误弹文字选区；正文、输入框和路径仍能复制。
- **活动任务更好读**：筛选按生命周期排列，刷流做种按上传速度排序，时间线减少无用留白。
- **站点设置更清楚**：桌面展开信息按列对齐，操作热区更大。
- **影片背景更自然**：进入详情页后整站换成剧照背景，加载完成再淡入。

### 修好了

- 修正数据库迁移编号冲突，升级不再因重复版本和分叉报错。

### 升级须知

- 关闭实时监控后，新文件不会即时出现，请等待定期对账或主动扫描。
- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.14.0 → v0.15.0](https://github.com/movieclaw/MovieClaw/compare/v0.14.0...v0.15.0)。
