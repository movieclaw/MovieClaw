## Apple TV 0.14.0: Browse a local actor's work with the remote

Cast cards in local and NFO libraries can now open every title by that actor in the same library, even when no online person page exists.

> ✅ Works with MovieClaw Server 0.28.0 or later, the same as 0.13.0. The new actor-filtered wall requires Server 0.48.0 or later. This GitHub release contains notes only and does not upload a TestFlight build.

### Highlights

#### Go from an actor to the matching poster wall

On an item detail page, focus an actor who has no online person page and press the remote. Apple TV opens that same library with **Actor: Name** in the wall summary; remove the actor from the sort and filter menu to return to all titles. Actors with an online person page still open that page, and directors without one remain static.

Installation requires a corresponding TestFlight build prepared separately from this GitHub release.

Thanks to @Migflyway. Full changes: [tvos-v0.13.0 → tvos-v0.14.0](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.13.0...tvos-v0.14.0).

## 简体中文

## Apple TV 0.14.0：用遥控器找到本地演员的同库作品

本地库和 NFO 库里的演员卡现在也能打开这位演员在同一媒体库中的全部作品，不再依赖在线影人页。

> ✅ 搭配 MovieClaw 服务器 0.28.0 或更新版本即可使用，与 0.13.0 相同。新的演员筛选海报墙需要服务器 0.48.0 或更新版本。这个 GitHub Release 只有说明，不会上传 TestFlight 构建。

### 本版亮点

#### 从演员直接进入对应海报墙

在条目详情页把焦点移到没有在线影人页的演员，再按遥控器。Apple TV 会打开同一媒体库，并在海报墙摘要中显示「演员：姓名」；从排序与筛选菜单移除演员即可回到整库。带在线影人页的演员仍进入影人页；没有影人页的导演仍不可点。

安装仍需要另行准备与此版本对应的 TestFlight 构建。

感谢 @Migflyway。完整改动：[tvos-v0.13.0 → tvos-v0.14.0](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.13.0...tvos-v0.14.0)。
