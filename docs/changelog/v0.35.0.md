## v0.35.0: Plugins, instant previews and long series made easy

MovieClaw now has a plugin system you can manage in one place, TV previews can start instantly, and long-running series open on the episode you're watching.

✅ No Docker image update is required. Administrators can update from **Settings → Update & Maintenance**.
The Apple apps stay at **0.7.0**. Update Android and Android TV to **0.2.0**.

### Highlights

#### Add what MovieClaw can't do yet, with plugins

Adding a messaging channel or another downloader used to mean waiting for a new release. Now WeChat, Telegram, Discord, Feishu, qBittorrent and Transmission ship as official plugins, and you can install third-party plugin packages next to them. Each plugin has a detail page listing what it adds, which permissions it asks for (rated by risk) and where its code lives; you can turn it off or roll it back. You can also ask the AI assistant to build and install a plugin for something MovieClaw is missing. Administrators can start at **Settings → Plugins**.

#### TV previews and Reels start right away

Large previews on the TV home and detail pages, and Reels, used to stall while the server prepared the original file. Turn on **Clip pre-cut** and the server prepares short 1080p clips in the background, pausing whenever someone is watching. Previews on Apple TV, iPhone and Android TV then start immediately, even away from home. Each title takes about 20 MB, and progress shows in the task center, picking up where it left off after a restart or update. Administrators can turn it on at **Settings → Playback → Clip pre-cut**; MovieClaw suggests it once you start using Reels.

#### Series with hundreds of episodes are easy to browse

Long seasons now split into 50-episode ranges, and every season opens on the range and episode you're up to, so you no longer scroll past hundreds of episodes. This applies automatically on the web, iPhone, Mac, Apple TV, Android and Android TV.

### More features and improvements

- **Subscriptions don't stop early**: When TMDB lists only part of a drama, subscriptions keep going; adjust the count in **Manage → Adjust episodes**.
- **Delete the download too**: Deleting from the library can also remove its download task and source files (off by default).
- **Better resource search**: Searching from a detail page also uses the English and original titles.
- **Android player and subscriptions**: iOS-style player controls with an episode picker and intro markers, plus a redesigned subscription page.
- **Mac player stays on top**: The player window floats above other windows while playing.
- **Netflix theme in brand red**: The main play button and the "In library" badge use the brand red.
- **Clearer search**: "Load more" disappears once every site has no more results; Adult is no longer a built-in search tab.

### Fixed

- Android TV now appears in third-party TV launchers, with a new app icon and banner.
- Android subscriptions without seasons, episode watched marks and resuming now work as expected.
- Android's library home refreshes after you delete, restore or purge files.
- The iPhone download dialog no longer says auto-import is unavailable the first time it opens.
- Poster cards no longer have their top corners clipped when they lift on hover.
- An AI assistant conversation can continue after a reply was cut off before any text arrived.

### Before you update

- This release migrates the database. To return to v0.34.0 or earlier, restore the automatic pre-update backup.
- Third-party plugins run on your server. Install them only from sources you trust.
- No Mac transcoder update is required for this release.

Thanks to @WadeChenn for the Android player and subscription work, @duchanghexuhe for the poster card and Netflix theme polish, and @anlan-home for the Android TV launcher fix.

Full changes: [v0.34.0 → v0.35.0](https://github.com/movieclaw/MovieClaw/compare/v0.34.0...v0.35.0).

## 简体中文

## v0.35.0：插件来了，预告秒开，长剧好找

MovieClaw 有了可以集中管理的插件系统；电视上的预告可以秒开；长剧打开就停在你看到的那一集。

✅ 本版无需更新 Docker 镜像，管理员在「设置 → 更新与维护」一键更新即可。
Apple App 保持 **0.7.0**；Android 与 Android TV 请更新到 **0.2.0**。

### 本版亮点

#### MovieClaw 还不会的，装个插件补上

以前想多接一个消息通道或下载器，只能等新版本。现在微信、Telegram、Discord、飞书、qBittorrent、Transmission 都是官方插件，你也可以在旁边装第三方插件包。
每个插件有详情页，写清它带来什么功能、要哪些权限（按风险分级）、代码放在哪；可以随时停用或回退。也可以让 AI 助手为缺的功能写一个插件并装好。
管理员从「设置 → 插件」开始。

#### 电视预告和刷片，点开就播

以前电视首页、详情页的大图预告和刷片，要等服务器处理原片才动起来。打开「片段预切」后，服务器在后台把精彩片段提前切成 1080p 小文件，有人看片时自动暂停。
之后 Apple TV、iPhone、Android TV 上的预告立刻起播，在外网也一样。每部约占 20 MB；进度在任务中心可见，重启或更新后接着切。
管理员在「设置 → 播放 → 片段预切」开启；开始刷片后 MovieClaw 也会提示你。

#### 几百集的剧，也能一下找到

长季现在按 50 集分段，每一季打开就落在你看到的那一段、那一集，不用再划过几百集。网页、iPhone、Mac、Apple TV、Android、Android TV 升级后自动生效。

### 其他新功能与改进

- **订阅不再提前结束**：TMDB 只收录部分剧集时继续追；可在「管理 → 调整集数」改集数。
- **删片时可连下载一起删**：从媒体库删除时可勾选同时删下载任务和源文件（默认不勾）。
- **找资源更准**：在详情页搜资源时，同时用英文名和原名搜索。
- **Android 播放器与订阅**：iOS 风格的播放控件，带选集和片头标记；订阅详情页重新设计。
- **Mac 播放器置顶**：播放时播放器窗口浮在其他窗口之上。
- **Netflix 主题换上品牌红**：主播放键和「已入库」斜标改用品牌红。
- **搜索更清楚**：所有站点都没有下一页时不再显示「加载更多」；「成人」不再是内置搜索分类。

### 修好了

- Android TV 现在能出现在第三方电视桌面里，并换上了新图标和横幅。
- Android 上没有分季的订阅、剧集已看标记和继续观看恢复正常。
- Android 删除、恢复或彻底清除文件后，片库首页会及时刷新。
- iPhone 下载弹窗第一次打开时，不再提示「自动识别暂不可用」。
- 海报卡悬停上浮时，顶部圆角不再被裁掉。
- AI 助手的回复在出字前被打断后，对话可以继续。

### 升级须知

- 本版升级了数据库。如需回退到 v0.34.0 或更早版本，请用更新前自动生成的备份恢复。
- 第三方插件运行在你的服务器上，请只安装可信来源的插件。
- 本版无需更新 Mac 转码器。
