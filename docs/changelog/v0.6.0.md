## v0.6.0: Connect viewing events, and browse large libraries faster

Send playback, favorite and subscription events to external services. Large libraries avoid repeated disk access, while search and conversations get easier to use.

✅ No Docker image update is required. Update from **Settings → Application**.

### Highlights

#### Let playback and imports trigger your automations

Add an endpoint in Settings → Webhook and choose playback, favorite or subscription events for notifications, viewing statistics or home-device automations. MovieClaw and Jellyfin-plugin-compatible formats are supported, with proxy selection, test delivery and recent delivery history.

#### Thousands of titles, without checking the disk over and over

Lists and covers use imported records where possible, reducing repeated access to media directories. Large libraries open faster in VidHub, especially on hard drives and network mounts.

### More features and improvements

- **Clean up missing records after a scan**: An optional library switch removes records for deleted files. It is off by default.
- **Edit and resend a question**: Use the pencil on your message to restart from that turn. Messages and code blocks also have copy buttons.
- **Clearer resource cards**: Text moves below the poster, with season and episode labels for packs and individual episodes.
- **11 more trackers**: hdsky, hdvideo, hhanclub, hdarea, hddolby, hdfans, hdtime, nicept, piggo, pttime and soulvoice.
- **Clearer import counts**: Show both title and file counts.

### Fixed

- The settings sidebar no longer turns white after connecting many trackers.
- Updating the image no longer leaves a false image-upgrade warning caused by an old application overlay.
- Unrelated libraries no longer block automatic routing with hard links in cross-disk setups.
- A failing Webhook endpoint no longer delays delivery to other endpoints.

### Before you update

- Detail pages no longer probe historical files while browsing. Run a manual library scan to fill in missing specifications.
- Editing and resending removes that turn and later conversation history. Automatic cleanup of missing records is also irreversible.
- This release migrates the database. Restore the automatic pre-update backup when rolling back across versions.

Thanks to the community for the new tracker support.

Full changes: [v0.5.0 → v0.6.0](https://github.com/movieclaw/MovieClaw/compare/v0.5.0...v0.6.0).

## 简体中文

## v0.6.0：看片动态能联动，大片库也好逛

这一版可以把播放、收藏、订阅事件接到外部服务。大库浏览减少了反复读盘，找片和聊天也更顺手了。

✅ 本版无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 开始看片、下载入库，都能触发你的自动化

在「设置 → Webhook」添加接收地址，选择要推送的播放、收藏或订阅事件，就能接入通知、观影统计和家庭设备联动。支持 MovieClaw 与 Jellyfin 插件兼容两种格式，可选代理、发送测试，并查看最近的投递记录。

#### 片库上千部，也不用等着硬盘一遍遍查

浏览列表和封面时优先使用入库记录，减少对媒体目录的重复访问。大库在 VidHub 里打开更快，机械盘和网络挂载尤其受益。

### 其他新功能与改进

- **磁盘删了片，记录可自动清**：媒体库新增扫描后清理丢失记录的开关，默认关闭，需自行开启。
- **提问可以改写重发**：点用户消息上的铅笔，从该轮重新对话；消息和代码块也能一键复制。
- **资源卡片更好读**：文字移到海报外，整季包与单集有了季集标签。
- **新增 11 个 PT 站点**：hdsky、hdvideo、hhanclub、hdarea、hddolby、hdfans、hdtime、nicept、piggo、pttime、soulvoice。
- **入库数量更明确**：同时显示作品数和文件数。

### 修好了

- 接入多个站点后，设置页侧栏不再变成整块白色。
- 更新镜像后，不再因遗留的旧应用版本误报「需升级镜像」。
- 跨盘布局下，自动路由与硬链接规则不再被无关媒体库误拦。
- 一个 Webhook 地址故障，不再拖慢其他地址的投递。

### 升级须知

- 详情页不再顺手补探历史文件规格；需要补齐时，请主动扫描一次媒体库。
- 改写重发会删除该轮及之后的对话；自动清理丢失记录也不可恢复，请按需使用。
- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

感谢社区带来新的站点支持。完整改动见 [v0.5.0 → v0.6.0](https://github.com/movieclaw/MovieClaw/compare/v0.5.0...v0.6.0)。
