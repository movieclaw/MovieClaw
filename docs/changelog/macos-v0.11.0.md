## Mac 0.11.0: Easier installation and updates

The Mac app adds English, an installation disk and in-app updates for the direct-download edition.

- The interface and menus now support Simplified Chinese and English. Server 0.43.0 adds matching server messages.
- The direct-download edition comes as a DMG with installation guidance. Move MovieClaw to Applications to use the new in-app update experience; this updater is for the direct-download edition.
- Improved fullscreen behavior while keeping playback on top, and the playback menu. Double-clicking the empty control area or title also enters fullscreen.
- Rule groups can exclude Dolby Vision Profile 5 with **DV P5**, with Server 0.43.0.

Full changes: [macos-v0.10.0 → macos-v0.11.0](https://github.com/movieclaw/MovieClaw/compare/macos-v0.10.0...macos-v0.11.0).

## 简体中文

## Mac 0.11.0：安装与更新更方便

Mac 版新增英语，官网直装版带来安装盘和应用内更新。

- 界面和菜单新增英语，支持简体中文与英语；服务器提示的对应语言需配合服务器 0.43.0。
- 官网直装版提供 DMG 安装盘和安装指引，移入「应用程序」后可使用新的应用内更新功能；此更新方式用于官网直装版。
- 改进「播放时置顶」下的全屏操作与播放菜单；双击控制面板空白处或片名也可进入全屏。
- 规则组新增「DV P5」选项，可排除杜比视界 Profile 5，需配合服务器 0.43.0。

完整改动：[macos-v0.10.0 → macos-v0.11.0](https://github.com/movieclaw/MovieClaw/compare/macos-v0.10.0...macos-v0.11.0)。
