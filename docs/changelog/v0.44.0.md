## v0.44.0: Subtitles from the soundtrack

When a file has no subtitles, MovieClaw can transcribe the dialogue on the server. The website also adds clips, and series get an air schedule.

> ⚠️ **A Docker image update is required.** Stop the container and back up the data directory before you pull the new image. Settings → Updates and maintenance will ask for the new image first and will not make the automatic backup. To return to 0.43.0, restore that backup and start the `v0.43.0` image.

### Highlights

#### No subtitles? Transcribe the audio track

Open the file in the library and choose **Generate AI subtitles**. Pick **Local speech recognition**. Transcription runs in the background on the server and does not call an AI model. Choose **Transcribe again** to ignore the previous transcript.

- Mandarin, Cantonese, English, Japanese and Korean only. Other languages are refused.
- Cloud-drive files are not supported. Commentary tracks are skipped.
- Transcription uses the server CPU and pauses while the server is transcoding for playback.
- Without the new image, the panel says the speech component is missing.

#### Browse clips on the website

On a phone, pull down on the library home until it says **Release to start watching**, then let go. On a wider screen, open the **Open clips** card on that same home page. You can filter, mark watched or favorite, share, and choose **Watch full**.

- Smoother playback needs **Prepare clips** under Settings → Playback. Until clips are ready, the page shows how many are done.
- A clip uses a transcode slot when the original file cannot play directly.

#### See when the next episode airs

On a series in the library, open **Air schedule** under the season. It shows what has aired, what is missing, and the next date. **Follow new episodes** subscribes from there. **Find episode N** searches for a gap.

- Air dates come from TMDB. Times in the library are estimates.
- The card stays hidden when the season has no upcoming dates, on a share page, or on a server older than this release.

### More features and improvements

- **Subscribe from episode N.** In the subscription dialog, choose **From episode N**. Earlier episodes are not searched or downloaded. iPhone 0.12.0 and Android 0.9.0 show this as a note; you change it on the website.
- **Limit a rule group to sites.** Settings → Subscription rules, under **Sites**. Tap once to allow a site (the order is the priority), again to block it, a third time to clear. Leave them all unset to use every enabled site.
- **Titles follow your interface language.** Discover and the library show titles and overviews in the language of the interface. Under Settings → Metadata and organization, **Metadata language** is now **Library language**. That control is what gets written into folders, NFO files, poster text and external players.
- On an English interface, **Search releases** also tries the Chinese title.
- A single episode published up to two days early can match. A search before the air date waits, instead of retrying an empty result.
- After you upload into a cloud library, the next scan lists the changed folder when the drive plugin reports that folder. Otherwise the whole mount is scanned.

### Fixed

- Bonus and extra torrents are no longer treated as the episode, so the subscription can still fetch the episode itself.
- Third-party plugins can load again on a NAS that copies access-control lists onto the plugin sandbox.
- Changing the folder an automatic import follows no longer leaves a failed ingest job stuck.
- On a phone, the last clip is no longer covered by the video frame, and leaving it is recorded.

### For administrators

- This image is larger because it includes the speech model.
- A library scan can be limited to named folders on a mounted cloud drive. Passing both a local path and a cloud path is rejected.
- Plugins can correlate a playback event with the catalog watch record.

### Before you update

- This release migrates the database. It stores interface-language translations next to the library-language text. Rolling back without the backup in the warning above drops those translations. Titles and overviews already written in the library language stay in that backup.
- The air schedule on iPhone needs 0.12.0. On Android it needs 0.9.0. Older apps keep working, and the schedule stays hidden until both the app and this server are updated. The website in this release already has it.

Thanks to @o1xhack. Full changes: [v0.43.0 → v0.44.0](https://github.com/movieclaw/MovieClaw/compare/v0.43.0...v0.44.0).

## 简体中文

## v0.44.0：没有字幕，也能听出台词

一部片子没有字幕时，服务器可以自己把对白听写出来。网页也能刷片段，剧集看得到播出日历。

> ⚠️ **本次需要更新 Docker 镜像。** 先停止容器，再备份数据目录，然后拉取新镜像。「设置 → 更新与维护」会先要求换镜像，并且不会做更新前的自动备份。要回到 0.43.0，请恢复这份备份，再用 `v0.43.0` 镜像启动。

### 本版亮点

#### 没有字幕？从音轨把对白听写出来

在媒体库打开这部片子的文件，选择「生成 AI 字幕」，来源选「本地语音识别」。识别在服务器后台进行，不调用 AI。想重来就选「重新识别」。

- 只支持普通话、粤语、英语、日语、韩语，其他语言会被拒绝。
- 网盘文件暂不支持。解说音轨会跳过。
- 识别占用服务器 CPU；有人正在转码播放时，识别会暂停。
- 没换新镜像时，面板会提示缺少本地语音识别组件。

#### 在网页上刷片段

手机上，在媒体库首页一直往下拉，出现「松手，开始欣赏」后松开。宽屏上，同一页有一张「打开片段」卡片。可以筛选、标已看或收藏、分享，也可以「看全片」。

- 要更顺，请到「设置 → 播放」打开「片段预切」。片段还没切好时，页面会显示完成了多少。
- 原文件不能直接播时，这一条片段会占用一个转码名额。

#### 看下一集什么时候播

在媒体库的剧集详情里，季的下面打开「播出日历」。已播、缺集和下一次更新日期都在这里。「订阅追更」会从这里订上；「补第 N 集」会去找缺的那集。

- 播出日期来自 TMDB，入库时间是按站点发布规律估的。
- 这一季没有即将播出的集、分享页，或服务器还不是这一版时，这张卡片不出现。

### 其他新功能与改进

- **从第 N 集起订阅。** 在订阅对话框里选「从第 N 集起」。更早的集不会搜索，也不会下载。iPhone 0.12.0 和 Android 0.9.0 会把这件事写成说明；要改仍到网页上改。
- **规则组可以限定站点。** 「设置 → 订阅规则」里的「站点」。点一下只允许这个站（点选顺序就是优先级），再点排除，第三下取消。一个都不选，就是所有已启用的站点。
- **片名跟界面语言走。** 发现页和媒体库里，每个人看到的片名和简介跟自己的界面语言。「设置 → 刮削与整理」里的「元数据语言」改名为「媒体库语言」，它决定写进文件夹、NFO、海报文字和外部播放器的语言。
- 英文界面上的「搜索资源」（Search releases）也会用中文名去搜。
- 明确标了集数的资源，最多可以比播出日早两天对上。播出日之前的搜索会等待，不再对着空结果反复重试。
- 往网盘媒体库传完文件后，下次扫描会只列有变化的文件夹，前提是网盘插件报出了那个文件夹；没有报的话，仍扫描整个挂载目录。

### 修好了

- 彩蛋、花絮种子不会再被当成正片那一集，订阅仍能去抓正片。
- 会把访问控制列表拷进插件沙箱的 NAS 上，第三方插件可以再次加载。
- 改了自动导入所监听的文件夹之后，不会再留下一个失败的入库任务一直挂着。
- 手机网页上，最后一条片段不再被画面挡住，离开时也会记上。

### 管理员须知

- 新镜像因为带上了语音模型，体积更大。
- 媒体库扫描可以只列网盘上点名的文件夹。本地路径和网盘路径不能同时传。
- 插件可以把一次播放事件和片库里的观看记录对上。

### 升级须知

- 这一版会迁移数据库，在媒体库语言的原文旁边存界面语言的译文。不恢复上面那份备份就回退，这些译文会丢掉。已经按媒体库语言写好的片名和简介留在那份备份里。
- iPhone 上的播出日历需要 0.12.0，Android 需要 0.9.0。更旧的 App 仍能用，日历会先藏起来，直到 App 和这一版服务器都更新。这一版网页已经有日历。
