## Apple TV 0.13.0: Choose an episode from the player

Series now have an episode shelf inside the player. The remote can open it, move through available episodes, and change seasons without returning to the detail page.

> ✅ Works with MovieClaw Server 0.28.0 or later, the same as 0.12.7. Changing seasons inside the player requires Server 0.50.0 or later; older supported servers still show the current season. This GitHub release contains notes only and does not upload a TestFlight build.

### Highlights

#### Browse episodes without leaving the picture

Press up while a series is playing to open the still-image shelf. Focus starts on the episode currently playing; move across the shelf and press the remote to switch, or move up to choose another season. Missing episodes remain visible and are skipped by focus.

Installation requires a corresponding TestFlight build prepared separately from this GitHub release.

Full changes: [tvos-v0.12.7 → tvos-v0.13.0](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.12.7...tvos-v0.13.0).

## 简体中文

## Apple TV 0.13.0：直接从播放器选集

剧集播放器现在有自己的分集剧照排。用遥控器就能打开、切换可播放的集数，也能换季，不必先退回详情页。

> ✅ 搭配 MovieClaw 服务器 0.28.0 或更新版本即可使用，与 0.12.7 相同。在播放器里跨季切换需要服务器 0.50.0 或更新版本；更早但仍受支持的服务器仍会显示当前季。这个 GitHub Release 只有说明，不会上传 TestFlight 构建。

### 本版亮点

#### 不离开画面，也能浏览分集

播放剧集时按上键，会打开分集剧照排。焦点先落在正在播放的一集；左右移动后按遥控器即可换集，继续向上可以选择其他季。缺集仍会列出，焦点会自动跳过。

安装仍需要另行准备与此版本对应的 TestFlight 构建。

完整改动：[tvos-v0.12.7 → tvos-v0.13.0](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.12.7...tvos-v0.13.0)。
