## v0.23.0: Smoother mobile playback, and easier browsing of large libraries

Double-tap to seek, hold for faster playback and swipe to adjust progress. Large libraries scroll smoothly, download destinations can be remembered, and external AI clients can connect to MovieClaw.

> ⚠️ **A Docker image update is required.** MCP dependencies and the way mclaw updates with the application have changed. Pull the new image and recreate the container before updating in-app.

### Highlights

#### Seek, speed up and scrub comfortably on your phone

Double-tap the left or right side to skip ten seconds, hold for 2× playback, swipe to seek, or lock controls in landscape. The timeline marks embedded chapters. Seeking or switching streams over remote connections uses a still frame or preview to reduce black flashes.

#### Remember where you browsed and where downloads belong

Poster walls, photo galleries, artwork galleries and favorites can restore your browsing position. Administrators can remember download destinations by resource category; the final path and downloader are still shown for confirmation before submitting.

#### Give external AI clients access to your media services

Administrators can create MCP endpoints and select which services clients such as Claude Desktop may call. Each endpoint has its own tools, token and connection self-test, with separately configurable access.

### More features and improvements

- **Lighter large-library scrolling**: Poster walls, galleries and resource search render only items near the visible window.
- **Careful handling of identical titles and years**: Check tracker title IDs before delivery and request review when uncertain instead of silently downloading the wrong film.
- **Chapter images for new imports**: Generate after import without letting chapter jobs block scans for hours.
- **Artwork browsing in favorites**: Resource search and galleries share the lightbox, with mouse-only navigation buttons.
- **More complete CLI access**: Added Activity summaries and sharing actions. mclaw now updates with application artifacts.
- **Clearer playback diagnostics**: Show transfer speed and try to recover decoding errors before reducing quality.

### Fixed

- Corrected altered colors after transcoding, green Dolby Vision screenshots and hardware-transcoding failures for some 10-bit sources.
- Fixed seeking interrupted by mobile system gestures, seeks during track switches and positions beyond the end.
- Download confirmations are no longer hidden behind the lightbox; long and stacked dialogs behave better.
- Early imports avoid copying files still being written, and old quality-upgrade jobs finish correctly.
- Transfers from Other libraries no longer move unrelated titles from the same folder, and file identity records follow the transfer.
- After jumping through the alphabet index, scrolling upward loads earlier titles.

### Before you update

- This release migrates the database. Restore the automatic pre-update backup when rolling back across versions.
- Remembered download destinations are for administrators; ordinary members continue using server routing.
- The title-level scraping-owner action is removed. Library-level scraping settings still apply.

Full changes: [v0.22.0 → v0.23.0](https://github.com/movieclaw/MovieClaw/compare/v0.22.0...v0.23.0).

## 简体中文

## v0.23.0：手机看片更顺，翻大片库也不卡

这一版让播放器支持双击快进、长按倍速和横滑调进度。大片库浏览更流畅，下载位置可以记住，还能让外部 AI 客户端连接 MovieClaw。

> ⚠️ **本版需要更新 Docker 镜像**：新增 MCP 依赖，并调整命令行随应用更新的方式。请先拉取新镜像并重建容器，再做应用内更新。

### 本版亮点

#### 快进、倍速、拖进度，手机上都好操作

双击画面左右可前后跳 10 秒，长按进入 2 倍速，横滑可调整进度，横屏支持锁定控件。进度条会显示内嵌章节刻度，外网拖动和切换时用画面或缩略图过渡，减少黑屏。

#### 上次翻到哪、下载放哪，都能记住

海报墙、相册墙、图廊与收藏页可以回到上次浏览位置。管理员手动下载时，按资源分类记住保存位置，下次仍会先显示最终路径和下载器，确认后再提交。

#### 外部 AI，也能用你的影音服务

管理员可创建 MCP 端点，选择要开放的服务，让 Claude Desktop 等外部客户端调用。每个端点有自己的工具目录、令牌和连通性自检，授权范围可以分别配置。

### 其他新功能与改进

- **大片库滚动更轻**：海报墙、相册墙、图廊和资源搜索只绘制当前窗口附近的内容。
- **同名同年的片子更慎重**：投递前核对站点影片编号，拿不准时进入待处理，避免静默下错片。
- **新片自动补章节图**：下载入库后就安排生成，也不再让章节任务长时间挡住扫描。
- **收藏页也能看图廊**：图片浏览和资源搜索共用灯箱，鼠标设备增加翻页按钮。
- **命令行能力更完整**：新增活动汇总与影片分享等入口，mclaw 从本版起随应用产物更新。
- **播放诊断更直观**：展示取流速度，遇到解码错误先尝试恢复再降档。

### 修好了

- 转码画面变色、杜比视界截图泛绿，以及部分 10-bit 片源硬件转码失败的问题得到修复。
- 手机系统手势打断拖动、切音轨空档拖动和片尾越界等进度条问题得到修复。
- 灯箱中的下载确认条不再被盖住，超长弹窗和多层弹窗也更好操作。
- 边下载边入库不再去复制仍在写入的文件，洗版遗留任务会正常收尾。
- 「其他」库转移不会连带搬走同目录的其他条目，文件身份记录也会跟着更新。
- 从字母索引跳转后向上滑动，可以继续加载前面的影片。

### 升级须知

- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。
- 下载位置记忆仅供管理员使用；普通成员继续由服务器自动路由。
- 条目页的「刮削归属」入口已移除，媒体库级刮削设置继续生效。

完整改动见 [v0.22.0 → v0.23.0](https://github.com/movieclaw/MovieClaw/compare/v0.22.0...v0.23.0)。
