## Android TV 0.7.0: Smoother browsing and a poster screensaver

Browse more smoothly and return home from compatible TV launchers.

- Improved scrolling on detail pages, poster rows and Continue watching.
- Compatible TV launchers can return to the home root through movieclaw://home; focus is restored after leaving playback or the sidebar.
- A poster screensaver can cycle through Continue watching artwork while idle.
- The home page retries when the network becomes available after startup. Rule groups add **DV P5** exclusion with Server 0.43.0.

The Android TV interface remains Chinese in this release.

Full changes: [androidtv-v0.6.0 → androidtv-v0.7.0](https://github.com/movieclaw/MovieClaw/compare/androidtv-v0.6.0...androidtv-v0.7.0).

## Android TV 0.7.0：浏览更顺畅，待机看海报

电视浏览更顺畅，也能从兼容的电视桌面快速回到首页。

- 优化详情页、海报行和「接下来继续」的滑动体验。
- 兼容电视桌面可通过 movieclaw://home 回到首页根部，离开播放器或侧栏后恢复页面焦点。
- 新增海报屏保，待机时可轮播「继续观看」中的剧照。
- 开机时网络尚未就绪，首页会在联网后重试；规则组新增「DV P5」排除选项，需服务器 0.43.0。

Android TV 界面本次仍以中文为主。
