## v0.47.1: A stability update

The website no longer mistakes a slow transcode for a slow connection, a finished download that lands in an ignored folder is explained, and Netflix arrival cards use a wide still when one exists.

> ✅ Update from Settings → Updates and maintenance. The Docker runtime stays 25. This release does not migrate the database.

### Fixed

- While the website is transcoding, it treated the server’s encoding speed as your connection speed. If you had not limited quality, the picture paused and the stream restarted once at a lower bitrate. If you had already limited quality, or that restart had already happened, the card **The connection is too slow for this quality** appeared, with **Keep current quality** and **Switch to** a lower resolution. This version uses the connection’s own speed. A connection that really is too slow still restarts once or shows that card. Playback that is not being transcoded is judged as in 0.47.0.
- A subscription download could finish and never enter the library, with nothing on the timeline to say why, when the files landed in an automatic-import entry you had ignored. This version shows **finished downloading but cannot be imported** on that subscription and in the pending list. It does not clear the ignore, and it does not download again. An administrator opens **Settings → Automatic import**, expands that rule, chooses **Ignored**, and presses **Resume processing** on the entry, then waits for the next scan. To keep the entry ignored, handle the files yourself.
- With the theme set to **Netflix**, the wide cards on **My subscriptions** (the phone tab is **Subscriptions**) under **May arrive today** or **Arriving soon** fill the frame when the title has a wide still. A title with only a poster, or a wide still that does not load, keeps the blurred poster with the full poster in the center, instead of an empty dark frame. Silver Glass does not have this row.

### Before you update

- There is no database migration. The Docker runtime stays 25, so updating from Settings → Updates and maintenance does not require a new image. **Roll back to a previous version** can return to 0.47.0 without restoring a backup, because the database structure is unchanged.
- Known: the new notice still says **Settings → Watch Import**. That page is **Settings → Automatic import**.

Thanks to @duchanghexuhe. Full changes: [v0.47.0 → v0.47.1](https://github.com/movieclaw/MovieClaw/compare/v0.47.0...v0.47.1).

## 简体中文

## v0.47.1：稳定性更新

网页转码变慢时会被当成网速不够，已下载完但落在忽略目录里的订阅不说明原因，Netflix 主题的入库预告在有横图时没有铺满。这一版把这三处改过来。

> ✅ 在「设置 → 更新与维护」里更新。Docker 运行时仍是 25。这一版不迁移数据库。

### 修好了

- 网页正在转码时，会把服务器出画的速度当成你的网速。没有限制画质时，画面停住并自动重开一次，按这个偏低的速度压低码率。已经限制过画质，或已经自动重开过一次，会弹出「网速跟不上当前画质」，按钮是「继续当前画质」和「改用」加一个更低的分辨率。这一版改用线路本身的速度。线路真的不够时，仍会自动重开一次或弹出这张卡。没有走转码的播放，判断与 0.47.0 相同。
- 订阅下载已经完成，文件却落在你忽略过的自动入库条目里时，上一版会一直等入库，时间线上不说明原因。这一版在这条订阅和待处理事项里提示「下载完成但无法入库」。它不会取消忽略，也不会重新下载。管理员打开「设置 → 自动入库」，展开对应规则，点「已忽略」，再点该条目上的「恢复处理」，然后等下一次巡检。想继续忽略的话，自己处理这些文件。
- 主题选 Netflix 后，桌面顶栏「我的订阅」、手机底栏「订阅」里，「今日可能入库」或「即将入库」那一行的横卡，有横版剧照时铺满画面。只有海报，或横图打不开时，仍是模糊的海报底加上中间完整的海报，不会剩一块空底色。银玻璃主题没有这一行。

### 升级须知

- 没有数据库迁移。Docker 运行时仍是 25，所以从「设置 → 更新与维护」更新不必换镜像。在「回退到历史版本」里回到 0.47.0 时不用恢复备份，因为数据库结构没有变。
- 已知：新的提示正文仍写着「设置 → 监听导入」。这个页面现在的名字是「自动入库」。

感谢 @duchanghexuhe。完整改动：[v0.47.0 → v0.47.1](https://github.com/movieclaw/MovieClaw/compare/v0.47.0...v0.47.1)。
