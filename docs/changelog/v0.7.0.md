## v0.7.0: Player downloads work, and your disks can rest

Download content from Jellyfin-compatible clients and browse large libraries faster. Closing playback now stops leftover disk reads promptly.

✅ No Docker image update is required. Update from **Settings → Application**.

### Highlights

#### The Download button now downloads

Clients such as VidHub can download local videos with resume support and select a specific version. strm content redirects to the cloud-drive URL, so the cloud drive handles the download traffic.

#### Stop watching, and the server stops reading

When a client reports that playback has stopped, the server closes leftover video connections for that device. This fixes disks continuing to read and CPU usage staying high after the playback window closes.

### More features and improvements

- **Faster large-library home screens**: Lists load only the information they display, and concurrent cover requests share their generated result.
- **Less background disk activity**: Routine watches and reconciliation skip specification probing for historical files. Manual scans still fill it in.

### Fixed

- The CLI and AI assistant can now configure and test Webhooks and inspect delivery history.

### Before you update

- This release adds database indexes. Restore the automatic pre-update backup when rolling back across versions.

Full changes: [v0.6.0 → v0.7.0](https://github.com/movieclaw/MovieClaw/compare/v0.6.0...v0.7.0).

## 简体中文

## v0.7.0：客户端下载能用了，关窗后硬盘也能歇了

这一版补上 Jellyfin 客户端的下载功能，并继续加快大库浏览。关掉播放窗口后，服务器也会及时停止读盘。

✅ 本版无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 播放器里的「下载」，现在真的能下载

VidHub 等客户端可以下载本地视频，支持断点续传，也能指定多版本影片中的某个版本。strm 内容直接跳到云盘地址，下载流量由云盘承担。

#### 看片结束，服务器及时收工

客户端上报停止播放后，服务器会关闭该设备留下的视频连接。关窗后硬盘仍不停读、CPU 降不下来的问题得到修复。

### 其他新功能与改进

- **大库首页继续提速**：列表只加载展示需要的信息，库封面并发请求也会复用生成结果。
- **后台少打扰硬盘**：日常监听和定期对账跳过历史文件规格探测；主动扫描仍会完整补齐。

### 修好了

- 命令行和 AI 助手现在能配置、测试 Webhook，并查看投递记录。

### 升级须知

- 本版新增数据库索引。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.6.0 → v0.7.0](https://github.com/movieclaw/MovieClaw/compare/v0.6.0...v0.7.0)。
