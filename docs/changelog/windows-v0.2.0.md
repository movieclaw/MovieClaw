## Windows 0.2.0: Follow a local actor into the library

Cast cards in local and NFO libraries can now open every title by that actor in the same library, even when no online person page exists. The Windows interface remains Chinese.

> ✅ Server requirements are unchanged from 0.1.4. The new actor-filtered wall requires MovieClaw Server 0.48.0 or later. The app offers this update itself, or download it from https://github.com/movieclaw/MovieClaw/releases/tag/windows-v0.2.0.

### Highlights

#### Turn an actor card into a library view

On an item detail page, click an actor who has no online person page. Windows opens that same library with **正在看 姓名 的作品** above the posters; choose **返回全部作品** to remove the condition. Keyboard activation works too. Actors with an online person page still open that page, and directors without one remain static.

Thanks to @Migflyway. Full changes: [windows-v0.1.4 → windows-v0.2.0](https://github.com/movieclaw/MovieClaw/compare/windows-v0.1.4...windows-v0.2.0).

## 简体中文

## Windows 0.2.0：从本地演员找到同库作品

本地库和 NFO 库里的演员卡现在也能打开这位演员在同一媒体库中的全部作品，不再依赖在线影人页。Windows 界面仍是中文。

> ✅ 对服务器的要求与 0.1.4 相同。新的演员筛选海报墙需要 MovieClaw 服务器 0.48.0 或更新版本。App 会自己提示这次更新，也可以从 https://github.com/movieclaw/MovieClaw/releases/tag/windows-v0.2.0 下载。

### 本版亮点

#### 把演员卡变成同库作品墙

在条目详情页点没有在线影人页的演员，Windows 会打开同一媒体库，并在海报上方显示「正在看 姓名 的作品」；选择「返回全部作品」即可移除条件。键盘操作同样可用。带在线影人页的演员仍进入影人页；没有影人页的导演仍不可点。

感谢 @Migflyway。完整改动：[windows-v0.1.4 → windows-v0.2.0](https://github.com/movieclaw/MovieClaw/compare/windows-v0.1.4...windows-v0.2.0)。
