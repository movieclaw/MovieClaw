## v0.38.0: Take your library offline

Download films and episodes to your iPhone or iPad, watch without reaching your server, and bring your progress back when you reconnect. Model setup also gains model discovery and checks for compatible tool calling.

> ⚠️ **Update the Docker image**: Pull `movieclaw/movieclaw:latest` and recreate the container. In-app updating alone cannot install this release's container startup changes. Offline downloading requires **iPhone and iPad 0.8.0 or later**.

### Highlights

#### Get ready for a journey without internet

Streaming from home is not always possible on a flight or an unreliable connection. With iPhone and iPad 0.8.0, open a title's menu and choose **Download**: keep the original or choose a smaller quality, and download one episode, unwatched episodes or the whole series. Subtitles and artwork travel with it; offline viewing progress joins your server history when you reconnect.

The server can use your existing Mac transcoder to prepare smaller HEVC copies. Watching takes priority over downloads, and interrupted conversion resumes when resources return. No Mac transcoder update is required. Disc folders and ISO images cannot be downloaded; converted copies contain one audio track and do not include image-based subtitles.

#### Connect a model your endpoint can actually use

Administrators can fetch an endpoint's model list from **Settings → Notifications & integrations → Model access**, select the model used for connection testing, and add models outside the OpenAI preset. Updated OpenAI, DeepSeek, Kimi, GLM and Bailian catalogs carry their model limits and thinking options. Setup checks tool-calling requirements against the chosen protocol, so an incompatible model is caught before an AI conversation starts.

### More features and improvements

- **Choose who can download video**: Administrators can control video downloading in **Settings → Members**. The same permission applies to iPhone downloads and Jellyfin-compatible clients; existing local copies remain playable when permission is turned off.
- **Plan download space**: All available qualities below the source are shown with estimated sizes; converted sizes are marked with ≈. Choosing a series download fetches its quality choices in one batch.
- **See conversion progress**: Activity shows the title, quality, transcoder, speed and conversion progress instead of an export identifier.
- **Background work can continue**: A download running on the Mac transcoder no longer makes the server treat the library as being watched and unnecessarily defer intro detection.

### Fixed

- Database upgrades on slow disks are no longer killed by the container's startup timeout, and a failed migration no longer leaves half of that migration applied.
- Update checks find the latest server and NER model releases even when separate client releases were published more recently.

### Before you update

- This release migrates the database. To return to v0.37.0 or earlier, restore the automatic pre-update backup.
- New downloads require the server to be reachable. Existing downloaded copies can be played offline; removing download permission does not remotely erase them.

Full changes: [v0.37.0 → v0.38.0](https://github.com/movieclaw/MovieClaw/compare/v0.37.0...v0.38.0).

## 简体中文

## v0.38.0：把片库带到没网的地方

电影和剧集可以下载到 iPhone 或 iPad，连不上家里的服务器也能看；重新联网后，观看进度会同步回来。模型接入也增加了模型列表获取和工具调用兼容性检查。

> ⚠️ **需要更新 Docker 镜像**：请拉取 `movieclaw/movieclaw:latest` 并重建容器。仅做应用内更新无法安装本版的容器启动改动。离线下载需要 **iPhone 与 iPad 0.8.0 或更新版本**。

### 本版亮点

#### 出发前下好，没网也能看

飞机上或网络不稳定时，不一定能连上家里的片库。搭配 iPhone 与 iPad 0.8.0，在影片菜单中选择「下载」：保留原画或选择更小的画质，剧集可下载一集、未看的集或整部。字幕和图片一起带走，离线观看进度会在重新联网后合入服务器的观看记录。

服务器可以用现有的 Mac 转码器准备体积更小的 HEVC 副本。有人看片时下载转码会让出资源，中断后在资源恢复时继续。无需更新 Mac 转码器。原盘目录和 ISO 暂不能下载；转码副本只保留一条音轨，不包含图形字幕。

#### 接入前，先确认模型在这个端点能用

管理员可在「设置 → 通知与集成 → 模型接入」获取端点的模型列表，选择用于连接测试的模型，并添加 OpenAI 预设目录之外的模型。OpenAI、DeepSeek、Kimi、GLM 和百炼的模型目录更新了模型限制与思考选项。接入时会检查模型的工具调用要求是否符合所选协议，在开始 AI 对话前发现不兼容的配置。

### 其他新功能与改进

- **谁能下载影片，由你决定**：管理员在「设置 → 成员」控制影片下载权限，iPhone 与 Jellyfin 兼容客户端遵循同一开关；关闭权限后，已经下载的本机副本仍可播放。
- **下载前算好空间**：列出所有低于源画质的可用档位与预计大小，转码大小标「≈」；剧集选档一次获取整批画质信息。
- **看清转码进度**：活动页显示片名、画质、转码器、速度与转码进度，不再显示导出编号。
- **后台识别照常进行**：Mac 转码器上的下载任务不再被算成有人看片，避免不必要地推迟片头识别。

### 修好了

- 慢盘上的数据库升级不再被容器启动超时强行中止，单条迁移失败也不会留下只执行了一半的改动。
- 即使后来发布了独立客户端，更新检查也能找到最新的服务器与 NER 模型版本。

### 升级须知

- 本版升级了数据库。如需回退到 v0.37.0 或更早版本，请用更新前自动生成的备份恢复。
- 新下载需要能连上服务器；已经下好的副本可以离线观看。关闭下载权限不会远程擦除本机文件。

完整改动见 [v0.37.0 → v0.38.0](https://github.com/movieclaw/MovieClaw/compare/v0.37.0...v0.38.0)。
