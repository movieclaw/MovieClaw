## v0.4.0: See your downloads, and take over when needed

Adjust subscriptions, choose torrents manually, and send download and import notifications to Telegram or Discord. Discovery and mobile controls are easier to use, too.

> ⚠️ **A Docker image update is required.** New messaging dependencies are included. Pull the new image and recreate the container before updating the application.

### Highlights

#### You do not have to wait for the next subscription check

Search immediately from a subscription, change its seasons and rules, or choose a torrent yourself. Download progress, speed and estimated time remaining refresh continuously, making stalled steps easier to identify.

#### Get updates in your usual messaging app

Settings → Notifications now supports Telegram and Discord. Enter the bot credentials and pair with a code to receive subscription updates and talk to the assistant, just as with WeChat.

#### Claim files that could not be identified

Watched imports distinguish unidentified content from environment failures. Your confirmed title identity is retained through retries. You can also skip existing files when enabling a watch rule.

### More features and improvements

- **Richer discovery**: Complete Douban lists and TMDB region, platform and genre rows support browsing beyond the first page.
- **Add your own trackers**: Place YAML files in `data/site-configs/` to connect custom NexusPHP sites. Added Audiences, HDHome, KeepFriends, OurBits, PTer and PTHome.
- **Easier library management**: Delete one version or episode, and drag libraries to reorder them.
- **Better mobile controls**: Larger touch targets, swipeable carousels and consistent confirmation dialogs.
- **Standalone mclaw CLI**: Its command tree follows the server API for terminal access.
- **Smoother long lists**: Less repeated rendering in poster grids, search and assistant replies. Custom AI endpoints can set a User-Agent.

### Fixed

- Imports no longer remain silently stuck after download completion, missing network-mount events or environment failures.
- Messaging channels retry temporary network errors more reliably, including pairing receipts and subscription notifications.
- Subscription edits correctly save their destination and can restore default library routing.
- Recent conversation pagination no longer skips a middle batch.
- Corrected download destination memory, tracker promotion detection and conversation creation on non-HTTPS deployments.

### Before you update

- This release migrates the database. Restore the automatic pre-update backup when rolling back across versions.

Full changes: [v0.3.0 → v0.4.0](https://github.com/movieclaw/MovieClaw/compare/v0.3.0...v0.4.0).

## 简体中文

## v0.4.0：追更进度看得见，卡住也能自己选

这一版让订阅可以随时调整、手动选种，并把下载与入库消息送到 Telegram、Discord。发现页和手机操作也更顺手了。

> ⚠️ **本版需要更新 Docker 镜像**：新增消息通道依赖，请先拉取新镜像并重建容器，再更新应用。

### 本版亮点

#### 订阅不用只能等下一轮

在订阅详情页可以「立即搜索」、调整追更范围与规则，也能手动挑一个种子下载。下载进度、速度和预计剩余时间会持续刷新，卡在哪一步更容易看清。

#### 下载消息，送到你常用的聊天工具

「设置 → 消息推送」新增 Telegram 和 Discord，填入机器人凭据、用配对码绑定即可。和微信一样，既能接收订阅动态，也能与助手对话。

#### 识别不出来的文件，留给你认领

监听导入把待认领内容和环境故障分开显示。你确认过的影片身份会保留，故障恢复后重试也不会丢；开启监听时还可以跳过目录里的存量文件。

### 其他新功能与改进

- **发现页更丰富**：加入豆瓣完整榜单与 TMDB 地区、平台、类型片单，支持浏览完整榜单。
- **站点可以自己接**：在 `data/site-configs/` 放入 YAML 接入自定义 NexusPHP 站点；新增观众、高清家园、朋友、OurBits、猫站、铂金家。
- **媒体库整理更方便**：可以删除某个版本或某一集，库顺序支持拖拽调整。
- **手机操作更顺手**：按钮触控区域加大，轮播支持横滑，确认弹窗和操作提示统一。
- **独立命令行 mclaw**：命令树与服务端接口同步，方便从终端操作。
- **长列表更流畅**：海报墙、搜索和助手输出减少重复绘制；自定义 AI 接入点可设置 User-Agent。

### 修好了

- 下载刚完成、网络挂载没有文件事件，或入库遇到环境故障时，不再长期无声卡住。
- 消息通道遇到临时网络故障会继续重试，绑定回执和订阅通知更稳定。
- 调整订阅时能正确保存入库目标，也能改回按默认媒体库路由。
- 侧栏最近会话分页不再漏掉中间一批记录。
- 修复下载目标记忆、站点促销识别和非 HTTPS 部署新建会话等问题。

### 升级须知

- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.3.0 → v0.4.0](https://github.com/movieclaw/MovieClaw/compare/v0.3.0...v0.4.0)。
