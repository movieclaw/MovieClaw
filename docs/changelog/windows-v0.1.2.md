## Windows 0.1.2: Exclude Dolby Vision Profile 5

A small update adds one more way to filter releases your devices cannot play well.

- Rule groups add **DV P5** exclusion, so incompatible releases can be filtered out. Requires Server 0.43.0.

This is the Windows playback app. The Windows remote transcoder is a separate application.

Full changes: [windows-v0.1.1 → windows-v0.1.2](https://github.com/movieclaw/MovieClaw/compare/windows-v0.1.1...windows-v0.1.2).
