## Apple TV 0.12.7: Find what you have not finished

Library home rows and poster walls can now distinguish titles you have not started from titles you started but have not finished. Opening **View All** with the remote keeps the row's watch condition and sorting.

> ✅ Works with MovieClaw Server 0.28.0 or later, the same as 0.12.6. The new **Unfinished** condition requires Server 0.47.0 or later. Install the corresponding TestFlight build. This GitHub release contains notes only.

### Highlights

#### Continue from the titles that still have something left

Choose **Unfinished** while customizing a library home row to include movies you have not finished and series with available episodes left to watch. **Unwatched** remains a separate choice for titles you have never started. Poster walls opened from a filtered row keep that condition, explain when it produced an empty wall, and offer **Clear watch filter**.

The GitHub release contains release notes only. Installation requires the corresponding TestFlight build.

Thanks to @o1xhack. Full changes: [tvos-v0.12.6 → tvos-v0.12.7](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.12.6...tvos-v0.12.7).

## 简体中文

## Apple TV 0.12.7：找出还没看完的作品

资料库首页行和海报墙现在能区分「从没开始看」与「已经开始、但还没看完」。用遥控器点「查看全部」时，也会保留这一行的观看条件和排序。

> ✅ 搭配 MovieClaw 服务器 0.28.0 或更新版本即可使用，与 0.12.6 相同。新的「未看完」条件需要服务器 0.47.0 或更新版本。请安装对应的 TestFlight 构建。这个 GitHub Release 只有说明。

### 本版亮点

#### 从还有内容没看完的作品继续

自定义资料库首页行时选择「未看完」，会包含还没看完的电影，以及仍有在架集数没看完的剧集。「未看」仍是另一项，只包含从未开始的作品。从筛选过的首页行打开海报墙时会保留条件；筛选结果为空时，页面会说明原因，并提供「清除观看筛选」。

这个 GitHub Release 只有更新说明；安装需要对应的 TestFlight 构建。
