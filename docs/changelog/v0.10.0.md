## v0.10.0：后台任务有进度，重启之后还能接着做

这一版带来统一任务中心。字幕生成、扫描、整理和转移集中查看，应用更新或异常重启后，任务会继续执行或安全重试。

> ⚠️ **本版需要更新 Docker 镜像**：容器启动与恢复机制已更新，请先拉取新镜像并重建容器。Docker Compose 用户可执行 `docker compose pull && docker compose up -d`。

### 本版亮点

#### 下载、入库、字幕任务，一处看清

侧栏进入任务中心，就能查看后台作业、下载和入库。剧集任务合并展示，识别到作品时显示海报；字幕任务还会列出目标语言、当前阶段、用量和耗时。

#### 跑到一半重启，不再悄悄丢任务

字幕生成、媒体库扫描、元数据刷新、文件整理、转移和监听入库都会保存进度。更新应用或重启后，新进程会接手继续处理，或按任务状态安全重试，也能取消和重试。

### 其他新功能与改进

- **启动状态看得见**：容器启动和恢复期间有占位页，失败时提供可读诊断。
- **换挂载路径更稳**：根目录改成挂载别名或软链接时，尽量延续原记录，避免同一文件重复入库。
- **蓝光音轨信息更完整**：读取原盘流信息，补齐部分缺失的音轨语言。
- **北洋园支持账号密码登录**：同时保留原有 Cookie 接入方式。
- **手机任务卡更清楚**：阶段、来源、时间和操作重新整理，完成后不再挂无意义的进度条。

### 升级须知

- 旧镜像无法承载本版的启动与恢复机制，应用内更新会提示先升级镜像。
- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.9.0 → v0.10.0](https://github.com/movieclaw/MovieClaw/compare/v0.9.0...v0.10.0)。
