## v0.41.0: Skip the ads, keep your own pages

The player now skips ads by itself and learns which shows you skip the intro on. Plugins, including ones the AI assistant writes for you, can add their own pages to the sidebar, and the server uses far less memory.

> ✅ No Docker image update is required. Update from Settings → Update & Maintenance. To get automatic skipping in the apps, update to iPhone and iPad 0.9.2, Apple TV 0.9.2, Mac 0.9.2, Android 0.6.0 or Android TV 0.5.0.

### Highlights

#### Ads skip themselves, intros once you've skipped one

Every recognized ad or intro used to wait for you to press skip, episode after episode. Now ads and previews skip on their own, with **Undo (撤回)** next to the "skipped" notice for a few seconds. Skip an intro by hand once and the player remembers to skip it for the rest of that show; **No thanks (不用)** next to the notice takes that back. Undoing a skipped intro forgets the show too. This applies automatically in the web player and in the apps listed above.

- Skippable parts are marked in amber on the progress bar. Seeking or dragging into one only shows the skip button.
- Learned shows belong to each member's account, so they follow you to every app.
- There's no switch to turn automatic skipping off; every skip can be undone.
- Outros and unclassified repeats are never skipped on their own. Share links skip ads but don't learn intros.
- Apps older than the versions above keep manual skip buttons. Newer apps on an older server skip ads but don't learn intros.

#### Pages of your own in the sidebar

Plugins could add features but not a page to look at. Now a plugin can bring its own pages, which open inside MovieClaw on the web and sit in the sidebar (in a phone browser, on the 我的 page). Administrators can also ask the AI assistant for one, such as "a page with this week's new 4K films and current downloads": it builds the page as a plugin and asks you before installing it. Pages run with the permissions of whoever opens them, so each needs your consent: when approving a plugin package, tick **I trust this plugin's web pages (我信任这个插件的网页)**.

- Approving a package also asks whether the page goes in the sidebar and whether **members can see it too (成员也能看到)**. Pages from the AI assistant are visible to administrators only at first.
- Change either later, or revoke consent, under Settings → Plugins → **Plugin web pages (插件网页)**. Local plugins in data/plugins.yaml are agreed to there with **Agree (同意)**.
- To take an entry out of your own sidebar, use Settings → Appearance → **Navigation order (导航顺序)**.
- The apps don't show plugin pages.

### More features and improvements

- **Lower memory use**: in our replay of a real NAS's traffic, memory after a busy spell dropped from about 1.4 GB to about 400 MB.
- **Site searches keep going when you leave**: leaving the search page or closing the tab no longer cancels sites that haven't answered. Searching the same thing again within 10 minutes usually shows those results without asking the sites again.
- **Apps find the server on their own more often**: the app versions above, Windows 0.1.1 and Mac transcoder 0.33.1 discover the server even with Jellyfin compatibility turned off; older apps still need it on. With Docker's bridge network (UDP port 7359 mapped, as in the default compose file), open MovieClaw once in a browser at its LAN address (such as http://192.168.1.10:3000) and the server remembers it to answer apps, Infuse included. The built-in feature **Jellyfin LAN discovery (Jellyfin 局域网发现)** is now called **LAN discovery (局域网发现)**.
- **Drive plugins can sign in with a form**: a drive plugin can ask for credentials such as a client ID and secret. When it does, signing in offers **Enter credentials (填写凭据)** next to the QR code and browser-extension options. No released plugin uses it yet.
- **UHD Blu-ray remuxes with Dolby Vision on Android**: on an Android TV or phone with HDR10 but no Dolby Vision, these films (Profile 7) needed a graphics card to transcode, and were refused without one. They now play in HDR10: the server repackages them without transcoding the picture.

### Fixed

- Under Settings → Network → Services through the proxy (走代理的服务), **Test (测试)** failed with "未知的服务标签" for Feishu push (飞书推送), MovieClaw Cloud and App push (App 推送).
- On some TVs that claim Dolby Digital support but stall on it, such as some Xiaomi TVs, a video could fail at every quality step. Once playback steps down, the audio is now converted to stereo.
- Plugin packages (.mcplugin) were greyed out in the file picker in iPhone browsers, and possibly on Android phones.
- Cloud drives (115 plugin):
  - Listing a large drive folder could get the account rate-limited.
  - .strm files in a drive-primary library were uploaded again and again, and one that got uploaded could lose its local file.
  - After deleting a library and creating a new one, imports could fail and some titles could play another title's drive file.
  - Freeing local copies left behind empty show and season folders.
  - Signing in again from an account card as a different drive user created a second account and left the expired one broken. It is now refused.
  - While an account was rate-limited, actions you started kept extending the wait. They are now refused with how many minutes are left; playback still tries.
- And 2 more fixes: a search right after renaming a title could come back empty, and library scans with many errors no longer bloat the database.

### Before you update

- This release migrates the database. To return to v0.40.0, use Settings → Update & Maintenance → **Roll back to an earlier version (回退到历史版本)**. It restores the backup taken before the update, so anything since is lost, including intros learned for automatic skipping. If you update by pulling the Docker image instead, no backup is made, so stop the container and back up the data directory first.

Thanks to @jasonhorga. Full changes: [v0.40.0 → v0.41.0](https://github.com/movieclaw/MovieClaw/compare/v0.40.0...v0.41.0).

## 简体中文

## v0.41.0：广告自己跳，页面自己做

播放器现在会自动跳过广告，也会记住你在哪些剧里跳过片头。插件（包括让 AI 助手帮你写的插件）可以把自己的页面放进侧边栏，服务器占用的内存也大幅减少。

> ✅ 不需要更新 Docker 镜像，在「设置 → 更新与维护」里一键更新即可。各 App 要自动跳过，请更新到 iPhone 与 iPad 0.9.2、Apple TV 0.9.2、Mac 0.9.2、Android 0.6.0 或 Android TV 0.5.0。

### 本版亮点

#### 广告自动跳，片头跳过一次就记住

以前认出来的广告和片头都要你一集一集地按「跳过」。现在广告和预告自动跳过，提示旁有几秒的「撤回」。在一部剧里手动跳过一次片头，这部剧以后就自动跳，提示旁的「不用」可以反悔；撤回一次自动跳过的片头，这部剧也不再自动跳。网页播放器和上面列出的各 App 升级后自动生效。

- 能跳过的段落在进度条上标成琥珀色。拖动或跳转到这些段落里，只给「跳过」按钮。
- 记住的剧跟着每个成员的账号走，换哪个 App 都一样。
- 没有关闭自动跳过的开关；每次自动跳过都可以撤回。
- 片尾和尚未分类的重复段不会自动跳过。分享链接里广告照跳，但不会记片头。
- 早于上面版本的 App 仍是手动跳过按钮。新版 App 连旧服务器时广告照跳，但不会记片头。

#### 侧边栏里有你自己的页面

以前插件能加功能，却加不了一个能看的页面。现在插件可以自带页面，在网页版 MovieClaw 里直接打开，放在侧边栏（手机浏览器里在「我的」页）。管理员也可以让 AI 助手做一个，比如「一个能看本周新入库 4K 片和正在下载任务的页面」：它会把页面做成插件，装之前先问你。页面以打开它的人的权限运行，所以每个都要经你同意：批准插件包时勾选「我信任这个插件的网页」。

- 批准插件包时还会问要不要加到侧边栏、「成员也能看到」。AI 助手做的页面一开始只有管理员能看到。
- 之后想改这两项或撤销同意，到「设置 → 插件 → 插件网页」。放在 data/plugins.yaml 里的本地插件，也是在这里点「同意」。
- 想把某一项从自己的侧边栏移走，到「设置 → 外观 → 导航顺序」。
- 各 App 里不显示插件页面。

### 其他新功能与改进

- **内存占用大幅降低**：在我们回放一台真实 NAS 请求的测试中，忙过一阵之后的内存从约 1.4 GB 降到约 400 MB。
- **离开页面，站点搜索照常进行**：离开搜索页或关掉标签页，还没回结果的站点不会再被取消。10 分钟内再搜同样的内容，通常直接显示这次的结果，不再重新问一遍站点。
- **App 更容易自动找到服务器**：关掉 Jellyfin 兼容后，上面版本的各 App、Windows 0.1.1 和 Mac 转码器 0.33.1 也能在局域网里找到服务器，更早的 App 仍要开着它。Docker 桥接网络下（需映射 UDP 7359 端口，默认的 compose 文件已带），用浏览器以局域网地址（如 http://192.168.1.10:3000）打开一次 MovieClaw，服务器就会记住这个地址并用它应答各 App 和 Infuse。内置功能「Jellyfin 局域网发现」改名为「局域网发现」。
- **网盘插件可以填表登录**：网盘插件可以要求填写 Client ID、密钥这类凭据，登录时会在「扫码登录」「用浏览器扩展」之外多出「填写凭据」。目前还没有发布的插件用到它。
- **安卓上的杜比视界原盘**：在支持 HDR10、不支持杜比视界的安卓电视或手机上，UHD 原盘 remux 里的杜比视界片子（Profile 7）以前要靠显卡转码，没有显卡就拒播。现在直接按 HDR10 播放：服务器换封装，画面不用转码。

### 修好了

- 「设置 → 网络 → 走代理的服务」里飞书推送、MovieClaw Cloud、App 推送三项点「测试」报「未知的服务标签」的问题已修复。
- 在一些声称支持杜比数字、实际播放会卡住的电视上（如部分小米电视），片子可能每一档画质都播不了。现在一旦降档，音频就转成双声道。
- 在 iPhone 的浏览器里选插件包（.mcplugin）时文件是灰的、选不了的问题已修复，安卓手机上可能也有同样的问题。
- 网盘（115 插件）：
  - 列出网盘上很大的文件夹时，账号可能被限流。
  - 主根在网盘的库里，.strm 文件被反复上传；传上去的还可能被删掉本地文件。
  - 删除一个库再新建后，入库可能失败，有的片子还会播成另一部片子的网盘文件。
  - 腾空本地副本后，留下空的剧集和季文件夹。
  - 从账号卡片重新登录时登进了另一个网盘用户，会悄悄多出一个账号，过期的那个还是坏的。现在会拒绝。
  - 账号被限流期间，你发起的操作会让等待越拖越长。现在会直接拒绝并提示还要等几分钟；播放仍会尝试。
- 以及 2 处细节修复：改名后马上搜索可能搜不到；出错很多的库扫描不会再让数据库膨胀。

### 升级须知

- 这一版会迁移数据库。要回到 v0.40.0，到「设置 → 更新与维护 → 回退到历史版本」，它会恢复更新前的自动备份，之后的改动都会丢失，包括自动跳过记住的片头。如果你是拉取 Docker 镜像更新的，不会自动备份，请先停止容器并备份数据目录。
