## v0.17.0：家里谁在看片，一屏就能看清

这一版把任务中心扩展为「活动」，新增实时观看视图。整季包只有集号时，也不再把各集散到错误的季目录。

✅ 已使用 v0.16.0 对应镜像的用户无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 正在播放、正在下载，都在活动页

侧栏进入「活动」，在「观看」里查看家人正在看的影片、播放进度、设备和取流速度。播放器离线下载单独列出，也能看最近观看；「任务」里继续管理后台作业。

#### 可疑设备，管理员可以当场注销

播放或下载卡片菜单新增「注销设备」，立即撤销该设备令牌并停止取流，成员的观看进度保留。本版可处理当前正在播放或下载的设备，其他旧设备暂未提供独立管理入口。

### 其他新功能与改进

- **侧栏会提示正在发生的事**：有播放或下载时显示实时圆点，需要处理的任务显示警示角标。
- **手机活动页更紧凑**：切换入口放进顶栏，进度条贴卡片底边。
- **刷流窄屏更好读**：表格和汇总重新排布，速度与体积更清楚。
- **旧书签继续可用**：`/tasks` 自动跳到 `/activity`，保留查询条件。

### 修好了

- 像 `E01…E36` 这样没写季号的整季包，会结合目录与剧集信息统一定季；拿不准时等待人工确认，避免乱放。
- 本地播放不再误标成网盘直链，离线下载也不再混入正在播放数量。
- 同一设备拖动、暂停恢复时，观看会话不再反复重建、时间闪回。
- 从任务视角打开活动页时，实时圆点也能正确显示。

### 升级须知

- 升级后，此前因季集判断挂起的入库记录会自动重新处理。

完整改动见 [v0.16.0 → v0.17.0](https://github.com/movieclaw/MovieClaw/compare/v0.16.0...v0.17.0)。
