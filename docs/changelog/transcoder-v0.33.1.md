## Mac transcoder 0.33.1: Finds your server more often

This is a small update: when you set up the transcoder, it finds your MovieClaw server on the network in more setups.

> ✅ Works with the same servers as 0.33.0; no server update is needed to keep transcoding. Download from https://movieclaw.io/en/download and replace the old app.

### More features and improvements

- **Finding the server during setup**: the server is listed even when its Jellyfin compatibility is off, and with Docker's bridge network once someone has opened MovieClaw in a browser at its LAN address. Both need Server 0.41.0. The address is still filled in for you to check before you connect and pair.

Full changes: [transcoder-v0.33.0 → transcoder-v0.33.1](https://github.com/movieclaw/MovieClaw/compare/transcoder-v0.33.0...transcoder-v0.33.1).

## 简体中文

## Mac 转码器 0.33.1：更容易找到服务器

这是一个小更新：设置转码器时，更多部署方式下能在局域网里找到你的 MovieClaw 服务器。

> ✅ 能搭配的服务器与 0.33.0 相同，继续转码不需要更新服务器。从 https://movieclaw.io/zh/download 下载，替换旧版 App。

### 其他新功能与改进

- **设置时找服务器**：服务器关掉 Jellyfin 兼容时也能列出来；Docker 桥接网络下，只要有人用浏览器以局域网地址打开过一次 MovieClaw，也能列出来。这两种都需要服务器 0.41.0。找到的地址仍然只填进输入框，由你确认后再连接并配对。

完整改动：[transcoder-v0.33.0 → transcoder-v0.33.1](https://github.com/movieclaw/MovieClaw/compare/transcoder-v0.33.0...transcoder-v0.33.1)。
