## Apple TV 0.11.0: Watch in your language

Browse and watch with an interface that follows your system language.

- The interface now supports Simplified Chinese and English, following the system language. Server 0.43.0 adds matching server messages.
- Rule groups can exclude Dolby Vision Profile 5 with **DV P5**, with Server 0.43.0.

The GitHub release contains release notes only. Installation requires the corresponding TestFlight build.

Full changes: [tvos-v0.10.0 → tvos-v0.11.0](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.10.0...tvos-v0.11.0).

## 简体中文

## Apple TV 0.11.0：用熟悉的语言看片

在电视上用熟悉的语言浏览和看片，界面随系统选择中文或英语。

- 界面新增英语，简体中文与英语跟随系统语言；服务器提示的对应语言需配合服务器 0.43.0。
- 规则组新增「DV P5」选项，可排除杜比视界 Profile 5，需配合服务器 0.43.0。

GitHub 发布页仅提供版本说明，安装仍需对应的 TestFlight 构建。

完整改动：[tvos-v0.10.0 → tvos-v0.11.0](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.10.0...tvos-v0.11.0)。
