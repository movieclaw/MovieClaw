## v0.36.0: Network drives play like local files, Android gets instant notifications

Titles on network drives (strm files) now play, transcode and show thumbnails just like files on your disk, and Android can receive notifications straight from your own server without Google or vendor push.

> ⚠️ **Update the Docker image**: This release needs a new image (it makes updates on slow machines more reliable). Pull `movieclaw/movieclaw:latest` and recreate the container; the in-app updater will ask for this until you do.

The Apple apps stay at **0.7.0**. Update Android to **0.3.0** and Android TV to **0.2.1**. No Mac transcoder update is required.

### Highlights

#### Network-drive titles no longer feel second-class

Titles added through strm files used to play only when the player could handle the original stream, with no seek thumbnails and sometimes no picture at all when the link only worked inside your network. They now remux and transcode like local files, get seek thumbnails, honour request headers written in the strm file, and links players can't reach are relayed by the server. Embedded subtitles also load without reading the whole file. The new official **Network-drive spec prefetch** plugin checks each title ahead of time, and jumps ahead to the next episodes when you start watching, so playback starts faster. It works automatically; administrators can tune or turn off the plugin in **Settings → Plugins**.

#### Android notifications that arrive right away

Android couldn't receive server push at all, because Google and vendor push need the developer's own credentials. Now the Android app keeps a direct connection to your own server: download finished, added to library and today's updates arrive within a second, and anything missed while offline is delivered once you reconnect. The persistent notification can show live download progress or your own text, and you choose which events to receive, shared with iPhone and the web. Turn it on in **Settings → Notifications → Realtime notifications (keep connected)** on Android; a step-by-step guide helps keep it running in the background on vivo, Xiaomi, OPPO and Huawei/Honor phones.

### More features and improvements

- **Plugins in any language**: Plugins can be written in Go and other languages, run background jobs shown in the task center, and talk to the AI assistant.
- **Official plugins are optional**: Official plugins can now be disabled, uninstalled and restored.
- **Season packs on Android**: Download rows show each episode's progress, and the activity page matches the iPhone.
- **New Android icon**: The launcher and notification icons use the new aurora mark.
- **Keep your model API key**: Leaving the API key blank when editing a model provider keeps the saved key.
- **Windows client preview**: A community Windows client now lives in the repository under `apps/desktop`; official downloads will come later.

### Fixed

- OpenAI models with a thinking level no longer fail with error 400 once the assistant uses tools; switch the API protocol under a provider's advanced settings.
- The Firefox browser extension no longer installs as "corrupt", and site cookies actually sync.
- Site checks now say "login expired" or "Cloudflare challenge" instead of blaming a site layout change.
- When direct play fails twice, playback falls back to hardware transcoding instead of asking for software transcoding.
- Libraries on a mergerfs pool (fnOS, Unraid, OMV) pick up new downloads right away instead of hours later.
- Completed season packs with deselected files are no longer treated as incomplete.
- Updating no longer leaves slow machines or customised databases stuck restarting on an old version.
- Plus more accurate intro and end-credit skipping, and a clear notice when a sideloaded iPhone app can't receive push.

### Before you update

- This release migrates the database. To return to v0.35.0 or earlier, restore the automatic pre-update backup.

Thanks to @WadeChenn for Android realtime notifications and many fixes, @anlan-home for the Android activity page, and @sexyfeifan for the Windows client.

## 简体中文

## v0.36.0：网盘片和本地片一样播，Android 通知即时到

网盘（strm）条目现在能像本地文件一样播放、转码、显示进度条缩略图；Android 不靠谷歌或厂商推送，直接从你自己的服务器收到通知。

> ⚠️ **需要更新 Docker 镜像**：本版需要新镜像（让慢机器上的更新更可靠）。请拉取 `movieclaw/movieclaw:latest` 并重建容器；更新前应用内更新会一直提示这一步。

Apple App 保持 **0.7.0**；Android 请更新到 **0.3.0**，Android TV 请更新到 **0.2.1**。本版无需更新 Mac 转码器。

### 本版亮点

#### 网盘里的片，不再低人一等

以前通过 strm 加进来的片，只有播放器吃得下原始码流才能播，没有进度条缩略图；直链只在内网能用时，外面甚至没画面。
现在它们和本地文件一样换封装、转码，有进度条缩略图，认 strm 里写的请求头，播放器连不上的直链由服务器转发；内封字幕也不用再通读整片。
新的官方插件「网盘规格预探」提前探好每部片的规格，开始看某集时优先探后面几集，起播更快。
升级后自动生效；管理员可在「设置 → 插件」调整或停用它。

#### Android 通知，即时送达

以前 Android 完全收不到服务器推送：谷歌和厂商推送都要开发者自己的凭证。现在 Android App 和你自己的服务器保持直连，下载完成、入库、今日更新一秒内送达，离线期间漏掉的重连后补发。
常驻通知可以显示实时下载进度或你自定义的文字；推哪些事可自选，和 iPhone、网页共用一份设置。
在 Android「设置 → 通知 → 实时通知（保持连接）」开启；vivo、小米、OPPO、华为荣耀手机有分步引导，帮你让它在后台常驻。

### 其他新功能与改进

- **插件不限语言**：插件可以用 Go 等语言写，能建后台任务（任务中心可见），还能调用 AI 助手。
- **官方插件可以不要**：官方插件现在可以停用、卸载，也能随时恢复。
- **Android 季包进度**：下载行显示每一集的进度；活动页与 iPhone 对齐。
- **Android 新图标**：启动器图标和通知图标换成新的极光标志。
- **模型密钥不用重填**：编辑模型供应商时 API Key 留空，沿用已保存的密钥。
- **Windows 客户端预览**：社区贡献的 Windows 客户端已收进仓库 `apps/desktop`，正式下载稍后提供。

### 修好了

- OpenAI 模型选了思考档位后，AI 助手一用工具就报 400 的问题已修复；可在供应商的高级设置里切换 API 协议。
- Firefox 浏览器扩展不再提示「已损坏」，站点 Cookie 也能真正同步。
- 站点验证会明确提示「登录过期」或「Cloudflare 质询」，不再误报站点改版。
- 直通播放连续失败两次后改走硬件转码，不再直接要求软件转码。
- 媒体库放在 mergerfs 合并盘（飞牛、Unraid、OMV）上时，新下载能立即入库，不用等几个小时。
- 部分文件未勾选的季包下载完成后，不再被当成没下完。
- 慢机器或改过数据库的实例，更新后不再卡在旧版本反复重启。
- 以及片头片尾跳过更准；侧载的 iPhone App 收不到推送时会明确说明。

### 升级须知

- 本版升级了数据库。如需回退到 v0.35.0 或更早版本，请用更新前自动生成的备份恢复。
