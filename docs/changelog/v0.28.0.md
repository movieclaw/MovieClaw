## v0.28.0: MovieClaw comes to iPhone

An early native iOS app brings libraries, subscriptions and playback to iPhone. The Mac transcoder gets a major update, and every signed-in device can be managed in one place.

> ⚠️ **Mac transcoder users: Download its new version from this Release.** Older versions cannot take disc or Infuse transcoding jobs, which fall back to server transcoding or original-file playback.
> ✅ No Docker image update is required. Update from **Settings → Update & Maintenance**.

### Highlights

#### Watch your library in a native iPhone app

Instead of relying on the mobile website, use the built-in native player for 4K HDR and Blu-ray disc playback, resume and responsive seeking. Download `MovieClaw-iOS-unsigned.ipa` from this Release and install it with your Apple ID using AltStore, SideStore or Sideloadly. iOS 26 or later is required. Configure trackers and downloaders on the web; public TestFlight testing will open later.

#### A Mac transcoder that opens with a double-click

The transcoder has a status panel showing the current title, launch-at-login support and automatic error recovery. It handles Blu-ray discs and other sources, with GPU processing for HDR and Dolby Vision. The package is notarized by Apple and can be opened after downloading.

#### See who is signed in to your account

Settings → Devices lists browsers, apps, command-line clients and transcoders connected to your account. Sign out anything unfamiliar and approve CLI or transcoder pairing codes here. Each member can manage their own devices.

### More features and improvements

- **A richer subscription home**: Title logos, backdrops, weekly update schedules and just-imported titles.
- **Automatic subscription rules**: Set applicability in Settings → Subscription Rules to choose by movie or series and region.
- **Different themes for desktop and mobile**: Select them separately in Appearance settings.
- **Clear playback modes in Activity**: Show direct play, remuxing or transcoding, including the machine doing the work.
- **Remove leftover boosting torrents**: Clean them up when disabling boosting or later from Activity.
- **Faster playback and subscriptions**: Improved resume startup, subscription creation and home loading.

### Fixed

- Infuse playback through a remote transcoder no longer repeatedly fails.
- Newer Jellyfin-compatible clients such as Findroid and Swiftfin can connect instead of rejecting the server as too old.
- Docker automatic discovery uses the configured external access URL rather than advertising an unreachable address.
- Corrected scheduled-task switches in Chrome and mobile subscription-rule layouts.

### Before you update

- This release migrates the database. To return to v0.27.0 or earlier, restore the automatic pre-update backup.
- The project adopts the MovieClaw license, Apache-2.0 with an additional non-commercial condition. Personal and family use is unaffected.

Thanks to @duchanghexuhe for their contributions.

## 简体中文

## v0.28.0：MovieClaw 有了 iPhone App

原生 iOS App 先行版来了，片库、订阅、播放都能在 iPhone 上用原生方式完成。这一版
还给 Mac 转码器做了一次大改，并让你能在一处看清、管好每台登录过的设备。

> ⚠️ **用 Mac 转码器的，请到本版 Release 下载新版替换**：旧版接不了原盘和 Infuse
> 的转码任务，会退回服务器自己转或直接播原文件。
> ✅ 本版无需更新 Docker 镜像，在「设置 → 更新与维护」一键更新即可。

### 本版亮点

#### 在 iPhone 上用原生 App 看自己的片库

以前在手机上只能开网页，大片、原盘常常放不了或要转码。现在有了原生 App：自带播放器，
4K HDR、蓝光原盘直接放，续播、拖进度条都跟手。从本版 Release 下载
`MovieClaw-iOS-unsigned.ipa`，用 AltStore、SideStore 或 Sideloadly 以自己的 Apple ID
安装（需 iOS 26 及以上）。资源站点、下载器仍在网页端配置；TestFlight 公开测试稍后开放。

#### Mac 转码器：双击就能打开，原盘也能转

Mac 转码器换成一块状态面板：看得到正在转哪部片，能开机自启、出错自动恢复。蓝光原盘和
各种片源都能直接转，HDR、杜比视界交给显卡处理。安装包已通过 Apple 公证，下载后双击即可打开。

#### 一处看清谁登录着你的账号

「设置 → 设备」列出登录着你账号的浏览器、App、命令行和转码器，不认识的一键注销；
命令行和转码器也改为在这里按配对码批准。每位成员都能管理自己的设备。

### 其他新功能与改进

- **订阅首页更好看**：片名 Logo、剧照、一周更新日程和「刚刚入库」都有了。
- **订阅自动选规则组**：在「设置 → 订阅规则」设好适用范围，按电影 / 剧集、地区自动选。
- **电脑和手机可以用不同主题**：在「设置 → 外观」分别选择。
- **活动页看得出怎么在播**：标明直连、重封装还是转码，转码时显示在哪台机器上转。
- **关掉刷流后残留的种子可以清理**：关闭时或事后在活动页都能清。
- **起播、订阅都更快**：续播起播更快，新建订阅不再卡几秒，首页打开更快。

### 修好了

- 用 Infuse 看片、经远程转码器转码时总是失败，现在正常了。
- Findroid、Swiftfin 等新版 Jellyfin 客户端嫌服务器太旧、拒绝连接，现在能连了。
- Docker 部署时 Jellyfin 客户端自动发现到的地址连不上，现在改用你填的外部访问地址。
- 以及定时任务开关在 Chrome 里错位、订阅规则页在手机上变形等细节修复。

- 本版起项目改用 MovieClaw 许可证（Apache-2.0 附加非商业条件），个人和家庭自用不受影响。

感谢 @duchanghexuhe 的贡献。完整改动见 [v0.27.0 → v0.28.0](https://github.com/movieclaw/movieclaw/compare/v0.27.0...v0.28.0)。
