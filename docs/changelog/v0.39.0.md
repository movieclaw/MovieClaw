## v0.39.0: Bring your ChatGPT plan, and let the AI look things up

The AI assistant can now run on your ChatGPT Plus or Pro subscription instead of an API key, and it can search the web for things your library doesn't know. Finished downloads also show up in the library right away again.

> ⚠️ **Update the Docker image**: Stop the container and back up the data directory, then run `docker compose pull && docker compose up -d`. In-app update cannot install this version; it shows that a new Docker image is required.

### Highlights

#### Already paying for ChatGPT? Use it here

Until now the AI assistant needed an OpenAI API key, billed separately from your ChatGPT subscription. Now an administrator can connect a ChatGPT Plus or Pro plan and pick its models for chats and subtitles, sharing the plan's usage with your other apps. Start at Settings → Model Providers → add a provider → **ChatGPT 订阅 (ChatGPT subscription)**, then follow the page.

- This is a preview. Signing in happens on a computer: install this version's `mclaw`, pair it with `mclaw login`, then run the copied `mclaw llm chatgpt login` command and approve in the browser.
- The web page can wait for the result and shows the connected account's email. Reconnecting or removing the plan is also done on the web.
- Each ChatGPT account is its own provider. Removing one tries to revoke access on OpenAI's side; if that can't be confirmed, the page tells you to disconnect the app in ChatGPT settings.
- Manage usage at https://chatgpt.com/settings/usage. When the plan runs out, replies stop with a "may have reached your subscription limit" message.

#### Ask about things your library doesn't know

The assistant could only answer from your library and TMDB, so news, reviews or release rumours were out of reach. Connect Tavily, Exa or Brave Search and it can search the web, citing titles and links. Go to Settings → AI Settings → **Web search (网页搜索)**, pick a service, paste its key and press **Verify and save (验证并保存)**.

- Nothing changes until you connect a service: without one, the assistant has no search tool.
- The key is saved only after a test search passes, and each save uses one search from your quota.
- These services are usually abroad. Searches don't use your proxy by default; turn it on for **Web search (网页搜索)** under Settings → Network if needed.
- iPhone 0.9.0 or later has the same section under AI Settings.

### More features and improvements

- **Blu-ray on Android plays straight from the disc**: With Android 0.4.0 or Android TV 0.3.0, Blu-ray folders and ISOs play on the device with every audio track, lossless TrueHD and DTS-HD MA, and PGS subtitles. The server no longer converts them. DVDs and VC-1 discs still go through the server.
- **One assistant everywhere**: Chats over WeChat, Telegram and other messaging channels now get the same assistant as the web, with skills and web search, and no longer stop after 40 steps. Only media cards stay web-only.
- **The assistant knows who's talking**: it is told your nickname, and its personality has been rewritten to be more direct and to try things itself before asking.
- **A companion while you wait**: Xiaomu (小幕), a small moonlit cat, sits by the chat box on the web and in iPhone 0.9.0 and reacts while a task runs. It stays still when motion is reduced.
- **Cloud-drive strm in watch folders**: Watched download folders now organize strm files into the library like videos instead of skipping them as "no video file". Items skipped by an earlier version are retried once after the update.
- **Safer logs**: cloud-drive link secrets (such as `pickcode` and signatures) and passwords inside URLs are masked in logs.

### Fixed

- With live monitoring on, files downloaded straight into a library folder could stay out of the library until a manual scan. They now usually appear within seconds of finishing.
- Some films marked Dolby Vision but carrying an HDR10 picture (often "DV HDR10+ Hybrid" releases) played purple or green in the Apple apps. Older apps now get a correct HDR10 stream from the server; titles already in the library are corrected at startup.
- Dolby Vision Profile 5 titles no longer lose Dolby Vision on Android Dolby Vision devices when the audio has to be converted, and no longer turn purple when an Intel or AMD GPU converts them while a Mac transcoder is online.
- Some HDR TS recordings made the Mac transcoder fail when converting.
- The MCP endpoint copied from Settings now works on Docker installs instead of returning 404. Thanks to @zkl2333.

### For administrators

- Messaging-channel chats can now run commands and edit files in the assistant's workspace on the server, as web chats already could. Keep the linked messaging account as safe as your admin login.

### Before you update

- The assistant no longer adds clickable links to MovieClaw pages in its replies.
- Known issue: on a server with only an Intel GPU and no Mac transcoder, converting a true Dolby Vision Profile 5 title still looks purple.

Thanks to @o1xhack and @zkl2333. Full changes: [v0.38.0 → v0.39.0](https://github.com/movieclaw/MovieClaw/compare/v0.38.0...v0.39.0).

## 简体中文

## v0.39.0：用上你的 ChatGPT 订阅，AI 也能上网查了

AI 助手现在可以直接用你的 ChatGPT Plus / Pro 订阅，不必另买 API Key；还能上网搜索片库里查不到的信息。下载完成的文件也会马上出现在媒体库里了。

> ⚠️ **需要更新 Docker 镜像**：先停止容器并备份数据目录，再执行 `docker compose pull && docker compose up -d`。应用内更新装不了这一版，会提示需要拉取新的 Docker 镜像。

### 本版亮点

#### 已经在付 ChatGPT 的钱？直接拿来用

以前 AI 助手只能用 OpenAI 的 API Key，和 ChatGPT 订阅分开计费。现在管理员可以接入 ChatGPT Plus 或 Pro 订阅，对话和字幕都能选它的模型，额度与你其他用这个订阅的 App 共享。从「设置 → 模型接入 → 添加供应商 →「ChatGPT 订阅」」开始，按页面提示操作。

- 这是预览功能。授权在电脑上完成：装好这一版的 `mclaw`，用 `mclaw login` 配对服务器，再执行页面上复制的 `mclaw llm chatgpt login`，在浏览器里允许授权。
- 网页可以等待授权结果，连上后显示账号邮箱。重新授权和移除也在网页上操作。
- 每个 ChatGPT 账号是一个独立的供应商。移除时会尝试在 OpenAI 那边撤销授权；没能确认时，页面会提示你到 ChatGPT 设置里断开这个 App。
- 用量在 https://chatgpt.com/settings/usage 查看。订阅额度用完时，回复会停下并提示「可能已达到订阅额度」。

#### 片库里查不到的，也能问

以前助手只能根据你的片库和 TMDB 回答，新闻、口碑、上映传闻都查不到。现在接入 Tavily、Exa 或 Brave Search 后，它可以上网搜索，并给出来源标题和链接。到「设置 → AI 设定 → 网页搜索」，选一家服务、粘贴 Key，点「验证并保存」。

- 不接入就什么都不变：没有搜索服务时，助手没有搜索工具。
- 先用这把 Key 搜一次，通过了才保存；每次保存会用掉一次搜索额度。
- 这些服务多在海外。搜索默认不走代理，需要时到「设置 → 网络」为「网页搜索」打开代理。
- iPhone 0.9.0 或更新版本的「AI 设定」里也有同样的设置。

### 其他新功能与改进

- **安卓直接播蓝光原盘**：用 Android 0.4.0 或 Android TV 0.3.0，蓝光目录和蓝光 ISO 在设备上直接播放，所有音轨都能切换，TrueHD、DTS-HD MA 无损解码，PGS 字幕也能显示，服务器不再为它们转换。DVD 和 VC-1 原盘仍由服务器处理。
- **各处是同一个助手**：微信、Telegram 等消息渠道里的对话，现在和网页用同一个助手，技能、网页搜索都有，也不会再跑到 40 步就停下，只有媒体卡片仍只在网页显示。
- **助手知道是谁在说话**：它会知道你的昵称；性格描述也重写了，更直接，先自己想办法再问你。
- **等待时有个伴**：网页和 iPhone 0.9.0 的对话框旁多了一只月夜小猫「小幕」，任务进行时会有动作。系统开启「减少动态效果」时它保持静止。
- **监听导入支持网盘 strm**：监听的下载目录里的 strm 文件，现在会和视频一样整理进媒体库，不会再被当成「没有视频文件」跳过。旧版跳过的条目，升级后会自动重试一次。
- **日志更安全**：网盘直链里的密钥（如 `pickcode`、签名）和地址里的账号密码，在日志里会被遮住。

### 修好了

- 开启实时监控时，直接下载进媒体库目录的文件，有时要手动扫描才入库的问题已修复，现在通常下完几秒内就会出现。
- 部分标着杜比视界、实际是 HDR10 画面的片子（常见于「DV HDR10+ Hybrid」版本），在 Apple 各端整片偏紫或偏绿的问题已修复。旧版 App 会由服务器改给颜色正确的 HDR10 流；已入库的片子启动时自动更正。
- 杜比视界 P5 的片子在安卓杜比视界设备上需要转音轨时，不会再丢掉杜比视界；Mac 转码器在线时，也不会再被 Intel 或 AMD 显卡转成偏紫的画面。
- 部分 HDR 的 TS 录像在 Mac 转码器上转码失败的问题已修复。
- 在 Docker 部署下，设置里复制的 MCP 端点地址返回 404 的问题已修复。感谢 @zkl2333。

### 管理员须知

- 通过消息渠道和助手对话，现在也能在服务器上执行命令、读写助手工作区里的文件，和网页对话一样。请像保护管理员登录一样保护绑定的消息账号。

### 升级须知

- 助手的回复里不再附带 MovieClaw 页面的可点击链接。
- 已知问题：只有 Intel 核显、又没有 Mac 转码器的服务器，转码真正的杜比视界 P5 片子时画面仍会偏紫。
