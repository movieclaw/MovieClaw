## v0.24.0：系列电影聚成合集，追剧知道接着看哪集

这一版带来自动、手动与跨库合集，首页改为「接下来继续」。NAS 上浏览详情更省读盘，订阅和洗版卡住的问题也修了一批。

✅ 已使用 v0.23.0 对应镜像的用户无需更新 Docker 镜像，在「设置 → 更新与维护」一键更新即可。

### 本版亮点

#### 系列电影自动聚在一起，也能自己建片单

同系列作品会自动组成合集，并显示还缺哪些片；旧片库会在后台补齐。也能手动挑片、跨库组合集、排序和分享，不想显示的合集可以隐藏再恢复。

#### 下一次开播，直接找到该看的那集

首页「接下来继续」从观看位置出发，找出文件仍在、还没看完的下一集。收藏里没看完的排在前面，播放也不再改变收藏时间。

#### 换盘、合并库，一次搬一批

后端和 mclaw 支持批量转移、合并媒体库根路径。先预检空间、同盘与跨盘代价和重名冲突，失败后可以从检查点继续；源目录没搬干净前不会移除原根路径。

### 其他新功能与改进

- **NAS 浏览少反复读盘**：字幕、图片按目录缓存，NFO 在入库时吸收，打开详情不再重复解析磁盘文件。
- **订阅搜索更完整**：同时用英文名、中文名和原名查找，避免第一个词有结果就停止。
- **预览图生成可关闭**：「设置 → 播放」新增进度条预览开关，已生成的图片仍可使用。
- **成员分级覆盖播放**：列表中受限制的内容，拿到直链也不能绕过限制播放。
- **拖进度更跟手**：高频拖动减少多余绘制，进度把手不再超出控制条边缘。

### 修好了

- 分集名称和简介不再被自己写出的旧 NFO 冻结，用户提供的 NFO 也不会被静默覆盖或忽略。
- 体积离谱的假正片会在自动选种时拦下，避免把预告片当整部电影下载。
- 删除后重新订阅同一个种子，不再永远卡在「已投递」。
- 同目录的单集种子不会再错记来源，已经卡住的洗版任务会在后续巡检中收尾。
- 远距离跳转后，进度条和时间不再各自显示不同位置，取流速度读数也更准确。
- 多个 AI 会话同时输出时，侧栏不再反复抢着重排。

### 升级须知

- 批量转移与根路径归并目前通过后端和 mclaw 使用，网页尚未提供入口。
- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.23.0 → v0.24.0](https://github.com/movieclaw/MovieClaw/compare/v0.23.0...v0.24.0)。
