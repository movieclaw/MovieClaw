## v0.43.0: Choose your language, and let your GPU do more

Choose Chinese or English on the Web, use hardware HEVC where supported, and control long subscriptions in smaller batches.

> This update requires a new Docker image (runtime 24). Stop the container and back up the data directory before upgrading. To roll back, restore that backup together with the previous image.

- Web now supports Simplified Chinese and English. Choose **Appearance and language** in Settings; your account remembers the choice. Existing metadata language preferences stay unchanged; first-time setup chooses defaults from the setup language.
- Compatible clients can receive HEVC from a tested NAS hardware encoder. Offline exports can also use HEVC; H.264 remains the fallback.
- Limit very long subscriptions to an initial batch, or follow the latest episodes of an ongoing season. Rule groups can exclude Dolby Vision Profile 5 with **DV P5**.
- Plugin capability links now open the relevant task or notification row. Plugin details include download counts and a feedback link; compatible plugins can exchange viewing state.
- Improved playback display controls, episode-version selection and VAAPI full-range playback. Unidentifiable files stay pending instead of retrying hourly. Updated Web dependencies, including Next.js 15.5.28.

Apple interface language support requires the 0.11.0 apps. Android automatic address switching and the new offline experience require Android 0.8.0. Android, Android TV, Windows and HarmonyOS interfaces are not fully translated in this release.

Full changes: [v0.42.0 → v0.43.0](https://github.com/movieclaw/MovieClaw/compare/v0.42.0...v0.43.0).

## v0.43.0：中文与英语，更好地用上显卡

网页可选中文或英语，兼容设备可用显卡输出 HEVC，长剧也能分批订阅。

> 本次需要更新 Docker 镜像（runtime 24）。升级前先停止容器、备份数据目录；需要回退时，将旧版镜像与这份备份一起恢复。

- **网页可以选语言了**：支持简体中文和英语，在「设置 → 外观与语言」切换，按账号记住。已有的刮削语言设置保持不变；首次初始化会按当时的界面语言选择默认值。
- **让显卡做更多事**：通过自检的 NAS 显卡可为兼容客户端输出 HEVC，离线导出也可使用 HEVC，并保留 H.264 回退。
- **长剧按需追**：可以先订一批，再继续订阅；在播长剧可追最新几集。规则组新增「DV P5」选项，可排除杜比视界 Profile 5。
- **插件入口更直接**：从能力表直达对应任务或通知行；详情可看下载量与反馈入口，兼容插件可以同步观看状态。
- 改进画面显示控制、连续播放时的版本选择与 VAAPI 全范围视频播放；无法识别的文件留在待处理，不再每小时重试。更新网页依赖，包括 Next.js 15.5.28。

Apple 界面语言支持需配合 0.11.0；Android 自动切换地址和新版离线体验需 0.8.0。Android、Android TV、Windows、鸿蒙界面本次尚未完整英文化。

完整改动：[v0.42.0 → v0.43.0](https://github.com/movieclaw/MovieClaw/compare/v0.42.0...v0.43.0)。
