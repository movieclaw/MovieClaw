## Mac 0.14.0: Follow a local actor into the library

Cast cards in local and NFO libraries can now open every title by that actor in the same library, even when no online person page exists.

> ✅ Works with MovieClaw Server 0.31.0 or later, the same as 0.13.0. The new actor-filtered wall requires Server 0.48.0 or later. Download from https://movieclaw.io/en/download and replace the old app. The direct-download edition updates itself.

### Highlights

#### Turn an actor card into a library view

On an item detail page, select an actor who has no online person page. Mac opens that same library with **Actor: Name** under its title; use the remove action in the library menu to return to all titles. Actors with an online person page still open that page, and directors without one remain static.

Thanks to @Migflyway. Full changes: [macos-v0.13.0 → macos-v0.14.0](https://github.com/movieclaw/MovieClaw/compare/macos-v0.13.0...macos-v0.14.0).

## 简体中文

## Mac 0.14.0：从本地演员找到同库作品

本地库和 NFO 库里的演员卡现在也能打开这位演员在同一媒体库中的全部作品，不再依赖在线影人页。

> ✅ 搭配 MovieClaw 服务器 0.31.0 或更新版本即可使用，与 0.13.0 相同。新的演员筛选海报墙需要服务器 0.48.0 或更新版本。从 https://movieclaw.io/zh/download 下载并替换旧版 App。官网直装版会自己更新。

### 本版亮点

#### 把演员卡变成同库作品墙

在条目详情页点没有在线影人页的演员，Mac 会打开同一媒体库，并在库名下显示「演员：姓名」。从媒体库菜单移除这项条件即可回到整库。带在线影人页的演员仍进入影人页；没有影人页的导演仍不可点。

感谢 @Migflyway。完整改动：[macos-v0.13.0 → macos-v0.14.0](https://github.com/movieclaw/MovieClaw/compare/macos-v0.13.0...macos-v0.14.0)。
