## v0.27.0: Watch comfortably when you are away from home

Lowering quality in Infuse or VidHub now genuinely reduces the stream bitrate. Mobile gets a floating glass navigation bar, and movie bundles can import every film in a folder.

> ⚠️ **A Docker image update is required.** Run `docker pull movieclaw/movieclaw:latest` and recreate the container. This image fixes an underlying component issue that could prevent data from being saved. The fix is only in the new image; Update & Maintenance will ask you to upgrade the image first.

### Highlights

#### Lower quality in Infuse now makes a difference

Previously, choosing lower quality in Infuse or VidHub still sent the original file, leaving mobile data or hotel Wi-Fi struggling. MovieClaw now transcodes to the requested bitrate while retaining subtitles. Select quality as usual in the player; the server needs available hardware acceleration or permission to use software transcoding.

#### A floating glass navigation bar on mobile

The Silver Glass theme keeps Discover, Library and Subscriptions in a floating bottom capsule instead of hiding them behind the menu. Hold and slide to switch; it contracts while scrolling to leave more room for content. This takes effect after updating.

#### Import every film in a bundled folder

Series bundles with multiple films in one folder previously kept only the largest file. Each film is now identified and imported separately. Previously missed films are recovered automatically after upgrading.

### Other new features

- **Custom library covers**: Upload artwork when editing a library; Infuse can display it too.
- **Feishu notifications**: Paste a group bot's Webhook URL into Settings → Notifications.

### Improvements

- **Faster HEVC MP4 startup in Safari** on iPhone and Mac.
- **TMDB mirror addresses accept a domain alone**, without requiring a specific path.
- **Unexpected-exit notices can be dismissed** in settings.
- **More consistent Netflix styling** across page spacing, buttons and colors.

### Fixed

- Generating AI subtitles for large files from mobile no longer fails; closing the dialog lets the job continue in the background.
- Subtitle processing handed to the Agent retains your language and bilingual selections.
- Posters and stills display correctly on Windows deployments.
- Corrected detail-page background flashing and several mobile display issues.

### Before you update

- This release migrates the database. To return to v0.26.0 or earlier, restore the automatic pre-update backup.
- Known limitation: Lower-quality disc playback in Infuse may still fail. VidHub has not been fully verified.

Thanks to @jasonhorga, @duchanghexuhe for their contributions.

Full changes: [v0.26.0 → v0.27.0](https://github.com/movieclaw/movieclaw/compare/v0.26.0...v0.27.0).

## 简体中文

## v0.27.0：出门在外，也能流畅看片

用 Infuse、VidHub 在外面看自己的片库，终于能真的「调低画质」了。这一版还给手机网页
换上了液态玻璃底栏，一个文件夹里装着好几部电影的合集，也能一部不落地入库。

> ⚠️ **本版需要更新 Docker 镜像**：执行 `docker pull movieclaw/movieclaw:latest`
> 后重建容器。本版修正了一个会导致数据无法保存的底层组件问题，只有新镜像带着这个
> 修正；不更新镜像的话，「设置 → 更新与维护」会提示你先升级镜像。

### 本版亮点

#### 在外面用 Infuse 看片，调低画质真的有用了

以前在 Infuse、VidHub 里选了低画质，服务器其实还在传原文件，用手机流量或酒店 Wi-Fi
看大片照样转圈。现在客户端要多低的码率，movieclaw 就实时转成多低，字幕照常显示。
在播放器里照常选清晰度就行（需要服务器有可用的显卡，或已允许软件转码）。

#### 手机网页换上液态玻璃底栏

用手机打开银玻璃主题，不用再点左上角 ☰ 找菜单：发现、媒体库、订阅常驻在底部一条
悬浮的玻璃胶囊里，按住就能滑动切换，往下滚时自动收起、把画面让出来。升级后自动生效。

#### 一个文件夹装好几部电影？现在逐部入库

系列合集、打包下载的文件夹，以前只会收进最大的那一部，其余悄悄丢掉。现在每部都会
单独识别入库，**以前漏掉的也会在升级后自动补回来**，不用你动手。

### 其他新功能

- **媒体库自定义封面**：编辑媒体库时多了「封面」一栏，传一张喜欢的图，Infuse 里也看得到。
- **飞书推送**：在「设置 → 消息推送」贴上飞书群机器人的 Webhook 地址就能用。

### 体验改进

- **Safari 播放 HEVC 的 MP4 起播更快**：iPhone、Mac 上不用再干等十几秒。
- **TMDB 镜像地址只填域名也能用**，不用再纠结后面要不要加路径。
- **「异常退出」提醒可以手动关掉**，不会一直挂在设置页。
- **Netflix 主题更统一**：各页面的边距、按钮和配色对齐了。

### 修好了

- 在手机上给十几 GB 的大文件生成 AI 字幕，不会再报错失败；关掉对话框也会在后台完成。
- 「交给 Agent 处理」字幕时，你选的语言和双语设置不会再丢。
- Windows 上部署时海报、剧照显示不出来，现在正常了。
- 以及详情页背景闪烁、手机端若干显示问题等细节修复。

### 升级须知

- 本版升级了数据库。之后如需回退到 v0.26.0 或更早版本，请用更新前自动生成的备份恢复。
- 已知限制：Infuse 播放原盘时调低画质可能仍会失败；VidHub 尚未完整验证。

感谢 @jasonhorga、@duchanghexuhe 的贡献。完整改动见
[v0.26.0 → v0.27.0](https://github.com/movieclaw/movieclaw/compare/v0.26.0...v0.27.0)。
