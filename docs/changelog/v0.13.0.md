## v0.13.0：喜欢这位演员，再看看他演过什么

这一版能从演员、导演进入完整作品页。新入库的剧集会说明这次添了哪几集，影片详情与文件信息也更好读了。

✅ 已使用 v0.10.0 对应镜像的用户无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 从一位演员，找到下一部想看的片

在发现页电影或剧集详情里点击演员、导演，可以浏览其 TMDB 影视履历。作品会标明是否已入库、已订阅，也能继续打开详情并发起订阅。

#### 最近添加，说清这次新来了什么

剧集入库会记录本轮批次，首页展示这次新增的季、集数或连续集号，不再把整部剧的累计库存当成刚添加的内容。旧记录没有批次信息时，仍显示入库时间。

### 其他新功能与改进

- **比较文件更直观**：详情补上帧率和色彩空间，多版本影片可切换文件查看音轨、字幕与视频参数。
- **详情页更统一**：发现页和媒体库使用一致的信息层级，简介只在超长时提供展开。
- **海报信息更清爽**：首页保留片名年份，新增集数和入库时间移到悬停信息。
- **音轨字幕更紧凑**：摘要用标签展示，完整规格在详情里查看。
- **画质标签更准确**：1080p 不再写成 2K，HDR 和色彩空间优先显示明确格式。

### 修好了

- 恢复滚动位置或跨字母区域后，字母索引高亮不再错位。
- 已订阅海报不再重复提供不适用的订阅或补齐操作。
- 恢复 ffprobe 后，主动整库扫描能补齐历史文件的视频参数。

### 升级须知

- 升级不会自动探测所有历史视频；需要帧率、色彩空间等信息时，请主动扫描一次媒体库。
- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.12.0 → v0.13.0](https://github.com/movieclaw/MovieClaw/compare/v0.12.0...v0.13.0)。
