## Apple TV 0.12.6: Read every synopsis in full

A truncated synopsis on a detail page can now take focus and open a full-screen reading view. Episode synopses get the same view from the long-press menu, and playback gains several reliability fixes.

> ✅ Works with MovieClaw Server 0.28.0 or later, the same as 0.12.4. Install the corresponding TestFlight build. This GitHub release contains notes only.

### Highlights

#### Open the full synopsis with the remote

When the main synopsis is longer than three lines, move focus to it and press select to open **Full Overview**. The full text uses a centered, larger reading column; use Up and Down when it is longer than one screen. Press Back to return focus to the synopsis. A short synopsis stays ordinary text and does not add another focus stop.

Long-press an episode and choose **Full Overview** to read an episode synopsis beyond its four-line preview. Closing the view returns focus to that episode card.

### Fixed

- Playback is more reliable after long sessions, when rewinding image subtitles, and after seeking with AirPlay.

The GitHub release contains release notes only. Installation requires the corresponding TestFlight build.

Full changes: [tvos-v0.12.4 → tvos-v0.12.6](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.12.4...tvos-v0.12.6).

## 简体中文

## Apple TV 0.12.6：每一段简介都能看完整

详情页里被截断的简介现在可以接住焦点，并打开全屏阅读页。分集简介也能从长按菜单打开同一套阅读页；播放还修正了几处可靠性问题。

> ✅ 搭配 MovieClaw 服务器 0.28.0 或更新版本即可使用，与 0.12.4 相同。请安装对应的 TestFlight 构建。这个 GitHub Release 只有说明。

### 本版亮点

#### 用遥控器打开完整简介

首屏简介超过三行时，把焦点移到简介上并按确认，就能打开「完整简介」。全文以更大的字号居中排列；超过一屏时用上下键滚动。按返回键后，焦点回到简介。没有被截断的短简介仍是普通文字，不会多出一个焦点停靠点。

长按一张分集卡，再选「完整简介」，可以阅读超过四行预览的分集简介。关掉阅读页后，焦点会回到那张分集卡。

### 修好了

- 长时间观看、往回拖动图形字幕，以及 AirPlay 拖动进度后的播放更可靠。

这个 GitHub Release 只有更新说明；安装需要对应的 TestFlight 构建。

完整改动：[tvos-v0.12.4 → tvos-v0.12.6](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.12.4...tvos-v0.12.6)。
