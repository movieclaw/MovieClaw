## Windows 0.1.1: Finds your server more often

This is a small update: **LAN discovery (局域网发现)** on the connect screen finds your MovieClaw server in more setups.

> ✅ Same server requirements as 0.1.0. The app offers this update itself, or download it from https://github.com/movieclaw/MovieClaw/releases/tag/windows-v0.1.1.

### More features and improvements

- **Finding the server**: the server is listed even when its Jellyfin compatibility is off, and with Docker's bridge network once someone has opened MovieClaw in a browser at its LAN address. Both need Server 0.41.0. Older servers are still found as before.

Full changes: [windows-v0.1.0 → windows-v0.1.1](https://github.com/movieclaw/MovieClaw/compare/windows-v0.1.0...windows-v0.1.1).

## 简体中文

## Windows 0.1.1：更容易找到服务器

这是一个小更新：连接页的「局域网发现」在更多部署方式下能找到你的 MovieClaw 服务器。

> ✅ 对服务器的要求与 0.1.0 相同。App 会自己提示这次更新，也可以从 https://github.com/movieclaw/MovieClaw/releases/tag/windows-v0.1.1 下载。

### 其他新功能与改进

- **找服务器**：服务器关掉 Jellyfin 兼容时也能列出来；Docker 桥接网络下，只要有人用浏览器以局域网地址打开过一次 MovieClaw，也能列出来。这两种都需要服务器 0.41.0。旧版服务器照常能找到。

完整改动：[windows-v0.1.0 → windows-v0.1.1](https://github.com/movieclaw/MovieClaw/compare/windows-v0.1.0...windows-v0.1.1)。
