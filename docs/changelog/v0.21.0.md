## v0.21.0: Ask for a film, and open it from the reply

Web AI conversations display media cards, while WeChat, Telegram and Discord accept images for the assistant. Update checks and messaging connection errors are clearer.

✅ If you already use the image for v0.19.0, no Docker image update is required. Update from **Settings → Update & Maintenance**.

### Highlights

#### Open recommended titles directly from the conversation

Questions about your library or what to watch can produce library covers, posters, playback cards and subscription cards in web replies. Ratings, inventory and subscription progress load live, with direct actions to open details or subscribe.

#### Send a picture and keep talking in your messaging app

WeChat, Telegram and Discord support posters, screenshots and error images. A picture followed promptly by text is combined into one turn, with up to four images. Unsupported models and image-processing failures explain the problem and retain content for retry.

### Fixed

- Update checks distinguish GitHub timeouts, connection failures and exhausted quotas, and identify direct or proxied access instead of reporting every failure as being offline.
- Temporary network errors retry with backoff; background failures no longer block manual checks throughout a cooldown.
- Custom update URLs ending in a slash no longer produce incorrect paths.
- Telegram, Discord and Webhook connection tests report missing configuration or invalid credentials clearly.

### Before you update

- Media cards are currently displayed only in web conversations. Messaging-app replies remain text.
- Images require a vision-capable model. Video, PDF and voice attachments are not supported yet.

Thanks to @miniers for the messaging-channel connection tests.

Full changes: [v0.20.0 → v0.21.0](https://github.com/movieclaw/MovieClaw/compare/v0.20.0...v0.21.0).

## 简体中文

## v0.21.0：问助手找片，回答里就能直接点海报

这一版让网页 AI 对话展示影音卡片，微信、Telegram、Discord 也能给助手发图片。检查更新和消息通道的网络提示更清楚了。

✅ 已使用 v0.19.0 对应镜像的用户无需更新 Docker 镜像，在「设置 → 更新与维护」一键更新即可。

### 本版亮点

#### 助手推荐的片子，卡片里直接打开

问「我的电影库有什么」或「最近有什么想看的」，网页回答里可以出现媒体库封面、海报、播放和订阅卡片。评分、库存与追更状态由页面实时加载，也能直接打开详情或发起订阅。

#### 在聊天工具里，发图接着说

微信、Telegram、Discord 都支持给助手发海报、截图和报错图片。先发图、紧接着打字会合成一轮；一轮最多 4 张。模型不支持看图或图片处理失败时，会明确说明原因，并保留可重试的内容。

### 修好了

- 检查更新会区分 GitHub 超时、连接失败与配额耗尽，并写明当前走直连还是代理，不再统一误报断网。
- 临时网络错误会退避重试，后台失败也不再让手动检查一直被冷却期挡住。
- 自定义更新地址带尾斜杠时，不再拼出错误路径。
- Telegram、Discord 和 Webhook 补上连通性测试，未配置或凭据无效时给出中文提示。

### 升级须知

- 影音卡片目前只在网页会话展示，聊天工具里的回答仍是文字。
- 图片消息需使用视觉模型；视频、PDF、语音等附件暂未支持。

感谢 @miniers 补齐消息通道连通性测试。完整改动见 [v0.20.0 → v0.21.0](https://github.com/movieclaw/MovieClaw/compare/v0.20.0...v0.21.0)。
