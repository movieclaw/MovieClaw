## v0.7.1：剧集下载不再拿到空文件

这一版修正 Jellyfin 客户端的下载和观看状态。整部剧、整季不再出现无法使用的下载按钮，电影和单集照常下载。

✅ 本版无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 下载按钮，只放在能下载的地方

以前客户端可能在整部剧上显示「下载」，点下去却得到一个打不开的 0 字节文件。现在剧集和季会隐藏这个按钮，文件仍在的电影与单集才显示下载入口。

### 其他新功能与改进

- **季卡片更完整**：补齐集数角标，以及容器、分辨率、高清等文件信息。
- **客户端探测更稳定**：未支持的接口按 Jellyfin 协议返回，取流格式识别也更准确。

### 修好了

- 文件已经丢失的剧集，也能在客户端手动标记已看。
- 客户端上报播放失败时，不再误记成一次正常观看。

完整改动见 [v0.7.0 → v0.7.1](https://github.com/movieclaw/MovieClaw/compare/v0.7.0...v0.7.1)。
