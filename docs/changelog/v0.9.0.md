## v0.9.0：字幕看得懂，全家各自接着看

这一版能用 AI 生成单语或双语外挂字幕，也能识别 PGS 图形字幕。家人有了独立账号，Infuse 接入和手动下载入库也更完整了。

> ⚠️ **本版需要更新 Docker 镜像**：新增字幕转换、文字识别和语言包，请先拉取新镜像并重建容器。Docker Compose 用户可执行 `docker compose pull && docker compose up -d`。

### 本版亮点

#### 手头的字幕，可以翻成你想看的语言

从已有内封或外挂字幕生成 AI 字幕，支持单语、双语、术语表、进度查看和断点续传。PGS 图形字幕也能先识别成文字；完成后保存到视频旁，Infuse、Jellyfin 等播放器都能用。生成前可以检查时间轴，也能单独校准已有外挂字幕。

#### 家里每个人，都有自己的看片记录

管理员可以创建成员，分别设置能看的媒体库、能搜的站点和下载权限。观看进度、收藏、字幕选择和搜索历史各自保存，连接 Jellyfin 客户端时也使用独立用户。

#### 选种时，就把字幕和音轨挑好

种子识别模型升级到 v2，搜索结果展示字幕与音轨语言。订阅规则可以要求简体中文字幕、国语、粤语等；没有声明相应语言的资源不会自动选中。

### 其他新功能与改进

- **Infuse 接入更完整**：补齐添加媒体库所需接口，并按成员权限显示内容。
- **手动下载也能智能入库**：下载前预判目标媒体库，完成后沿用已确认的作品身份。
- **本地元数据优先**：网页和播放器共用本地 NFO、图片与媒体信息。
- **音轨字幕分别记住**：每位成员下次播放沿用自己的选择，支持更多中文外挂字幕命名与编码。

### 修好了

- 手机启动时接口失败，不再只剩白屏。
- 改善旧版 WebKit 兼容与海报加载后悬停信息不出现的问题。

### 升级须知

- 新镜像内置 `torrent-ner-v2`，升级后会自动重算历史种子属性，筛选结果会逐步刷新。
- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.8.0 → v0.9.0](https://github.com/movieclaw/MovieClaw/compare/v0.8.0...v0.9.0)。
