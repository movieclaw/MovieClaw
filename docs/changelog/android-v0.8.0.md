## Android 0.8.0: Better on tablets and offline

Enjoy improved tablet layouts, offline downloads and automatic switching between server addresses.

- Improved tablet layouts, QR sign-in, settings and Reels.
- Automatically switch between verified home and outside server addresses, including reverse proxies hosted under a path. This needs the address support in Server 0.42.0 or later.
- Offline downloads add Wi-Fi-only control, per-account isolation and remembered quality choices. Downloads can retain progress across network interruptions; verify background behavior on your device.
- Reels prefer pre-cut clips and follow the current server address. Rule groups add **DV P5** exclusion with Server 0.43.0.

The Android interface remains Chinese in this release.

Full changes: [android-v0.7.0 → android-v0.8.0](https://github.com/movieclaw/MovieClaw/compare/android-v0.7.0...android-v0.8.0).

## Android 0.8.0：平板与离线体验升级

平板布局、离线下载和内外网自动切换一起升级。

- 改进平板布局，补齐扫码登录、设置与「小幕」体验。
- 自动选择已验证的内外网地址，兼容带子路径的反向代理，需服务器 0.42.0 或更新版本。
- 离线下载新增「仅 Wi-Fi」、按账号隔离与画质记忆，网络中断时保留进度；不同设备的后台续传表现仍需实机确认。
- 「小幕」优先播放预切片段，媒体地址跟随当前服务器入口；规则组新增「DV P5」排除选项，需服务器 0.43.0。

Android 界面本次仍以中文为主。

完整改动：[android-v0.7.0 → android-v0.8.0](https://github.com/movieclaw/MovieClaw/compare/android-v0.7.0...android-v0.8.0)。
