## v0.42.0: A plugin market, and subscriptions that know your languages

Administrators can now browse and install plugins from a market inside MovieClaw. Smart subscriptions ask once whether you understand a language, so they stop grabbing releases you can't follow. The Apple apps now switch between your home and outside addresses on their own.

> ✅ No Docker image update is required. Update from Settings → Update & Maintenance. If your data directory is on ZFS (fnOS, for example), updating in the app can fail at the last step this one time: pull the new Docker image instead. Switching addresses automatically needs iPhone and iPad 0.10.0, Mac 0.10.0 or Apple TV 0.10.0.

### Highlights

#### Find plugins without hunting for files

Getting a plugin used to mean finding a .mcplugin file and uploading it yourself. Now go to Settings → Plugins → **Plugin market (插件市场)** to search, read about a plugin and its permissions, then install it. Installing still shows the same approval screen as an upload. Plugins with a newer version show **Update (更新)**.

- Only administrators see the market.
- The plugin list must carry MovieClaw's signature, and every download is checked against it before the approval screen opens.
- Versions this server can't run are marked, such as **Needs a newer MovieClaw (需要更新 MovieClaw)**.
- The market downloads from GitHub through the same network settings as in-app updates. When GitHub can't be reached, it shows the last list it got.

#### Subscriptions that don't grab what you can't watch

Smart subscriptions could download a foreign release with no subtitles you can read. Now, the first time you subscribe to something in a new language, the subscribe dialog asks something like "这是英语片，要中文字幕吗？". Your answer is remembered. When only an unreadable release exists, the subscription waits for one with subtitles. It tells you once when the wait runs out, and the subscription page offers **Download the original this time (这次先下原版)**. Change the quality in the dialog and it asks whether to keep doing that for just this title, all films or shows, a region, or a network (shows only). A sequel keeps the quality you set for the title before it.

- Chinese counts as understood. A release qualifies when its subtitles or its audio are in a language you understand.
- Review or remove what it remembers under Settings → Subscription rules → Smart settings: **Languages I understand (看得懂的语言)** and **Quality habits (画质习惯)**.
- Films and shows now share one set of smart settings. If yours differed, the show values became an "所有剧集" habit, so nothing changes.
- Only administrators are asked. Members, the AI assistant, plugins and older apps use what's remembered and require subtitles for languages nobody has answered.
- Existing subscriptions keep working as before. The first time you answer a language question or change smart settings, every smart subscription is re-checked: foreign titles then wait for readable subtitles. Episodes already downloaded aren't touched.
- iPhone and iPad 0.10.0 and Android 0.7.0 ask the same questions.

#### Apps use your home address at home

The apps always used the address you signed in with, so if that was your domain, even at home everything went out and back through it. The server also took viewers outside for people at home, so cloud drive uploads didn't make way for them and **Always stream from the drive (总是直连网盘)** didn't apply. Now the server collects the addresses people use under Settings → Network → **Access addresses (访问地址)**, and the Apple apps above pick the home or outside address on their own. The server also tells home from outside by the address a request came in on.

- Addresses are learned only from administrators' requests. Administrators can also use **Add address (添加地址)**.
- The apps send your sign-in only to an address that proves it's your server.
- The web page, Android and Windows apps don't switch addresses yet.

### More features and improvements

- **Themes are plugins**: the Netflix theme now ships as a built-in plugin and looks the same. You can uninstall it under Settings → Plugins and restore it later. Theme packages (.mcplugin) install there too; a theme that brings its own code needs **I trust this theme's code (我信任这个主题的代码)**. Pick one under Settings → Appearance → Theme (主题).
- **Long MP4s on Android**: a long MP4 with many audio tracks, such as a 4K Dolby Vision film with TrueHD, could crash the Android app about ten seconds into playback. The server now repackages these files. This needs Android 0.7.0 or Android TV 0.6.0.
- **Seek previews in Jellyfin apps**: Jellyfin apps now show thumbnails while you drag the progress bar. Thumbnails are made in the background once a title is played, while **Generate seek previews (生成进度条预览图)** is on, as it is by default.

### Fixed

- Updating in the app failed at the last step on ZFS (fnOS, for example), showing that the last update failed. Rolling back failed the same way.
- With an NVIDIA card, HDR films were tone-mapped on the CPU instead of the card.
- With Intel or AMD graphics (VAAPI or QSV), HDR films that needed transcoding failed to play with a transcoding error.
- Hardware transcoding of widescreen or 60 fps videos failed right away.
- Switching the discover page to Douban shows could fail with "加载失败", and other pages slowed down while it loaded.
- In a cloud drive library, freeing the first episode of a season pack deleted the whole download, so the season was downloaded again and again.
- Subscribing to only the newest season with automatic follow-up also downloaded old-season episodes that TMDB lists without an air date. Ones not downloaded yet leave the subscription the next time you change it.
- And 1 more fix: plugins that run in their own process could not start on a server running directly on Windows.

### Before you update

- This release migrates the database. To return to v0.41.0, use Settings → Update & Maintenance → **Roll back to an earlier version (回退到历史版本)**. It restores the backup taken before the update, so anything since is lost, including remembered languages and quality habits. If you update by pulling the Docker image, no backup is made, so stop the container and back up the data directory first.

## 简体中文

## v0.42.0：插件市场开张，订阅懂你的语言

管理员现在可以在 MovieClaw 里直接浏览、安装插件。智能订阅会问一次你看不看得懂某种语言，不再抓来看不懂的版本。Apple 各端会自己在家里地址和外网地址之间切换。

> ✅ 不需要更新 Docker 镜像，在「设置 → 更新与维护」里一键更新即可。如果数据目录在 ZFS 上（如飞牛 NAS），这一次应用内更新可能在最后一步失败，请改为拉取新的 Docker 镜像。自动切换地址需要 iPhone 与 iPad 0.10.0、Mac 0.10.0 或 Apple TV 0.10.0。

### 本版亮点

#### 找插件，不用再到处找文件

以前装插件要自己找到 .mcplugin 文件再上传。现在到「设置 → 插件 → 插件市场」，搜索、看介绍和权限，然后安装。安装时仍是和上传一样的批准界面。有新版本的插件会显示「更新」。

- 只有管理员能看到插件市场。
- 插件列表必须带 MovieClaw 的签名，每个下载的包都按它核对过才进入批准界面。
- 这台服务器跑不了的版本会标出来，如「需要更新 MovieClaw」。
- 插件市场从 GitHub 下载，走的是和应用内更新相同的网络设置。连不上 GitHub 时显示上次取到的列表。

#### 订阅不再抓来看不懂的版本

以前智能订阅可能下到一个没有你看得懂字幕的外语版本。现在第一次订阅某种新语言的片子时，订阅弹层会问一句，如「这是英语片，要中文字幕吗？」，回答一次就记住。只有看不懂的原版时，订阅会等带字幕的版本；等到期会提醒你一次，订阅页里有「这次先下原版」。在弹层里改了画质，会问以后要不要也这样：只这部、所有电影或剧集、某个地区或某个播出平台（仅剧集）。续集沿用上一部单独改过的画质。

- 中文默认算看得懂。字幕或音轨里有一种你看得懂的语言就算合格。
- 记住的内容在「设置 → 订阅规则 → 智能设置」的「看得懂的语言」和「画质习惯」里查看或移除。
- 电影和剧集的智能设置合并成一套。原来两套不一样的，剧集那套变成一条「所有剧集」的习惯，行为不变。
- 只有管理员会被问到。成员、AI 助手、插件和旧版 App 订阅时沿用记住的内容，没人回答过的语言一律要字幕。
- 已有的订阅升级后照旧。你第一次回答语言问题或修改智能设置时，所有智能订阅都会重新核对一遍：外语片之后会等看得懂的字幕版。已经下载的不受影响。
- iPhone 与 iPad 0.10.0、Android 0.7.0 也会问同样的问题。

#### 在家走家里的地址

各 App 一直用登录时的地址，用域名登录的话，在家也要绕外面一圈。服务器还会把在外面看片的人当成在家：网盘上传不给他们让路，「总是直连网盘」也不生效。现在服务器会把大家用过的地址收集到「设置 → 网络 → 访问地址」，上面那几个 Apple App 会自己选家里或外网的地址。服务器也改为按请求进来的地址判断在家还是在外面。

- 只从管理员的请求里学地址。管理员也可以「添加地址」。
- App 只会把登录信息发给证明了是你这台服务器的地址。
- 网页、Android 和 Windows App 暂时不切换地址。

### 其他新功能与改进

- **主题变成插件**：Netflix 主题现在是随应用携带的插件，样子不变。可以在「设置 → 插件」里卸载，之后随时恢复。主题包（.mcplugin）也在那里安装；带代码的主题要勾选「我信任这个主题的代码」。到「设置 → 外观 → 主题」里选用。
- **安卓上的长 MP4**：音轨很多的长 MP4（如带 TrueHD 的 4K 杜比视界电影）在安卓上播放约十秒后可能整个 App 闪退。现在服务器会给这类文件换封装。需要 Android 0.7.0 或 Android TV 0.6.0。
- **Jellyfin App 拖进度有预览图**：Jellyfin App 拖动进度条时现在会显示缩略图。缩略图在片子播放后由后台生成，前提是「生成进度条预览图」开着（默认开启）。

### 修好了

- 在 ZFS 上（如飞牛 NAS）应用内更新在最后一步失败、提示上次更新失败的问题已修复，回退到历史版本同样会失败的问题也一并修复。
- 用 NVIDIA 显卡时，HDR 片的色调映射不在显卡上做、全由 CPU 承担的问题已修复。
- 用 Intel 或 AMD 显卡（VAAPI 或 QSV）时，需要转码的 HDR 片报转码失败、播不了的问题已修复。
- 宽银幕或 60 帧的视频硬件转码一开始就失败的问题已修复。
- 发现页切到豆瓣剧集时可能「加载失败」、同时其他页面变慢的问题已修复。
- 网盘库里季包的第一集腾空后整个下载被删、整季反复重新下载的问题已修复。
- 只勾最新一季并开启自动续订时，TMDB 上没有播出日期的旧季集也被下载的问题已修复。还没下的这类集，在你下次修改这个订阅时移出订阅。
- 以及 1 处细节修复：直接在 Windows 上运行服务器时，独立进程运行的插件起不来。

### 升级须知

- 这一版会迁移数据库。要回到 v0.41.0，到「设置 → 更新与维护 → 回退到历史版本」，它会恢复更新前的自动备份，之后的改动都会丢失，包括记住的语言和画质习惯。如果你是拉取 Docker 镜像更新的，不会自动备份，请先停止容器并备份数据目录。
