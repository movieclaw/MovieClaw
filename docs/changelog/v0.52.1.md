## v0.52.1: A stability update

Consecutive claims and background artwork or thumbnail generation no longer stall the rest of the server, and picking an unusable text subtitle track for AI subtitle generation now explains why that track cannot be used instead of showing a misleading PGS error.

> ✅ Update from Settings → Updates and maintenance. The Docker runtime stays 25. This release does not migrate the database.

### Fixed

- Claiming or importing several titles in a row could leave background artwork downloads and thumbnail or episode-still frame grabs holding database connections while waiting in line. Under batch activity, other requests across the server could time out with 500 errors. Background artwork and thumbnail jobs now release their database connection before downloading images or grabbing frames, and only reconnect to save the finished results.
- Starting **Generate AI subtitles** with an explicitly chosen text subtitle track that turns out to be empty or incomplete previously returned an error saying the confirmed PGS track had changed. It now returns the actual reason that text track failed the completeness check. Requests that explicitly confirm PGS conversion still report when the PGS track has changed.

### Before you update

- There is no database migration. The Docker runtime stays 25, so updating from Settings → Updates and maintenance does not require a new image. **Roll back to a previous version** can return to 0.52.0 without restoring a backup, because the database structure is unchanged.

Full changes: [v0.52.0 → v0.52.1](https://github.com/movieclaw/MovieClaw/compare/v0.52.0...v0.52.1).

## 简体中文

## v0.52.1：稳定性更新

连续认领作品以及后台补图、抓帧不再拖慢全站其他请求，在「AI 生成字幕」里手动指定不可用的文本字幕轨时，也会直接说明该轨不合格的原因，不再误报 PGS 轨道已变化。

> ✅ 在「设置 → 更新与维护」里更新。Docker 运行时仍是 25。这一版不迁移数据库。

### 修好了

- 连续认领或入库多部作品时，后台下载海报和抓帧生成缩略图、分集剧照会在排队、下载或解码期间一直占着数据库连接。批量操作一多，全站其他请求就可能超时报 500。现在后台补图和抓帧在排队、下载或解码前会先归还数据库连接，等结果就绪后再写回数据库。
- 在「AI 生成字幕」里手动指定某条文本字幕轨发起生成时，如果该轨内容为空或不够完整，之前会误报「用户确认的 PGS 轨道已变化，请重新预检后再试」。现在会返回该文本轨真正的完整度不合格原因；显式确认 PGS 转换时若 PGS 轨道发生变化，仍会给出原有提示。

### 升级须知

- 没有数据库迁移。Docker 运行时仍是 25，从「设置 → 更新与维护」更新不必换镜像。在「回退到历史版本」里回到 0.52.0 时不用恢复备份，因为数据库结构没有变。

完整改动：[v0.52.0 → v0.52.1](https://github.com/movieclaw/MovieClaw/compare/v0.52.0...v0.52.1)。
