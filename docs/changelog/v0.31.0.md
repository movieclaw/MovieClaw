## v0.31.0: Find it by a few letters, see it in full detail

Library search now understands pinyin, initials, Traditional Chinese and cast names, and posters and stills are stored at original quality. Skip buttons also learn short intros, end credits, ads and previews.

> ⚠️ **Update the Docker image**: Stop the container and back up the data directory, then run `docker compose pull && docker compose up -d`. In-app update cannot install this version; it shows that a new Docker image is required. Also update the iPhone app to 0.4.0 (https://github.com/movieclaw/MovieClaw/releases/download/v0.31.0/MovieClaw-iOS-unsigned.ipa): with 0.3.0, library search fails on this server.

### Highlights

#### Type a few letters and find the title

Searching your library used to match only the exact title text, so you had to switch to a Chinese keyboard and remember the name. Now full pinyin, initials (such as `st` or `xjcy`), Chinese mixed with pinyin, Traditional Chinese, alternative titles, and actor or director names all work. Results are sorted by relevance and say why they matched, and matching people get their own row that opens their page in your library. On the web, open search (⌘K / Ctrl+K) and pick **Library (媒体库)**; on iPhone, tap the magnifier and pick the same tab.

- Suggestions appear as you type. On iPhone, results also update as you type.
- Results are no longer grouped by library or counted. Scroll, or tap **More results (更多结果)**, to load more.
- After the update the server builds a search index in the background. Search works meanwhile, but may be slower on large libraries.

#### Sharper posters, stills and cast photos

Episode stills used to be stored 300 pixels wide and posters 780, so they looked soft on a TV or large screen. Now the server keeps the original images by default, every device gets the size it needs, and cast photos are saved locally too. With your own Fanart.tv API key you also get more posters, backgrounds, title logos and season posters. Administrators start at Settings → Scrape & Organize → **Local image quality (本地图片画质)** and **Enable Fanart.tv (启用 Fanart.tv)**.

- Quality options are Original (the default), Standard, Save space and Custom, each with an estimated size for your library.
- Titles already in your library get Fanart.tv artwork after **Refresh metadata (刷新元数据)** or their next scheduled refresh. To pick by hand, use ⋯ → **Change images… (更换图片…)** on the title page.

### More features and improvements

**Library and playback**
- **Skip buttons by type**: Short intros such as studio logos are detected, and end credits of Western series are found from the on-screen credits. Ads and next-episode previews show **Skip ad (跳过广告)** and **Skip preview (跳过预告)**; other segments show **Skip segment (跳过此段)**.
- **Faster intro and credits detection**: Up to 4 episodes run in parallel, depending on CPU cores. While someone is watching it keeps one going, and it pauses only while the server itself is transcoding.
- **Collections shown on the home page** also get a card in **My libraries (我的媒体库)**.
- **Refresh metadata** no longer downloads every image again. It keeps the ones that are fine, and the task center shows how many images were new, reused or missing.

**Sites and downloads**
- **Separate downloader for ratio boosting**: Settings → Sites → ⋯ → Enable boosting… → **Boost downloader (刷流下载器)**, shown when you have more than one downloader. If it is unavailable, the site pauses boosting instead of switching downloaders. Deleting it turns off boosting for those sites; seeding torrents stay.
- **New sites**: SunnyPT (shown as Sunny, connects with an API key generated on the site) and UBits (connects with a browser cookie).

**iPhone**
- Tap ✕ on the Continue Watching bar to hide it until this device plays something again.
- The scan button on the Me tab approves another device's sign-in.
- Customize home is now an edit list: show or hide rows, drag to reorder, and add rows by type, library or collection.
- Connection errors say what went wrong and what to try, with the address and error code.

### Fixed

- On iPhone, signing in with an http address that uses a domain name failed with error -1022.
- Editing the home layout on iPhone deleted "All movies" and "All series" rows added on the web.
- The iPhone lock screen and Control Center showed no artwork for what was playing.
- Skip buttons sometimes marked story scenes as end credits, labelled other segments as intros, missed short ads, or used old times after a file was replaced.
- Playback through the Mac transcoder could stop partway through. This is fixed on the server.
- The Mac transcoder reconnected by itself after you disconnected it, kept its old name on the server after renaming, and was slow to reconnect after the network came back. These need the new transcoder: https://github.com/movieclaw/MovieClaw/releases/download/v0.31.0/MovieClawTranscoder-macos-arm64.zip
- In search, recent titles and torrents were mixed and **Clear (清空)** wiped both; on a phone, a series in the results took two taps to open.
- System logs could contain the TMDB API key and site passkeys in plain text.
- Plus 2 smaller fixes.

### For administrators

- **Images take more disk space**: Existing images are downloaded again once, whichever quality you pick, as scheduled refresh reaches each title over about a month. In our test library we estimate Original at about 2.6 GB, up from 0.28 GB; the settings page shows the estimate for yours. To use less, choose Standard or Save space under **Local image quality** soon after updating.
- **iPhone notifications are not usable yet**: New pages Settings → **MovieClaw Cloud** and **App push (App 推送)** (administrators) and **Notifications (通知)** (everyone) prepare them, but they need an App Store or TestFlight build, which is not public yet. The sideloaded app cannot receive notifications.
- **MovieClaw Cloud reporting**: Once connected, the server reports its version and system. **Share statistics (上报统计信息)** is on by default and also reports device counts by platform and app version, and whether official push is reachable; turn it off on the MovieClaw Cloud page. Nothing is sent while not connected.

### Before you update

- This release migrates the database, and a Docker image update makes no automatic backup. To return to v0.30.0, stop the container, change the image tag to `movieclaw/movieclaw:v0.30.0`, restore the backup you made, then start it.
- The iPhone items above, and the new skip button labels on iPhone, need app 0.4.0.
- **Intro and credits detection runs again on every series**, keeping CPU and disks busy, possibly for many hours on a large library. Until a series is done it has no skip buttons; a season you start playing goes first.
- "All movies" and "All series" rows no longer appear by themselves. If you have two or more libraries of a type and never customized the home page, they are gone; add them back at Library → ⋯ → Customize home → **+ Add a row (＋ 添加一行)**.
- Settings → Devices no longer has the pairing code box. Tap **Approve new device login (批准新设备登录)** there, or open `/activate`. Old approval links still work.
- **Message push (消息推送)** is now called **IM push (IM 推送)**, in the same place.
- `mclaw search library-items` is now `mclaw search library`, and `/api/v1/search/library-items` is gone. Download the new mclaw from this release and update your scripts.
- Logs written before the update still contain those keys. Delete old files in `data/logs` before sharing logs.

Thanks to @DongShull. Full changes: [v0.30.0 → v0.31.0](https://github.com/movieclaw/MovieClaw/compare/v0.30.0...v0.31.0).

## 简体中文

## v0.31.0：打几个字母就搜到，图也看得清

媒体库搜索认得拼音、首字母、繁体和演职员名字，海报、剧照改存原图。跳过按钮也能认出短片头、片尾演职员表、广告和预告了。

> ⚠️ **需要更新 Docker 镜像**：先停止容器并备份数据目录，再执行 `docker compose pull && docker compose up -d`。应用内更新装不了这一版，会提示需要拉取新的 Docker 镜像。iPhone App 也请更新到 0.4.0（https://github.com/movieclaw/MovieClaw/releases/download/v0.31.0/MovieClaw-iOS-unsigned.ipa）：0.3.0 连这一版服务器时，媒体库搜索会失败。

### 本版亮点

#### 打几个字母，就能搜到想看的片

以前搜媒体库只认片名原文，得切中文输入法，还得记准名字。现在全拼、首字母（如「st」「xjcy」）、中文拼音混输、繁体、别名，以及演员和导演的名字都能搜到。结果按相关度排列并注明命中原因，搜到的人物单独成一行，点进去是他在你库里的影人页。网页上打开搜索（⌘K / Ctrl+K）选「媒体库」；iPhone 上点放大镜，选同一个标签。

- 输入时就有联想；iPhone 上边输入边出结果。
- 结果不再按库分组、不再显示总数；往下滚或点「更多结果」加载更多。
- 升级后服务器会在后台建立搜索索引。建好之前照样能搜，大库可能会慢一些。

#### 海报、剧照和演职员头像更清楚

以前分集剧照只存 300 像素宽、海报存 780，电视和大屏上看着发虚。现在服务器默认保存原图，各设备按需要的尺寸取图，演职员头像也存到本地。填上自己的 Fanart.tv API Key，还能多出海报、背景、片名 Logo 和季海报可选。管理员从「设置 → 刮削与整理」里的「本地图片画质」和「启用 Fanart.tv」开始。

- 画质可选原图（默认）、标准、节省空间和自定义，每档标出按你的媒体库估算的大小。
- 已入库的条目要「刷新元数据」或等下次定时刷新，才会用上 Fanart.tv 的图。想手动挑，在条目详情的 ⋯ 里点「更换图片…」。

### 其他新功能与改进

**媒体库与播放**
- **跳过按钮分类型**：能认出厂标这类短片头，欧美剧可以靠画面上的演职员表认出片尾。广告和下集预告分别显示「跳过广告」「跳过预告」，其他片段显示「跳过此段」。
- **片头片尾识别更快**：按 CPU 核数最多同时识别 4 集；有人在看片时只留一路，服务器本机转码时才暂停。
- **首页显示的合集**会同时在「我的媒体库」里多出一张卡片。
- **刷新元数据**不会再把所有图片重下一遍，完好的直接沿用；任务中心会显示新下载、沿用和没下到的图片数。

**站点与下载**
- **刷流单独选下载器**：「设置 → 资源站点 → ⋯ → 开启刷流…」里多了「刷流下载器」，有两台及以上下载器时才出现。它不可用时该站暂停刷流，不会改投别的下载器。删除这台下载器会关闭用它刷流的站点，已在做种的种子保留。
- **新增站点**：SunnyPT（界面上叫 Sunny，用站点生成的 API Key 接入）和 UBits（用浏览器 Cookie 接入）。

**iPhone**
- 点「接着看」条上的 ✕ 可以收起它，这台设备再播放时才重新出现。
- 「我的」页的扫码按钮可以批准其他设备登录。
- 「自定义首页」改成编辑列表：显示或隐藏、拖动排序，可以按类型、媒体库或合集添加行。
- 连接出错时会说明原因和解决办法，并带上地址和错误码。

### 修好了

- iPhone 用「http + 域名」地址登录时报 -1022 的问题已修复。
- 在 iPhone 上编辑首页布局时，会删掉网页上添加的「全部电影」「全部剧集」行的问题已修复。
- iPhone 锁屏和控制中心的「正在播放」没有封面的问题已修复。
- 跳过按钮偶尔把剧情当成片尾、把其他片段标成片头、漏掉短广告，或者换过片源后用旧时间点的问题已修复。
- 用 Mac 转码器播放时可能中途停住的问题已修复，这项修复在服务器上。
- Mac 转码器手动断开后又自己连回去、改名后服务器上还是旧名字、网络恢复后迟迟不重连的问题已修复。需要新版转码器：https://github.com/movieclaw/MovieClaw/releases/download/v0.31.0/MovieClawTranscoder-macos-arm64.zip
- 最近搜索里影视和资源混在一起、点「清空」两种一起清掉，以及手机上点搜索结果里的剧集要点两下才能进详情的问题已修复。
- 系统日志里可能出现明文 TMDB API Key 和站点 passkey 的问题已修复。
- 以及 2 处细节修复。

### 管理员须知

- **图片会多占磁盘**：不管选哪档画质，已有图片都会重新下载一次，由定时刷新在约一个月内轮完。在我们的测试库里，原图档估算约 2.6 GB，原来是 0.28 GB；设置页会按你的库给出估算。想少占一些，升级后尽早在「本地图片画质」里选标准或节省空间。
- **iPhone 通知暂时用不上**：新增的「设置 → MovieClaw Cloud」「App 推送」（管理员）和「通知」（所有人）是为它准备的，但需要从 App Store 或 TestFlight 安装的 App，目前还没有公开。侧载版收不到通知。
- **MovieClaw Cloud 上报**：连接后，服务器会上报版本和系统信息。「上报统计信息」默认开启，还会上报按平台和 App 版本汇总的设备数，以及官方推送能否连通；可以在 MovieClaw Cloud 页关掉。没连接时不会发送任何信息。

### 升级须知

- 本版包含数据库迁移，更新 Docker 镜像不会自动备份。要回到 v0.30.0：停止容器，把镜像标签改回 `movieclaw/movieclaw:v0.30.0`，恢复你做的备份后再启动。
- 上面的 iPhone 各项，以及 iPhone 上的新跳过按钮名，需要 App 0.4.0。
- **升级后会给所有剧集重新识别一遍片头片尾**，CPU 和磁盘会忙上一阵，大库可能要很多个小时。识别完之前那部剧不显示跳过按钮，开始播放的那一季优先识别。
- 「全部电影」「全部剧集」行不再自动出现：同类型有两个及以上的库、又没自定义过首页的，会看不到它们。要加回来：媒体库页 ⋯ →「自定义首页」→「＋ 添加一行」。
- 「设置 → 设备」里不再有配对码输入框。在那里点「批准新设备登录」，或直接打开 `/activate`；旧的批准链接仍然能用。
- 「消息推送」改名为「IM 推送」，位置不变。
- `mclaw search library-items` 改为 `mclaw search library`，接口 `/api/v1/search/library-items` 已删除。请从本版下载新的 mclaw，并同步修改自己的脚本。
- 升级前写下的日志里仍有这些密钥。分享日志之前，先删掉 `data/logs` 里的旧文件。
