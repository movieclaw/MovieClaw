## v0.3.0: A clearer way back, and more places for your files

Choose a previous version with clearer rollback information, and organize files into a custom directory without creating a library first.

✅ No Docker image update is required. Update from **Settings → Application**.

### Highlights

#### Know what a rollback will restore

Choose from locally retained versions and see whether a database backup is needed and which point in time it will restore. The default is five versions; you can change the limit and check disk usage. Another backup is created before rolling back.

#### Send organized files to a directory you choose

Watched imports can now target a custom directory, including mounted cloud storage or a strm output directory. Subscription downloads support the same destination without requiring a library.

### More features and improvements

- **Updates are easier to spot**: A blue sidebar badge and a version card show new releases and their notes.
- **Update traffic can use a proxy**: Network & Proxy settings include a GitHub Updates switch and connection test.
- **Pending items are clearer**: A card layout makes the main actions easier to find.

### Fixed

- Corrected several issues with saving and using custom directory destinations.
- Added staging paths to subscription download records and synchronized the related CLI interfaces.

### Before you update

- If your deployment previously used environment variables to proxy update traffic, enable GitHub Updates in Settings → Network & Proxy after upgrading.

Full changes: [v0.2.0 → v0.3.0](https://github.com/movieclaw/MovieClaw/compare/v0.2.0...v0.3.0).

## 简体中文

## v0.3.0：升级有退路，整理有去处

这一版让更新更好找、回退更清楚。自动整理也能输出到自定义目录，不必先建一个媒体库。

✅ 本版无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 回到哪个版本，先看清再决定

回退时可以从本地保留的多个版本里选择，并看清是否需要恢复数据库备份、会回到哪个时点。默认保留最近 5 个版本，也能调整数量和查看磁盘占用；回退前会再做一次备份。

#### 整理好的文件，可以放到你指定的地方

监听导入新增「自定义目录」目标，网盘挂载目录、strm 输出目录都能作为去处。订阅下载也支持这个目标，不再必须绑定媒体库。

### 其他新功能与改进

- **新版本更容易发现**：侧栏用蓝色徽标提醒，设置页直接展示版本卡片和更新日志。
- **更新流量可走代理**：「设置 → 网络与代理」新增「GitHub 更新」开关和连通性测试。
- **待处理事项更清楚**：弹窗改为卡片布局，主要操作更容易找到。

### 修好了

- 修正自定义目录目标的几处保存与使用问题。
- 订阅下载记录补上暂存路径，命令行也同步了相关接口。

### 升级须知

- 以前靠环境变量代理更新流量的部署，升级后请在「设置 → 网络与代理」开启「GitHub 更新」。

完整改动见 [v0.2.0 → v0.3.0](https://github.com/movieclaw/MovieClaw/compare/v0.2.0...v0.3.0)。
