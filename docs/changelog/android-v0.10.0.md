## Android 0.10.0: Pick another episode without leaving playback

Series now have an episode drawer inside the player. You can see where you are, switch to another available episode, or change seasons without returning to the detail page. The Android interface remains Chinese.

> ✅ Works with MovieClaw Server 0.33.0 or later, the same as 0.9.5. Changing seasons inside the player requires Server 0.50.0 or later; older supported servers still show the current season. Install from https://movieclaw.io/download/android.apk

### Highlights

#### Keep the picture in sight while choosing an episode

While a series is playing, tap **选集** or the **下一集** capsule in the bottom controls. The drawer opens beside the picture, centers the episode currently playing, shows watch progress, and leaves missing episodes visible but unavailable. The system back gesture closes the drawer before it exits playback.

The previous episode-number grid has been replaced by this drawer. Change seasons from the season name at the top; selecting another season changes only the list until you choose an episode.

Full changes: [android-v0.9.5 → android-v0.10.0](https://github.com/movieclaw/MovieClaw/compare/android-v0.9.5...android-v0.10.0).

## 简体中文

## Android 0.10.0：不用退出播放就能换一集

剧集播放器现在自带选集抽屉。你可以直接看见正在播放的位置，切换到另一集，也能换季，不必先退回详情页。Android 界面仍是中文。

> ✅ 搭配 MovieClaw 服务器 0.33.0 或更新版本即可使用，与 0.9.5 相同。在播放器里跨季切换需要服务器 0.50.0 或更新版本；更早但仍受支持的服务器仍会显示当前季。从 https://movieclaw.io/download/android.apk 安装。

### 本版亮点

#### 画面还在眼前，就能挑下一集

播放剧集时，点底栏的「选集」或「下一集」胶囊。抽屉会出现在画面旁边，自动把正在播放的一集放到中间，显示观看进度；缺集仍会列出，但不能点。系统返回手势会先收起抽屉，再退出播放。

原来的集号宫格已由这个抽屉替代。点顶部的季名可以换季；换季只会先换列表，选中某一集后才开始播放。

完整改动：[android-v0.9.5 → android-v0.10.0](https://github.com/movieclaw/MovieClaw/compare/android-v0.9.5...android-v0.10.0)。
