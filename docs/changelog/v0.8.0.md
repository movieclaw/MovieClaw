## v0.8.0: Correct the title when recognition gets it wrong

Manually correct title recognition and filter for Simplified Chinese subtitles. Subscription rules can require HDR while excluding Dolby Vision, and ZSpace imports work properly.

✅ No Docker image update is required. Update from **Settings → Application**.

### Highlights

#### Fix a mismatch without repeatedly running recognition

The title detail page now offers a recognition correction panel. Inspect the new result or search for the right title and confirm its poster and synopsis. Extras and trailers can be marked as non-standalone content and removed from the movie library.

#### Choose subtitles and picture formats for your device

Search results can filter for Simplified Chinese subtitles. Subscription rules control HDR and Dolby Vision separately, including combinations such as requiring HDR while excluding DV. Existing rules retain their meaning.

### More features and improvements

- **See what is already in your library**: Recommendations and lists show an in-library marker linking to the local detail page.
- **AGSVPT support**: Connect it in tracker settings.
- **Fewer extras mistaken for movies**: Recognition considers the title directory and common extra-folder and filename conventions.

### Fixed

- Files imported through hard links on ZSpace can now be indexed by its built-in media app.
- M-Team adult-category searches return results correctly.
- Watched import counts use titles, rather than counting multiple seasons of the same series as separate imports.

### Before you update

- Historical torrent attributes are recalculated after updating. Potential existing mismatches enter identity review for your confirmation.
- This release migrates the database. Restore the automatic pre-update backup when rolling back across versions.

Full changes: [v0.7.1 → v0.8.0](https://github.com/movieclaw/MovieClaw/compare/v0.7.1...v0.8.0).

## 简体中文

## v0.8.0：认错的片子，终于能自己改回来

这一版带来手动修正影片识别，以及简体中文字幕筛选。订阅可以分别要求 HDR、排除杜比视界，极空间入库也修好了。

✅ 本版无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 认错片，不必反复点重新识别

影片详情页新增「修正识别结果」：可以先看重新识别的结论，也能搜索正确作品、核对海报简介后认领。花絮和预告片可标成「非独立作品」，从影片库移出。

#### 找字幕和选画质，更贴合你的设备

搜索结果可以筛选简体中文字幕。订阅规则把 HDR 与杜比视界分开控制，支持「必须 HDR、排除 DV」这类组合；已有规则保持原来的含义。

### 其他新功能与改进

- **发现页能看到库存**：推荐和榜单标出「已在库中」，点击可打开库内详情。
- **新增 AGSVPT**：可在站点设置里接入。
- **花絮不再轻易认成另一部电影**：按影片目录取证，并识别常见花絮目录和文件名。

### 修好了

- 极空间硬链接入库的文件，现在能被「极影视」正常收录。
- M-Team 成人分类搜索现在能正确返回结果。
- 监听导入按作品统计「已入库」，同一部剧的多季不再重复计数。

### 升级须知

- 升级后会自动重算历史种子属性；可能认错的存量内容进入「身份复核」，由你确认。
- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.7.1 → v0.8.0](https://github.com/movieclaw/MovieClaw/compare/v0.7.1...v0.8.0)。
