## v0.25.0: Easier duplicate cleanup, and a home screen of your own

Duplicate files are grouped by confidence, Blu-ray discs can play directly, and each member can arrange their library home. Background scans also make room for browsing.

✅ If you already use the image for v0.23.0, no Docker image update is required. Update from **Settings → Update & Maintenance**.

### Highlights

#### Duplicate files are easier to compare and clean up

Detection runs as a background scan, and pages read saved results instead of recalculating the entire library on every visit. Groups distinguish safe cleanup, suggested cleanup and decisions for you, including HDR versus SDR or different resolutions. Filename differences, sizes and bitrates are easier to compare. Stale conclusions are not used to delete files.

#### Click Play on a Blu-ray disc

The web player and Jellyfin-compatible clients support Blu-ray discs, with direct output for a single clip and playlist-based remuxing for multiple clips. A disc entry no longer breaks the client's entire Recently Added row.

#### Each person can choose their home rows

Show or hide rows, change their order, sorting and names, and add library or collection rows. Filter to unwatched content, use random sorting or restore the defaults. Collection pages can pin themselves to the home screen too.

### More features and improvements

- **Clean up when canceling a subscription**: Remove torrents and files within its covered scope, or clean an unchecked season; multi-season packs are retained.
- **Background work interferes less**: Reconciliation skips unchanged directories, scans yield during busy foreground requests, and collections need fewer repeated queries.
- **Set task schedules**: Settings → Application → Scheduled Tasks controls intervals and enabled state, with previous and next execution times.
- **Honest network-mount guidance**: NFS and SMB directories avoid ineffective watches and explain that periodic reconciliation discovers new files.
- **Lighter browsing and playback**: Sorting refreshes only the title wall; favorites and collections can sort. Transcode caches span sessions, and measured bandwidth informs bitrate.
- **Less waiting to delete large files**: Move them out of the library first, then reclaim storage in the background.

### Fixed

- A second finger, landscape gestures or a quick release no longer cancel seeking or send it back to the starting point.
- Seeking to the end no longer restarts the film, and controls remain visible while holding the timeline.
- Viewing records with user data survive library or file removal and reconnect when the same title is imported again.
- Import deduplication no longer wrongly rejects downloaded quality upgrades.
- Unknown specifications are not automatically treated as worst quality, and missing episode numbers do not imply duplicates.
- Duplicate scans no longer occupy APIs for extended periods; failed cleanup is not falsely marked successful.

### Before you update

- Torrent and media cleanup still deletes actual files. Check the confirmation's scope; background deletion does not provide recovery.
- This release migrates the database. Restore the automatic pre-update backup when rolling back across versions.

Full changes: [v0.24.0 → v0.25.0](https://github.com/movieclaw/MovieClaw/compare/v0.24.0...v0.25.0).

## 简体中文

## v0.25.0：重复文件好清理，片库首页自己排

这一版让重复文件按把握程度分组，蓝光原盘可以直接播放。每位成员都能安排自己的媒体库首页，后台扫描也更懂得给浏览让路。

✅ 已使用 v0.23.0 对应镜像的用户无需更新 Docker 镜像，在「设置 → 更新与维护」一键更新即可。

### 本版亮点

#### 重复文件，不必对着满屏名字发愁

检测改为后台扫描，页面直接读取结果，不再每次打开都重算全库。结果分为「可以放心清理」「建议清理」「需要你决定」，HDR、SDR 或分辨率不同等取舍可以成组处理。文件名差异、大小和码率更好比较，过期的结论不会用于清理。

#### 蓝光原盘，也能直接点播放

网页播放器和 Jellyfin 客户端支持蓝光原盘播放，单剪辑直接输出，多剪辑按播放列表转封装。原盘也不会再让客户端的「最近添加」整行报错。

#### 首页显示哪些片单，由每个人自己决定

每位成员可调整首页行的显示、顺序、排序和名称，添加媒体库或合集行。支持只看没看过的、随机排序和恢复默认；合集页也能直接选择显示在首页。

### 其他新功能与改进

- **取消订阅可顺手清理**：按订阅覆盖的范围清理种子与文件，取消某季后也可以按季清；跨季包会保留。
- **后台少拖慢前台**：定期对账跳过没变化的目录，扫描等任务在前台请求繁忙时让路，合集也减少重复查询。
- **定时任务可自己安排**：在「设置 → 应用 → 定时任务」调整周期与启停，查看上次、下次执行时间。
- **网络挂载提示更准确**：NFS、SMB 等目录不再建立无效实时监听，说明新文件由定期对账发现。
- **浏览和播放更轻**：换排序只刷新影片墙，收藏与合集可排序；转码缓存能跨会话复用，并按实测带宽确定码率。
- **删除大文件少干等**：先完成库内移走，再在后台回收磁盘内容。

### 修好了

- 手机上第二根手指碰进度条、横屏拖动和快速松手，不再把跳转作废或退回起点。
- 拖到片尾不再从头重播，按住进度条时控制条也不会突然消失。
- 删库或删文件后，仍有关联的观看记录会保留，同作品重新入库可以接回进度。
- 洗版下载回来的升级版本，不再被入库去重错误挡住。
- 未知画质规格不会被直接当成最差，没解析出集号的文件也不再误判成重复。
- 重复扫描不再长时间占住接口，清理失败的结果不会假装已经成功。

### 升级须知

- 清理种子、媒体文件及删除影片仍是实际删除，请核对确认框中的范围；后台回收不提供恢复。
- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.24.0 → v0.25.0](https://github.com/movieclaw/MovieClaw/compare/v0.24.0...v0.25.0)。
