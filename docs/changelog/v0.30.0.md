## v0.30.0: Skip the intro and keep watching

Skip series intros with one click and automatically continue at the credits. Combine multiple libraries into home rows, enjoy more reliable web playback on slow networks, and meet MovieClaw's new Aurora identity.

> ✅ No Docker image update is required. Update from **Settings → Update & Maintenance**. Update the iPhone app to **0.3.0** as well.
> Mac transcoder users should update it for faster remote-transcoding startup and seeking. Older versions remain usable.

### Highlights

#### Skip intros, then continue when the credits start

MovieClaw compares episodes within a season to recognize intros, credits and opening sponsor segments. Skip Intro appears at the right moment; the credits trigger an Up Next countdown. After three episodes without interaction, automatic continuation stops. Web, app and Infuse playback are supported. Series libraries enable detection after upgrading, process new imports and gradually fill in existing shows, with currently followed shows first. Administrators can disable detection from a series library's menu → Edit Library.

#### Combine several movie libraries into one home row

All Movies, All Series and All Other Videos combine libraries of the same type without duplicating titles. Rows appear automatically when at least two libraries share a type, or you can add them through Library → Customize Home → Add a Row.

#### More reliable web playback, with faster startup

When bandwidth is low, the web player offers a lower quality rather than silently switching. It reconnects after interruptions, explains missing files and remembers quality per title. Some MP4 and large TS files now start in seconds rather than waiting a minute or two. This takes effect after upgrading.

### More features and improvements

- **Aurora branding**: New icons across apps, the web, Mac transcoder and browser extension, including a favicon.
- **Smoother HEVC on iPhone web**: Skipping intros and seeking in Safari avoids short stalls.
- **GitHub access tokens**: Add a token in Update & Maintenance if update checks report rate limiting.
- **Clearer member permissions**: Members manage their own collections and subscriptions; Tracker Search becomes Resource Search.

### Fixed

- Seeking during 4K playback on iPhone web no longer misaligns subtitles or produces a black screen.
- Longer versions in Infuse retain their resume point instead of being marked watched prematurely.
- First scans of large series libraries no longer fail imports with database-lock errors.
- The app's bottom Continue Watching control shows only playback on that device, without mixing in Infuse activity.
- Corrected orphan-file cleanup errors in Cache Management and other details.

### Before you update

- Background intro and credit detection uses disk and CPU resources, and pauses when someone is watching.
- This release migrates the database. To return to v0.29.0 or earlier, restore the automatic pre-update backup.

Full changes: [v0.29.0 → v0.30.0](https://github.com/movieclaw/movieclaw/compare/v0.29.0...v0.30.0).

## v0.30.0：追剧不用再拖片头

这一版让追剧省事了：剧集能一键跳过片头、片尾自动接下一集。首页可以把几个库的电影合成一行，
网页播放器在慢网络和出错时也更稳。movieclaw 还换上了新标志「极光」。

> ✅ 本版无需更新 Docker 镜像，在「设置 → 更新与维护」一键更新即可。iPhone App 请同时更新到 0.3.0。
> 用 Mac 转码器的，建议同时更新转码器，远程转码起播、拖进度会更快；不更新也照常能用。

### 本版亮点

#### 一键跳过片头，片尾自动接下一集

连着刷剧时，每集都要手动拖过同一段片头。现在 movieclaw 会把同一季的各集互相比对，
自动认出片头、片尾和片头前的冠名广告：播到片头时出现「跳过片头」，片尾一开始就弹出
「即将播放」，倒计时走完自动放下一集，连续三集没人操作就停下。网页、App 和 Infuse 都能用。
剧集库升级后自动开启，新集入库时顺手识别，已有的剧在后台慢慢补，正在追的剧排在最前。
不想要的话，管理员可在该剧集库页的 ⋯ →「编辑库」里关掉「识别片头片尾」。

#### 几个库的电影，首页合成一行

电影分在好几个库里，首页只能一个库一行地翻。现在首页多了「全部电影」「全部剧集」
「全部其他视频」，把同类型的库合成一面墙，同一部片只出现一次。同类型有两个及以上的库时
自动出现；也可以在「媒体库」页的「自定义首页」→「＋ 添加一行」里自己加。

#### 网页看片更稳、起播更快

网速慢时网页播放器不再偷偷降画质，而是像 App 一样提示你换低一档；断线自动重连，文件找不到直接说明，
画质按每部片分别记住。部分 MP4 和大体积 TS 文件首次播放从等一两分钟缩到几秒。升级后自动生效。

### 其他新功能与改进

- **新标志「极光」**：App 图标、网页、Mac 转码器、浏览器扩展全部换新，网页标签页也有了图标。
- **iPhone 网页播 HEVC 更顺**：Safari 里跳过片头、拖进度不再停顿一两秒。
- **GitHub 访问令牌**：检查更新提示「GitHub 限流」时，可在「设置 → 更新与维护」里填一个令牌。
- **成员权限更严谨**：成员只能管理自己建的合集和订阅，「站点搜索」更名为「资源搜索」。

### 修好了

- iPhone 网页播放 4K 片拖动进度后，字幕对不上、画面黑屏，现在不会了。
- 用 Infuse 看多版本影片的长版时，没看完就被标成已看、续播点丢失，现在不会了。
- 首次扫描大剧集库时报「database is locked」、文件入不了库，现在不会了。
- App 底部「接着看」只显示这台设备上的播放，不再混进 Infuse 里看的片。
- 以及「缓存管理」里清理孤儿文件报错等细节修复。

### 升级须知

- 升级后剧集库会在后台识别片头片尾，会占用一些读盘和 CPU；有人在看片时自动暂停。
- 本版升级了数据库。之后如需回退到 v0.29.0 或更早版本，请用更新前自动生成的备份恢复。

完整改动见 [v0.29.0 → v0.30.0](https://github.com/movieclaw/movieclaw/compare/v0.29.0...v0.30.0)。
