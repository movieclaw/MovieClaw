## v0.20.0：发张图给助手，再教它你的做事习惯

这一版让 AI 助手支持图片、思考强度和自定义技能。长任务中途停止或服务重启后，对话也更容易继续。

✅ 已使用 v0.19.0 对应镜像的用户无需更新 Docker 镜像，在「设置 → 更新与维护」一键更新即可。

### 本版亮点

#### 海报、截图、报错，可以直接给助手看

网页对话支持上传图片，输入框和消息里都有预览。暂存图片会自动清理，避免越聊占用越多空间；使用前请选择支持看图的模型。

#### 想让它多想一会，或按你的流程做

输入框可按模型能力选择思考档位，续聊时沿用。自定义技能可以教助手一套固定流程，直接让它「帮我创建一个技能」即可；对话里用 `/skill:名字` 选择调用。

### 其他新功能与改进

- **输入更顺手**：斜杠选择技能，技能以标签显示，旧对话继续可用。
- **中断后更容易续聊**：异常重启时修复会话状态，点停止后保留中断说明，相关后台命令也会结束。
- **模型目录更新**：补充多家供应商的新模型与思考能力声明。
- **文件探测失败会重试**：网络挂载临时抖动后自动补探，持续损坏的文件避免反复长时间等待。

### 修好了

- 蓝光原盘不会再被同分辨率的 Remux 当作更好版本替换掉，历史片源信息会自动补齐。
- 仍在订阅追踪、尚未入库的作品，现在也能刷新元数据和选择图片。
- 修复助手停止、附件校验和技能输入的若干问题。

### 升级须知

- 模型目录移除了 Kimi k2.5，重新保存供应商配置时需改选目录中的可用模型。
- 命名模板使用 `{media_source}` 且库里有 ISO 时，下次整理会把对应片源写成 `Disc`；原盘目录仍整体跳过整理。

完整改动见 [v0.19.0 → v0.20.0](https://github.com/movieclaw/MovieClaw/compare/v0.19.0...v0.20.0)。
