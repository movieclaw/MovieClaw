## v0.12.0: Better filters for finding films, and a clearer view of your subscriptions

Combine discovery filters and browse complete lists. The library home adds recent viewing, subscription updates and collection progress are clearer, and AI conversations can reconnect after interruptions.

✅ If you already use the image for v0.10.0, no Docker image update is required. Update from **Settings → Application**.

### Highlights

#### Combine the filters for the film you want

Filter discovery by genre, origin, year, rating, runtime and sort order. Conditions stay in the page URL through refreshes, navigation and sharing. Lists support full pagination, alongside entries for today's popular titles, recent highly rated films and miniseries.

#### Find where you left off from the home screen

Recent viewing is separate for each member and shows progress, the latest watched episode and new episode counts. A series appears as one card, within the account's visible-library boundaries.

#### See today's subscription updates together

The subscription home separates movies and series, with today's updates, collection summaries and continuing-subscription indicators. Import estimates combine search intervals, historical durations and live download progress; same-day updates are grouped.

### More features and improvements

- **Continue conversations**: Web and CLI share sessions with continuation, retry, stop and reconnection support.
- **Lighter large-library browsing**: Scans summarize counts and file sizes instead of pages repeatedly traversing the entire library.
- **Smaller image transfers**: Sized artwork caches reduce mobile traffic and repeated NAS encoding.
- **Return to the right context**: Detail navigation retains filters, and subscriptions link directly to related active tasks.

### Fixed

- Subscription lists now follow recent activity rather than remaining ordered by creation time.
- Fixed missing episode-statistics fields after some interrupted migrations.
- Player forwarding rules no longer intercept conversation detail requests.
- Corrected forecast timing, selected unaired episodes when future tracking is off, and full-pack sampling.

### Before you update

- This release migrates the database and repairs episode statistics. Restore the automatic pre-update backup when rolling back across versions.

Full changes: [v0.11.0 → v0.12.0](https://github.com/movieclaw/MovieClaw/compare/v0.11.0...v0.12.0).

## 简体中文

## v0.12.0：找片有筛选，追更有总览

这一版让发现页能组合筛选、浏览完整片单，媒体库首页加入最近观看。订阅当天更新与收录进度更清楚，AI 对话也能断线接回。

✅ 已使用 v0.10.0 对应镜像的用户无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 想找哪种片，条件可以一起选

发现页支持按类型、产地、年份、评分、片长和排序组合筛选。条件保存在页面地址里，刷新、返回和分享都能保留；榜单与片单可以分页看完整内容，还有今日热榜、近期高口碑、迷你剧等入口。

#### 上次看到哪，首页就能找到

媒体库首页新增按成员隔离的「最近观看」，展示进度、最近看的分集与新增集数。同一部剧聚成一张卡片，也会遵守当前账号的可见库范围。

#### 今天更新了什么，订阅页集中看

订阅首页按电影和剧集分区，新增今日更新、收录摘要与自动续订标识。预计入库时间结合搜索间隔、历史耗时和实时下载进度，同日连续更新会合并展示。

### 其他新功能与改进

- **对话可以接着来**：网页与 CLI 使用统一会话，支持继续、重试、停止和断线接回。
- **大库浏览更轻**：库存数量和文件大小在扫描时汇总，页面不再反复遍历整库。
- **海报传输更省**：图片按尺寸缓存，减少手机流量和 NAS 重复编码。
- **返回更符合来路**：详情页保留筛选上下文，订阅页可直接打开相关进行中任务。

### 修好了

- 订阅列表会按最近活动排序，不再一直按创建时间排列。
- 修复部分升级中断后分集统计字段缺失的问题。
- 会话详情不再被播放器接口的转发规则误拦。
- 修正部分预测时间、关闭追新后的待播集预测和全集包采样问题。

### 升级须知

- 本版升级了数据库，并自动修复分集统计。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.11.0 → v0.12.0](https://github.com/movieclaw/MovieClaw/compare/v0.11.0...v0.12.0)。
