## v0.14.0：片库自动换好版本，分享率也有人照看

这一版带来自动洗版和站点分享率保护。旧资源可以按偏好替换成更好的版本，下载、入库和洗版进度也更清楚。

✅ 已使用 v0.10.0 对应镜像的用户无需更新 Docker 镜像，在「设置 → 应用」一键更新即可。

### 本版亮点

#### 已经收好的片子，也能继续升级画质

洗版会为库里的电影和剧集寻找更好的版本，完成下载、替换与旧文件回收，也能在详情页手动挑选。无法判断现有片源时，可以先人工标注；任务和订阅卡片会显示替换进度。

#### 分享率接近红线，自动抢免费种补一补

站点可开启分享率保护，临近红线时选择免费种刷流。配合预算、下载器限速和队列管理，并按站点实际 H&R 考核与做种时间决定何时汰换。

### 其他新功能与改进

- **先看预告再决定**：发现详情页加入预告片展示与内嵌播放。
- **未上映的片少白搜**：电影订阅按上映节奏安排搜索。
- **不输关键词也能逛资源**：站点搜索留空，按分类浏览最新种子。
- **任务卡说清卡点**：剧集按分集显示进度，系统取消会说明原因，刷流不再占侧栏提醒数字。
- **站点登录故障更明确**：透传真实原因，验证成功后清除旧错误和等待排期。
- **弱网少一次外联**：字体改为本地提供，页面不再依赖 Google Fonts。

### 修好了

- 旧版 qBittorrent 保存限速、队列设置时，不再误报无法连接。
- 修复洗版入库、同档去重和来源记录问题，挂起批次不再拖累其他已完成分集。
- 缺集订阅不再反复抓同一个缺内容的种子，也不再永远等待不存在的特别篇。
- M-Team 积分商城的单种免费期间，现在按全免费计费。
- 手机上可以展开媒体库「最近添加」的信息。

### 升级须知

- 建议在模型更新中安装 `torrent-ner-v3`，配合更准确的单集文件识别。
- 本版升级了数据库。如需跨版本回退，请用更新前自动生成的备份恢复。

完整改动见 [v0.13.0 → v0.14.0](https://github.com/movieclaw/MovieClaw/compare/v0.13.0...v0.14.0)。
