## v0.46.0: The air schedule is easier to scan

On a series, the season progress bar is gone. Episodes opens with what airs today or next, and Air schedule groups the days into this week, next week, and later.

> ✅ Update from Settings → Updates and maintenance. This release migrates the database and makes a backup first. MovieClaw Server 0.45.0 still runs if you restore that backup; see Before you update. The Docker runtime stays 25.

### Highlights

#### The air schedule reads as two lines

Open a series that still has an air date today or later. Under **Episodes**, the progress bar and its legend are gone. The first line names what airs today or next, such as **S02E03–E04 airs**, with the expected arrival on the right. The second line is the cadence, how many episodes are left, and the finale. **Air schedule** opens the sheet: a large remaining count, a collapsed summary of what already aired with **Find this episode**, and rows grouped into **This week**, **Next week**, and **Later**. The weekday sits on its own line. The date, the dot, the episode number, and the status share one row. A gap appears only when a real break skips a cadence weekday.

iPhone 0.12.2 and Android 0.9.2 show the same layout. Older apps keep the progress bar and still work on this server. The website shows the new layout with this server.

### Fixed

- A download that is only an E00 pilot stays under **Pending** instead of being marked finished and disappearing. A season pack that also has real episodes still skips the E00 and completes.
- The same cloud file is no longer kept as two empty ledger rows. The upgrade drops the extra empty row and recounts that library's file count and size. Files on the cloud drive, and local files that have bytes, are not deleted. Removing one library entry no longer deletes the cloud file while another entry still points at it.
- **Local speech recognition (本地语音识别)** keeps a finished subtitle when the dialogue is sparse, such as a short film or a long stretch of silence. An empty result is still discarded.
- On the home hero, **Settings → Appearance and language → Interface effects** is honored: **Background blur (蒙版模糊度)** and **Background darkness (蒙版暗度)** are no longer overridden. Blur at 0 turns the shared scrim filter off. After you sign in, the startup screen unmounts once it fades, instead of staying on top of the page.
- After a restart, a background task whose lease expired is queued again. The old run gives up its slot, so the list does not sit at "all queued" while nothing runs. While plugins are still loading, a plugin's task stays in the queue instead of being taken as an unknown type.

### For administrators

- A plugin can register a library source next to the built-in ones. With such a plugin installed, the create-library wizard lists it and asks for the connection fields that plugin declares. With no such plugin, the wizard is unchanged. No external source ships in this release. Jellyfin clients see an external library only when that source says to expose it; disabling the plugin hides it.

### Before you update

- The first migration adds optional columns on each library (`source_config`, `last_source_sync_at`). Restoring the backup and running 0.45.0 ignores those columns.
- The second migration removes duplicate empty cloud-ledger rows for the same remote file and recounts library stats. It does not delete cloud bytes or local files that have content. Restoring the backup puts those rows back. Running 0.45.0 on this database, without that restore, does not recreate the removed rows.

Full changes: [v0.45.0 → v0.46.0](https://github.com/movieclaw/MovieClaw/compare/v0.45.0...v0.46.0).

## 简体中文

## v0.46.0：播出日历更好读

剧集详情里，本季进度条没有了。分集标题下先写今天或下次更新哪几集，播出日历再按本周、下周和之后分组。

> ✅ 在「设置 → 更新与维护」里更新。这一版会迁移数据库，并先做备份。要回到 MovieClaw 服务器 0.45.0，请恢复这份备份；见文末「升级须知」。Docker 运行时仍是 25。

### 本版亮点

#### 播出日历改成两行

打开一部本季还有今天或以后播出日期的剧。在「分集」下面，进度条和图例没有了。第一行写今天或下次更新的集，例如「S02E03–E04更新」，右边是预计入库时间。第二行是更新节奏、还剩几集，以及大结局。点「播出日历」打开面板：上面是还剩多少集，已播出的摘要可以收起，里面有「补这一集」；下面按「本周」「下周」「之后」分组。星期单独一行。日期、圆点、集数和状态在同一行上对齐。只有真的跳过了一个播出日，才会出现停更分隔。

iPhone 0.12.2 和 Android 0.9.2 是同一套版式。更早的 App 仍显示进度条，在这台服务器上照常用。网页随这一版服务器换成新版式。

### 修好了

- 一份只有 E00 先导的下载会留在「待处理」，不再被标成完成后从清单里消失。季包里还有正片时，仍跳过 E00 并正常完成。
- 同一个网盘文件不再记成两笔空账。升级时去掉多出来的空账，并重算这个库的文件数和容量。网盘上的文件，以及本机有内容的文件，不会被删。删掉一条片源记录时，如果另一个条目还指着同一个网盘文件，不会把网盘文件一起删掉。
- 「本地语音识别」在识别已经做完、对白却很稀（短片、长段静音）时，会留下字幕。空结果仍然丢掉。
- 首页大图不再改写「设置 → 外观与语言 → 界面质感」里的「蒙版模糊度」和「蒙版暗度」。模糊度调到 0 时，共用蒙版不再模糊。登录之后，启动画面淡出就会卸掉，不再盖在页面上。
- 服务器重启后，租约过期的后台任务会重新排队。原来的那次执行会让出位置，任务列表不会停在「全是排队、实际没有在跑」。插件还在加载时，插件自己的任务留在队列里，不会被当成未知类型领走。

### 管理员须知

- 插件可以登记一种和内置库并列的媒体库来源。装了这种插件之后，建库向导会列出它，并按插件声明的字段询问连接配置。没装时，向导和以前一样。这一版没有自带任何外部来源。Jellyfin 客户端只在该来源声明要暴露时才看得到这个库；停用插件后，这个库会从客户端列表里消失。

### 升级须知

- 第一次迁移给每个媒体库加上可空的列（`source_config`、`last_source_sync_at`）。恢复备份再跑 0.45.0 时，这些列会被忽略。
- 第二次迁移去掉同一个网盘文件的重复空账，并重算媒体库统计。它不删网盘上的文件，也不删本机有内容的文件。恢复备份会把这些行带回来。不恢复备份、直接用这份数据库跑 0.45.0，不会把去掉的行造回来。

完整改动：[v0.45.0 → v0.46.0](https://github.com/movieclaw/MovieClaw/compare/v0.45.0...v0.46.0)。
