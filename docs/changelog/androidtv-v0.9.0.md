## Android TV 0.9.0: Browse a local actor's work with the remote

Cast cards in local and NFO libraries can now open every title by that actor in the same library, even when no online person page exists. The Android TV interface remains Chinese.

> ✅ Works with MovieClaw Server 0.28.0 or later, the same as 0.8.0. The new actor-filtered wall requires Server 0.48.0 or later. Install from https://movieclaw.io/download/androidtv.apk

### Highlights

#### Go from an actor to the matching poster wall

On an item detail page, focus an actor who has no online person page and press the remote. Android TV opens that same library with **演员：姓名** in the wall summary; use **移除演员：姓名** in the sort and filter menu to return to all titles. Actors with an online person page still open that page, and directors without one remain static.

Thanks to @Migflyway. Full changes: [androidtv-v0.8.0 → androidtv-v0.9.0](https://github.com/movieclaw/MovieClaw/compare/androidtv-v0.8.0...androidtv-v0.9.0).

## 简体中文

## Android TV 0.9.0：用遥控器找到本地演员的同库作品

本地库和 NFO 库里的演员卡现在也能打开这位演员在同一媒体库中的全部作品，不再依赖在线影人页。Android TV 界面仍是中文。

> ✅ 搭配 MovieClaw 服务器 0.28.0 或更新版本即可使用，与 0.8.0 相同。新的演员筛选海报墙需要服务器 0.48.0 或更新版本。从 https://movieclaw.io/download/androidtv.apk 安装。

### 本版亮点

#### 从演员直接进入对应海报墙

在条目详情页把焦点移到没有在线影人页的演员，再按遥控器。Android TV 会打开同一媒体库，并在海报墙摘要中显示「演员：姓名」；从排序与筛选菜单选择「移除演员：姓名」即可回到整库。带在线影人页的演员仍进入影人页；没有影人页的导演仍不可点。

感谢 @Migflyway。完整改动：[androidtv-v0.8.0 → androidtv-v0.9.0](https://github.com/movieclaw/MovieClaw/compare/androidtv-v0.8.0...androidtv-v0.9.0)。
