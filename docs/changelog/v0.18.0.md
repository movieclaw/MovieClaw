## v0.18.0：打开浏览器，就能直接看片

这一版带来网页播放器，支持续播、剧集连播、字幕和手机手势。忘记管理员密码也能离线重置，Infuse 的播放与搜索问题一并修复。

> ⚠️ **本版需要更新 Docker 镜像**：网页播放新增硬件转码能力，请拉取 `movieclaw/movieclaw:v0.18.0` 并重建容器，旧镜像无法承载本版。

### 本版亮点

#### 自己的片库，网页里直接播放

从影片详情或最近观看进入播放器，就能接着上次的位置看，剧集支持切换下一集。浏览器能直接播放时保留原画质，只有格式不支持时才转封装或转码；在「设置 → 播放」可以检测服务器的硬件加速能力。

#### 字幕、进度和手机操作，都跟上了

支持普通文字字幕、ASS 特效字幕和 PGS 图形字幕，音轨与字幕选择会记住。拖进度条能看缩略图，手机可滑动调亮度和音量、双击全屏；iOS Safari 支持系统全屏与画中画。诊断面板能查看播放方式、硬件加速和首帧耗时。

#### 忘记管理员密码，不必删库重来

在宿主机执行 `docker exec -it movieclaw python -m movieclaw_api.reset_password`，就能重置密码。用户名、站点、下载器、媒体库和订阅保留，完成后可立即登录。

### 其他新功能与改进

- **订阅逐集查进度**：按季折叠，每集展开搜索、投递、下载、入库和洗版过程。
- **音轨字幕更好选**：按语言分组，手机用抽屉查看完整规格。
- **刷流可暂停恢复**：站点菜单里限速让路，保留种子和数据；选种汰换也更贴合实际收益。
- **片源偏好更直接**：订阅规则支持媒体来源白名单与排序。
- **外挂字幕可删除**：管理员在详情页确认完整路径后删除，内封字幕不提供此入口。
- **对话可另开一条继续**：把当前上下文带入独立的新会话。

### 修好了

- Infuse、Apple TV 播放反复转圈、连带媒体库空白的问题得到修复。
- Infuse 搜索不再总是空结果，分集标题也能搜到。
- AI 字幕使用思考型模型时不再因输出被截断反复失败，断点里的失败块可以重新翻译。
- 站点账号密码登录能正确处理表单和特殊字符。
- 活动页传输量不再随连接切换归零，刷新时侧栏导航顺序也不再闪跳。

### 升级须知

- 软件转码可能占用较多 CPU，播放器会按设置征求启用确认。
- iOS 主屏 PWA 无法启用画中画时，请按页面提示用 Safari 打开。

完整改动见 [v0.17.0 → v0.18.0](https://github.com/movieclaw/MovieClaw/compare/v0.17.0...v0.18.0)。
