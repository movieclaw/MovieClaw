## Apple TV 0.9.0: Dolby Vision color fix

This is a stability update: some Dolby Vision films should no longer play with a purple or green tint. The version jumps from 0.7.0 to 0.9.0 to match the other Apple apps; there was no Apple TV 0.8.0.

> ✅ Works with MovieClaw Server 0.28.0 or later, the same as 0.7.0. Install from TestFlight.

### Fixed

- Some films marked Dolby Vision but carrying an HDR10 picture (often "DV HDR10+ Hybrid" releases) played with a purple or green tint. They should now play in correct HDR10 colors. Playing them at a lower quality needs Server 0.39.0.

Full changes: [tvos-v0.7.0 → tvos-v0.9.0](https://github.com/movieclaw/MovieClaw/compare/tvos-v0.7.0...tvos-v0.9.0).
