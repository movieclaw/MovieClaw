## v0.2.0: Updates and conversations, all in one place

This release introduces in-app updates and WeChat pairing. Upgrade or roll back without reworking your deployment, and search your own library alongside movies and resources.

✅ No Docker image update is required. Update from **Settings → Application**.

### Highlights

#### Install new versions from the web interface

Check for updates in Settings → Application to install a new version or roll back. The torrent recognition model can be updated separately, and update files support signature verification.

#### Talk to your media assistant in WeChat

Configure an AI model, then scan the pairing code to connect WeChat. Long conversations automatically compress their context. Set an external access URL so replies and notifications can include links directly to the relevant pages.

### More features and improvements

- **Search your library**: Library search joins the Movies & TV and Resources search categories.
- **Import cloud-drive content**: Recognize strm placeholder files, with guidance for adding unmatched titles manually.
- **Browse by letter**: The library index supports sliding to select a letter.
- **Manage the application in one place**: Set the external access URL and restart the application from Application settings.

### Before you update

- Future versions can be installed in-app. Releases that add runtime dependencies will still require a Docker image update, as explained in their release notes.

## 简体中文

## v0.2.0：更新和聊天，都能在这里完成

这一版带来应用内更新和微信绑定。升级、回退不必再折腾部署，找库里的片子也多了一个搜索入口。

✅ 本版无需更新 Docker 镜像，在「设置 → 应用」内即可更新。

### 本版亮点

#### 有新版本，在网页里一键升级

在「设置 → 应用」检查更新，就能直接安装新版本，也能一键回退。种子识别模型可以单独更新，更新文件支持签名校验。

#### 在微信里，直接找影音助手

先配置 AI 模型，再扫码绑定微信，就能把影音助手接进日常聊天。长对话会自动压缩上下文，设置好外部访问地址后，助手的回复和通知还可以带上能直接打开的页面链接。

### 其他新功能与改进

- **搜索自己的片库**：搜索新增「媒体库」，和影视、资源搜索并列。
- **网盘内容也能入库**：支持识别 strm 占位文件，找不到匹配时会引导你补录。
- **按字母找片更顺手**：媒体库字母索引支持滑动选择。
- **维护入口集中了**：「应用」设置里可以填写外部访问地址，也能重启应用。

### 升级须知

- 从本版起可以在应用内安装后续更新；遇到后续版本新增运行时依赖时，仍需按该版说明更新 Docker 镜像。
