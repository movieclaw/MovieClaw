# Apple TV 首页：GPU 合成瓶颈（2026-10）

状态：首屏大图区已优化（本文 §3）。卡片行、换片过渡等其余场景未逐项测量。

## 1. 结论

Apple TV 4K 二代（A12，输出 3840×2160）上，首页即使静止不动也只有约 30 帧：

- **主线程不是瓶颈**：App 每帧提交只要 1～2 毫秒；XCTest 的 `XCTHitchMetric` 在「接下来继续」里左右换卡 3 轮，App 侧卡顿 0 次。
- **瓶颈在 GPU 合成**：每帧 30 次离屏渲染，GPU 每帧 50～59 毫秒（预算 16.7 毫秒）。Instruments 对这些卡顿给出的原因都是「GPU 开销可能过大」。
- **主要来源是大图区的两层全屏遮罩**：剧照（连同预告）的下沿渐隐、左侧托字的黑，各套了一层全屏遮罩。剧照慢推（40 秒推近到 1.06 倍）、预告视频让画面每帧都在变，每帧都要在 4K 下把整块画面离屏渲染两遍。

## 2. 怎么测

### 指标

| 指标 | 来源 | 说明 |
| --- | --- | --- |
| GPU 每帧耗时 | Instruments「Animation Hitches」的 `hitches-gpu` 表 | 超过 16.7 毫秒就掉帧 |
| 离屏渲染次数 | `hitches-renders` 表的 `offscreen-passes` | 每帧固定，录到一帧就能看 |
| 渲染进程每帧耗时 | `hitches-renders` 表 | |
| App 提交耗时 | `hitches-updates` 表（按进程过滤） | 主线程侧 |
| 实际出帧率 | 相邻两帧的间隔 | |
| App 侧卡顿比 | `XCTHitchMetric` | 只统计 App 提交慢造成的卡顿，GPU 一侧的不算 |

模拟器跑在 Mac 的 CPU、GPU 上，合成与解码路径都和真机不同，这些数只能在真机上量。

### 在真机上操作

- 遥控器：XCUITest 的 `XCUIRemote`。真机上的测试进程读不到 Mac 的文件，改为轮询 Mac 上的一个 HTTP 指令服务取指令。
- 要关掉 XCUITest「每次按键前等 App 空闲」：首页有慢推和预告视频，几乎永不空闲，按键会被拖到几秒一下、最后等超时。做法是在**测试进程**里把 `XCUIApplicationProcess` 等空闲的方法换成空操作，不碰 App。
- 每次按键后查焦点要 App 交出一次无障碍树，会占它的主线程。测量时不查。
- 用 Release 构建：开发签名就能被 Instruments 采样，也能跑 UI 测试；Release 不认调试登录参数，直接用电视上已登录的账号。

### Instruments 的限制（Xcode 27 + tvOS 27，局域网连接）

- `xctrace record --attach` 找不到电视上的进程，`xctrace list devices` 一直把电视列为离线；只能 `--all-processes` 录全系统。
- 每次只能录到 1～3 秒就报「设备断开」，卡顿数据又要到开录约 0.7 秒后才出现，一次快照常常只有十几到几十帧。所以只用来量**稳定画面的每帧固定成本**，不够 30 帧就重录。
- 与 UI 测试同时跑时，`--attach` 方式会把测试连接一起断掉（`Lost connection to testmanagerd`）；`--all-processes` 不会。
- 同一时间只能有一组测量在跑：两组同时跑会互相重启 App，数据全乱。

## 3. 优化：大图区去掉全屏遮罩（画面不变）

首页剧照底下垫的是一种纯色（剧照边缘色，取到之前是电视底色），所以：

1. **剧照下沿渐隐**：「剧照经遮罩渐隐、露出底下的纯色」等于「剧照上盖一层从透明渐变到同一种颜色的渐变」。剧照半透明、换图交叉淡入时也逐项相等。
2. **托字的黑**：首页的黑是横向渐变（左 10% 满强度，屏宽 65% 处淡完）乘上同一条下沿渐隐，形状固定，只有深浅随剧照变。预先算成一张 960×540 的图，深浅用整层透明度给。透明度按渐变色标逐段线性插值算，与 SwiftUI 画渐变时一致。

详情页剧照底下是模糊剧照，不是纯色，不适用，仍用遮罩。

整体的 `compositingGroup()` 保留：单独去掉它 GPU 时间没有变化（约 22 毫秒，与只做第 1 步时相同）。

### 画面一致性

模拟器上关掉慢推与预告，同一时刻截图：新旧做法两张截图**逐像素相同**（差值全为 0）。换片时边缘色 0.8 秒渐变的过程逐帧量下半屏亮度，新旧终值相同，过程同样平滑。

### 真机结果

A12 Apple TV 4K 二代，NAS 真实数据，首屏静置（焦点在「播放」上，预告在放），新旧交替各 3 轮：

| | GPU 每帧（均值） | 实际出帧 | 离屏次数 / 帧 | 渲染进程每帧 | App 提交每帧 |
| --- | --- | --- | --- | --- | --- |
| 旧 | 52.0 / 45.3 / 50.2 毫秒 | 30.0 / 32.5 / 30.0 帧 | 30 | 12～14 毫秒 | 2～3 毫秒 |
| 新 | 10.1 / 11.2 / 11.3 毫秒 | 59.9 / 59.9 / 57.8 帧 | 17～24 | 11～12.5 毫秒 | 2～2.5 毫秒 |
