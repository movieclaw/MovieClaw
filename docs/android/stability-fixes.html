P1MKV 索引读取

P1过期心跳恢复

后续优化与验收

  1. 真机回归：MKV/HLS 多次 seek、快速点播和画质切换、过期会话恢复、MPV HDR/ASS、Surface 重建、通知控制、Reels 重播与离页。覆盖离线、慢网、503、低存储和 Exo-only 包。
  2. P2 缓存生命周期：退出登录清缓存时仍可能有 Exo/Reels/预取读者。后续用统一 lease / 引用计数定义安全清理时机；本轮未重构 clear/release 接口。
  3. ISO HTTPS：目前明确拒绝；使用成熟 TLS 传输接入，禁止把 HTTPS 请求按明文发送。
  4. 原盘能力：目前选择最大 M2TS。MPLS 多片段、seamless branching、libbluray / BD-J 是独立工作，不能靠生命周期修复承诺支持。
  5. ISO DNS 取消：socket shutdown 不能中断 getaddrinfo；开卷/清理在 IO 线程，但慢 DNS 仍可能延迟退出。
  6. 设备能力：后续按真实 Codec / HDR 能力与设备兼容性数据细化申报；本轮只收紧 MPV 可用性和画质限制。
