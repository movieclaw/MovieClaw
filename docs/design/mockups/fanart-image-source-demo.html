Q1海报卡在「TMDB 默认」模式下，怎么和 Fanart 比？

「TMDB 默认」的意思是直接用 TMDB 指定的那张海报，不按语言挑。现在 Fanart 也要参与海报，两者需要一个比较规则。

TMDB 只拿出指定的那一张，和 Fanart 的海报按语言比demo 里就是这么做的。Fanart 没有图或者被关掉时，结果和今天完全一样；Fanart 有更靠前语言的海报时才会换掉。比较用的是海报卡里的语言优先级，所以 Fanart 开着时，默认模式下那组语言芯片要能编辑（今天在默认模式下是灰的）。
Fanart 开着时强制按语言模式规则更简单，但用户在海报卡里选的「TMDB 默认」会悄悄失效，而且 TMDB 内部的选图结果也会跟着变。

Q2填了 Key，但 Fanart 开关关着时，换图弹层要不要显示 Fanart 的候选？

显示开关管的是自动选图，手动换图本身就是用户明确想用。有 Key 就说明这个渠道可用。
不显示开关同时管自动和手动，概念最统一，但用户想手动挑一张中文 Logo 得先去设置里打开开关。

Q3季海报用哪套语言优先级？

建议跟随海报卡的语言优先级，不再单开一张卡。季海报和海报长得一样，口味通常一致。

Q4Key 失效了（被撤销、填错）怎么办？

建议：刮削时跳过 Fanart、不影响 TMDB，日志里写一条中文说明；图片来源卡上的状态变成红色的「Key 已失效」，点开就是同一个 Key 表单，可以重新填。不额外发通知。

Q5默认的来源顺序

demo 里的默认顺序：海报 TMDB → Fanart，背景 TMDB → Fanart（TMDB 常有 4K，Fanart 背景固定 1920 宽），片名 Logo 和季海报 Fanart → TMDB（这两类 Fanart 的中文图更多）。

Q6iOS 设置页什么时候跟进？

iOS 也有刮削设置页（SettingsBScrapeModel.swift）。建议一期只做 Web 和后端，iOS 第二步再跟进；在那之前 iOS 上看到的是设置结果，只是不能改。
