# 跳过片头片尾的验证标准

本标准评估播放器真正跳过的内容，不以音频重复、OCR 命中、旧版本输出或测试跑通作为真值。
关联设计：[skip-intro.md](skip-intro.md)。适用于真人剧、动画、纪录片、综艺、教育/儿童节目；
地区、原声/配音、发行平台和片源版本分别记录，不假设同一剧名的边界一致。

## 1. 内容边界

| 内容 | 判定 |
|---|---|
| 正式片头、主题曲配固定标题/演职员蒙太奇 | 可标为 intro；本集独有剧情仍受保护 |
| 冷开场、前情回顾、本集独有镜头、对白、旁白及其承载的画面 | 受保护；回顾不默认并进片头 |
| 独立广告、厂标、许可证 | 可跳但单独记录类型；不可因中文开头贴零而覆盖剧情 |
| 黑底/白底/动画演职员表，无新增叙事 | 可标为 outro；歌曲尚在继续不决定终点 |
| 演职员文字叠在本集剧情、纪录画面、讲解或实验上 | 受保护，文字不能否决内容价值 |
| 彩蛋、片尾后剧情 | 受保护；片尾必须在其之前结束，不能 to_end |
| 下集预告 | 独立 preview；不能仅因在文件末尾就并进 outro |
| 综艺资料书页、引文、教育字卡 | 默认受保护；是否跳过须有独立语义依据 |
| 黑场、静音、无字幕、固定配乐 | 仅为边界线索，单独不足以证明可跳 |

可跳片段必须连续；中间插入受保护内容就分段。`to_end` 要求从片段终点至文件结束没有
彩蛋、剧情、预告等独立内容，不能仅用“距 EOF 很近”替代内容检查。

## 2. 标注证据

先写内容标签和可接受的边界区间，再比较算法。保留源文件大小、修改时间、音轨语言/索引、
视频时长、取帧实际时间和证据文件名。不同版本片源不能套用同一组标签。

1. 初筛覆盖首尾窗口，也包括没有检测结果的位置；不能只审查算法给出的片段。
2. 疑点与边界至少检查前后 10 秒上下文；边界附近按 0.5～1 秒连续抽帧，必要时扩大到
   完整剪辑段。单张图只能证明该帧内容，不能认证相邻几十秒安全。
3. 对照字幕事件、音轨时长/语言、波形、静音与音乐切换。重复音轨先去重；错封、短缺、解说
   或不同语言的音轨分别记录。音量低、波形相似或频谱有音乐，都不能证明没有对白。
4. 波形/频谱分析与实际听辨分别记录；仅做信号分析时不能写“听过且无对白”。画面、字幕和
   音轨矛盾，或缺少必要语义证据时，标为 `unknown`，不强行归入正确。
5. 边界记为区间，例如最后确认剧情的帧在 100.0 秒，首个确认片头的帧在 100.5 秒，则
   转场为 `[100.0, 100.5]`；不能将算法给出的 100.3 秒倒填为真值。

证据等级：A = 连续上下文与必要的声音/字幕语义均确认；B = 连续抽帧及可用字幕/音频信号确认，
仍有抽样限制；C = 稀疏截图或历史转述。等级单独统计，C 用于发现疑点，不作上线零误跳证明。

## 3. 指标与通过条件

- **误跳优先**：输出与已确认受保护区间的交集秒数、受影响集数、最长连续误跳分别报告。
  任意确认的重叠都是问题；≥0.5 秒阻止该候选规则通过，较短重叠回看逐帧，不直接舍入为零。
- **边界准确性**：先排除受保护内容，再看起止是否处于标注的允许区间。3 秒是可跳内容内部
  少跳的体验目标，不是允许越过 3 秒剧情。超出目标但未误跳，记为保守遗漏。
- **覆盖率**：分子为输出与独立标注可跳区间交集的并集长度；分母仅为已标注可跳长度。
  没有输出也进入遗漏统计。未完整标注全窗口时不报告“整集召回率”或“全库准确率”。
- **未知区间**：单独报告输出覆盖了多少未标注内容；不能从“未碰到已知剧情”推断全部正确。
- **类型与行为**：intro/outro/ad/preview 分类错误、重复按钮、区间相交、越过时长、to_end
  错误分别计数。不能用提高覆盖率抵消剧情误跳或误触发下一集。
- **回归门槛**：已有 A/B 级受保护标注不得新增误跳；确认的新正例须改善；按地区/类型、
  首集/中段/末集、整季/追更/缺集分别报告。被拒绝的规则也保留结果，避免反复试同一误区。

“零个已发现误跳”只描述已验证样本，不能宣称零风险。少量地区/类型和未知内容要显式列出。

## 4. 实验隔离与端到端

开发集和留出集按作品划分，避免同一季相似片头泄漏。先冻结候选规则和阈值，再打开留出集
结果；如果据其修改规则，它即成为开发证据，需另设留出集。历史已观察的作品不冒充新留出集。

每次行为改动同时验证：真实指纹 → 检测子进程 → 真实抽帧/OCR或注明的观测回放 → 存储 →
播放会话/Jellyfin 时间单位 → 跳转后内容。缓存冷/热、模型缺失、短片跳过核对、取帧失败、
倒序输入、部分季都必须保持保护规则；辅助候选字段不得落库或下发。

真实片源测试不得修改媒体和生产结果，缓存使用隔离目录。报告明确区分：新提取音轨、已有
指纹回放、真实画面流程、OCR 观测回放、合成视频与 API 替身；不把某一层通过写成全部层通过。
