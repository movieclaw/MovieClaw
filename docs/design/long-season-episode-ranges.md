# 长剧集分段选集

一季几百上千集（名侦探柯南在 TMDB 里一季 1186 集）时，分集区一次性摊开既难找也难滑。
各端统一改成「集段 + 本段分集 + 全部分集面板」，并且一切以「接着看的那一集」为锚。

交互原型：v2 Demo（iPhone + Apple TV，2026-10-10 用户确认）。

## 1. 锚点：接着看的那一集

- 服务端在分集接口（`library.items.list-episodes`、`playback.item.episodes`）返回 `resume_episode`：
  本季最近播放的那一集；它看完了取往后第一个没看完且有片源的；往后都看完了停在它本身。
  与首页「接下来继续」同一条规则（`season_resume_episode`）。
- 本季没播放过时为 null，客户端退回原规则：第一个看了一半的 → 第一个没看过的 → 第一集（有片源的优先）。
- 分享页的分集接口不给锚点（访客没有观看记录），走客户端原规则。
- **不要**再用客户端扫描结果覆盖服务端锚点：长剧里「第一个没看过的」可能是几百集前跳过的那一集。

## 2. 分段

- 本季分集 **超过 50 集** 才分段；≤50 集时各端界面与改版前完全一致（不出现段胶囊、面板入口）。
- 段按集号切：第 `floor((集号 - 1) / 50)` 段；空段不出现。段名用段内实际首末集号：`1–50`、`1151–1186`（en dash）。
- 段的状态只标一个：锚点所在的段带橙点。不标「整段看完」。

## 3. 锁定规则

| 时机 | 段 | 选中 / 焦点 |
|---|---|---|
| 进详情页 | 选中集所在的段 | 路由 / 通知指定了集就是那一集，否则是锚点；滚到它 |
| 打开「全部分集」面板（手机、网页、Mac） | 锚点所在的段 | 锚点格子描橙边并滚到可见 |
| 播放回来 / 刷新后锚点变了 | 新锚点所在的段 | 选中新锚点（看完 1050 → 1051–1100 段、选中 1051） |
| 刷新后锚点没变 | 不动 | 不动（保留用户在别的段的浏览） |
| 手动换段 | 那一段 | 段里有锚点选锚点，否则段首 |
| 换季 | 那一季锚点（或原规则落点）所在的段 | 同进详情页 |

## 4. 手机 / 网页 / Mac（指针与触屏）

- 分集区标题行：`分集` + 季选择 + 右侧 `全部 N 集 ›`（只在分段时出现，替代原来的「在库 x / y 集」位置；不分段时保持原样）。
- 标题行下一排段胶囊，横滑；选中段实心，锚点段右上角橙点。打开时把选中段滚到中间。
- 分集横排只放当前段的集；横排首尾各一张「← 上一段 / 下一段 →」小卡（第一段没有上一段，最后一段没有下一段）。
- 锚点那张卡左上角标「接着看」。
- 「全部分集」面板：标题「全部分集」+「在库 x / y」，一排段胶囊（打开时落在锚点段），下面数字宫格
  （手机 5 列；网页 / Mac 按宽度 8～10 列）。格子状态：已看 ✓、进度条、缺集虚线、锚点橙边、选中实心。
  点格子：关面板、选中那一集、段切到它所在的段、横排滚到它。
- 网页的面板走 Modal 基座（portal 到 body）。

## 5. 电视（Apple TV、Android TV）

- 季页签下面加一排段页签（只在分段时出现）。焦点移到哪一段，下面的横排就跳到那一段的入口集（锚点或段首）——
  与「焦点移到哪一季，下面就换成哪一季」同一套交互。
- 分集横排是**整季连续**的（懒加载），往右一直走会自然跨段，段页签的「当前段」跟着焦点所在的集走。
  跳段时直接定位，不播一长段滚动动画。
- 在段页签上**按确认**打开「全部分集」面板：左栏段列表（锚点段橙点），右边 10 列数字宫格；
  返回键关面板回到段页签；在格子上按确认关面板、焦点落到横排的那一集。首屏不加按钮。
- 从首屏往下进分集区，焦点落在锚点（或指定集）上，与现在一致。
- 锚点那张卡标「接着看」。

## 6. 性能

- 一季 1186 集的分集接口约 260KB、50ms（本机），一次取全季，客户端不分页。
- 手机横排只渲染当前段；电视横排与宫格都用懒加载容器。
