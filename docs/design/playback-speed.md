# 倍速播放

2026-10-19 定稿。目标：各端同一组档位、同一套记忆规则，入口按各平台习惯呈现。

## 引擎层：不换

各端已经在用平台自带的变速不变调，也是业界主流做法，这次不动：

| 端 | 实现 |
|---|---|
| iPhone / Mac / Apple TV（AetherEngine） | `TimeDomain` 时域伸缩；视频通路最高 2 倍（`maxSupportedRate`） |
| 安卓手机 / TV（Media3） | `setPlaybackSpeed`，底层 Sonic |
| Web | `playbackRate` + `preservesPitch` |
| Windows（mpv） | `speed`，自动插 `scaletempo2` |

影视以对白为主，时域法正合适。待真机实测：Atmos / E-AC-3 走 HDMI 直通时倍速的表现（压缩码流没法伸缩）。

## 档位

`0.5 / 0.75 / 正常 / 1.25 / 1.5 / 2`，各端同一组（Apple `PlaybackSpeed.all`、安卓 `PlaybackSpeeds.ALL`）。
最高 2 倍：自研引擎视频通路的上限，B 站、Infuse 也是 2 倍；安卓手机原来的 3 倍去掉。

## 记忆

- **按片记**：同一部剧换集、下次再打开都保持；换一部片从正常速度起（介于 Netflix「换片回 1x」与全局记忆之间）。
- 只存非正常速度，选回正常就删；最多 300 条，超出丢最久没用的（同画质记忆）。
- 访客分享、片段模式不记。
- 从记忆里取的倍速，开播提示「已沿用上次的选择」里点明（`倍速 1.5×`）。
- **长按 2 倍速**只是临时盖住所选那档，松手回到所选那档；长按期间在菜单改档，只改记着的那档。
- 换集、换档、换引擎重开时把所选倍速带给新引擎（引擎每次装载会把速率归 1，`AetherPlayback` 装载完再补设一次）。
- **供不上就降**：菜单选的加速吃光前向缓冲（不到 1 秒）时退回正常速度并记下，提示「缓冲跟不上，已回到正常速度」。
- 加速期间、以及降回后 8 秒内不判直通掉帧：引擎按音频节奏主动丢帧是预期内的，不能误判成「直通放不动」去降档转码。

## 入口

| 端 | 呈现 |
|---|---|
| iPhone | ⋯ 改成系统菜单（同发现页的筛选菜单）：「画质 ›」「倍速 ›」两个子菜单，标题下一行写当前值；下一节「播放诊断」开关；选中一档即收起。访客没有画质。音轨、字幕仍是自绘面板（字幕菜单要放步进器与开关，系统菜单放不下） |
| Mac | 底栏画质徽标换成 ⋯ 系统菜单，「画质 ▸」「倍速 ▸」悬停展开、当前项打勾；`[` `]` 逐档调速（同 Windows），到头不再变 |
| Apple TV | **不做倍速**（同 Netflix 电视端）：电视是靠在沙发上看，倍速用得少，入口放哪都显得太突出。试过面板第四栏（倍速不是选轨，别扭）、进度条上方系统式倍速键（太抢眼），2026-10-19 用户都否决。顺手留下两处面板改进：控制层顶部的下拉小箭头（写着面板有哪几栏），面板左右换栏落在已选中的那项 |
| 安卓手机 | 单独的画质图标和「1.0×」按钮收进 ⋮：从右侧滑出、占满高度的侧边面板（同 B 站等横屏侧边栏），结构同 iPhone 两级；二级左上「←」或返回键回一级 |

非正常速度时，时间旁常驻一个小角标「1.5×」，不另加按钮。

## 未覆盖

- 安卓手机竖屏也用右侧面板，没有改成底部弹出。
- Apple TV 不做倍速（见上）；需要时可以像 Infuse 那样只加「按住确认键临时 2 倍速」。
- Android TV、Web 仍只有长按 2 倍速，没有倍速菜单。
- Windows 档位（0.5～2，每次 ±0.25）没有对齐到这一组。
