# 播放画面缩放

iPhone/iPad 可在播放画面上双指放大切到「铺满裁切」、双指缩小恢复「完整显示」。iOS 与 Web 都可以在现有设置菜单中直接选择三种模式；顶栏不再增加常驻缩放按钮。锁屏或菜单打开时不响应捏合。

| 模式 | 行为 |
| --- | --- |
| 完整显示（默认） | 保持源画面比例，完整放入播放区域；可能留黑边 |
| 铺满裁切 | 保持比例，覆盖整个播放区域；可能裁去上下或左右 |
| 拉伸铺满 | 视频框填满播放区域；会改变人物与物体比例 |

「适应宽度」在不同宽高比下与完整显示或铺满裁切重合，因此不单独提供。这些选项只改变显示布局，不转码、不改原文件、不重开播放会话。

默认保持现有完整显示。选择只属于本次播放器：同一部剧自动连播、手动选集、换文件版本、旋转和重建引擎保留；切换到其他影片或重新进入播放器恢复默认。不保存全局偏好，不修改服务器或数据库。

## 内嵌黑边

1920×1080 的视频可能只有中央 1920×804 是有效画面，上下各有 138 像素黑边。完整显示仍按 16:9 视频框计算；在 1280×589 的播放区域里，有效画面约 1047×439，四周都有黑边。铺满裁切将视频框放到 1280×720，屏幕裁去的上下部分仍是黑边，有效画面约 1280×536，左右贴边且保留上下黑边。

这是用户选择的缩放，并非自动黑边检测；没有内嵌黑边的片源可能裁掉真实内容，设置菜单中说明这一点。

## 字幕、旋转与系统播放面

iOS 的 AVPlayer 通路保持原来的根 AVPlayerLayer 结构，只切换 videoGravity；无新增视频子图层、无手动改视频表面 frame。暂停旋转时，三个模式的字幕都用当前容器尺寸与片源显示比例计算，避免读到上一轮 AVPlayerLayer.videoRect。

普通文字字幕锚定画面可见部分；Apple 位图字幕缩放后保持自身比例并移回可见范围。画面定位的特效文字仍按视频坐标放置。Web ASS 使用默认 contain 画布，但施加与视频一致的居中缩放（裁切等比例，拉伸分别缩放横纵坐标），切模式、旋转、元数据尺寸更新时同步，不重建渲染器。JASSUB v2 的主 worker 由打包器生成，public 中的 Emscripten 子 worker 不能替代它。Web PGS 维持独立渲染器布局。

画中画、AirPlay 和浏览器原生全屏由系统独立布局；这里的选择针对应用内播放面。烧录字幕属于视频像素，会和画面一起缩放、裁切。

## 回归

- 内嵌上下黑边、无黑边 16:9、4:3、宽银幕；横屏、竖屏与平板宽高。
- 三模式设置菜单、顶栏无缩放按钮；切换不替换 video、地址或暂停位置。
- iOS 双指放大/缩小，单指拖进度、轻点、长按倍速与锁屏不受干扰。
- 同剧连播保留模式，换影片恢复默认；旋转保留模式、控制层和字幕仍在可见范围。
- ASS 带 pos 定位和矢量图形的字幕与画面参照物在三个模式下对齐；切回完整显示恢复位置。
