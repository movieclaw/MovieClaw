# 播放画面缩放

iPhone/iPad 与 Web 播放器在返回键旁提供缩放按钮，点击循环切换；设置菜单可直接选择。iPhone/iPad 也可长按缩放按钮选择。

| 模式 | 行为 |
| --- | --- |
| 完整显示（默认） | 保持源画面比例，完整放入播放区域；可能留黑边 |
| 适应宽度 | 保持比例，视频框左右贴边；可能裁去上下，宽银幕在窄屏上仍保留上下黑边 |
| 铺满裁切 | 保持比例，覆盖整个播放区域；可能裁去上下或左右 |
| 拉伸铺满 | 视频框填满播放区域；可能改变人物与物体比例 |

这些选项只改变显示布局，不转码、不改原文件、不重开播放会话。默认保持现有完整显示。选择只属于当前播放文件，换片/换集或重新进入播放器恢复默认；当前文件的横竖屏切换与播放引擎重建保留选择。无须保存服务器偏好或修改数据库。

## 内置黑边

1920×1080 的视频可能只有中央 1920×804 是有效画面，上下各有138像素黑边。完整显示仍按16:9视频框计算；在1280×589屏幕上，有效画面约1047×439，四周都有黑边。适应宽度将视频框放到1280×720，屏幕裁去的上下部分仍是黑边，有效画面约1280×536，左右贴边且保留上下黑边。

这是用户明确选择的缩放，并非自动黑边检测；在没有内置黑边的16:9片源上，同一选择可能裁掉真实内容，按钮和设置菜单都应说明。画面比例或分辨率未知时保守回到完整显示，元数据就绪后再应用当前选择。

## 字幕与系统播放面

控制层和字幕不随视频表面一起缩放。普通文字字幕锚定画面可见部分；Apple 原生引擎的位图字幕在缩放时保持自身比例，并移回可见范围。带画面定位的特效文字仍按视频坐标放置。Web ASS/PGS 保持原字幕渲染器布局，不把视频 CSS 缩放施加到字幕画布。

画中画、AirPlay 和浏览器原生全屏由系统独立布局；这里的选择针对应用内播放面。烧录在视频像素内的字幕会和视频一起缩放/裁切，无法独立保留。

## 回归

- 内置上下黑边、无黑边16:9、4:3和宽银幕；横屏、竖屏与平板宽高。
- 默认完整显示与旧布局一致；四模式循环返回默认，切换时视频实例/地址与进度不重置。
- 换片恢复默认，旋转保留选择；自研引擎与AVPlayer通路行为一致。
- 文字和位图字幕保持可见；切换回完整显示恢复原位置。
