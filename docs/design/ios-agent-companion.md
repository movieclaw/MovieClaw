# iPhone Agent 小幕（月夜伙伴 C）

2026-10-14：在新会话和已有会话的完整输入框右上方加入小幕，沿用月夜伙伴 C 的奶白猫、双色耳尖与播放键尾巴。宠物以独立透明 overlay 悬浮，不预留高度、不扩大输入区底色；快捷输入条保持原状。

## 实现

- `AgentMoonCompanion.imageset/moonlight.png`：内置透明 PNG，1024 × 1536，4 列 × 6 行，每格 256 × 256；实际显示 72pt。整张图只解码、共享一次（原始 RGBA 约 6 MiB）。
- 六行依次是待机、抬头、出发、工作、完成、失败；每行四帧。使用 `CALayer.contentsRect` 切换图集区域，相当于 Codex 的 `background-position`，不引入动画库或额外模型请求。
- 按首轮反馈将电影票道具替换为小鱼：出发叼鱼、工作时双爪抱鱼轻啃、完成举鱼。移除原先 58pt 顶部留白，宠物不再挤占消息空间；透明 UIView 不绘制背景，覆盖层宽度仅 90pt。
- 清理图集轮廓外的半透明雾状残留：保留 alpha ≥ 128 的原始角色像素及轮廓外 2px 抗锯齿，其他区域归零（包含透明像素的 RGB）。24 帧的颜色、位置与动作不变；图集测试验证每格四边完全透明，避免淡阴影再次混入。
- 真机反馈的大片黑晕仍出现在消息滚过宠物后方时：会话的 `scrollEdgeEffectStyle(.soft, for: .bottom)` 还会给底部消息叠加渐隐。改为 `scrollEdgeEffectHidden(true, for: .bottom)`，保留输入框自身的 `glassEffect`。端到端场景用长回复覆盖宠物后方，同时检查轮廓外气泡底色与正文清晰度，避免只在空白黑底验收。
- `AgentCompanion` 内部的可取消任务只更新这个小视图。开始处理时出发并啃鱼一轮（啃鱼 1.2 秒），随后静态抱鱼；每隔随机 15～25 秒仅眨眼 0.25 秒，不重复啃鱼。待机每隔随机 8～14 秒眨眼，其余时间静止。处理期间身体位置固定。
- 聚焦且有草稿时抬头一次并停住；轻点可打招呼。服务端完成后短暂庆祝并回到待机；错误 / 中断低头一次，随后保持静态担忧表情，重新输入时抬头；用户主动停止回到待机。动画不阻塞提交、停止、菜单或路由切换。重进已结束的历史会话不重复庆祝。
- 视图消失即取消动作；进入后台或开启系统「减少动态效果」只保留静态帧。回到前台不重播出发、啃鱼或错误动作。静态错误表情无需计时任务；长任务只在下一次眨眼时唤醒。
- 停止与成功仍以现有 Agent 事件为准；单次工具失败不会误判整个任务失败。原有错误提示和停止按钮保留。

## 素材制作

使用内置 imagegen，以已确认的 C 版概念图作为参考。初版提示词见 `docs/brand/companion/moonlight-generation.txt`，当前小鱼修订版见 `docs/brand/companion/moonlight-fish-generation.txt`。图集是手绘逐帧素材；继续调整形象时需保持网格、透明留白、脚底位置和行顺序。

## 验证

`AgentCompanionTests` 验证事件结果映射、打包图集的尺寸、每格有效像素和透明留白，以及六种宠物状态下输入区尺寸与无宠物时完全一致。已有 `AgentLogicTests` 覆盖事件归约。

`AgentCompanionUITests` 用真实 iPhone 界面、API、Agent、工具执行和 SSE；只有模型响应由本地确定性服务提供。测试环境使用独立临时数据库，不连接用户模型或片库。

从仓库根目录启动测试服务：

```sh
.venv/bin/python apps/apple/scripts/agent-companion-lab.py
```

在 `apps/apple` 下通过 `xcodebuild test` 运行 `MovieClawTests/AgentCompanionTests`、`MovieClawTests/AgentLogicTests` 和 `MovieClawUITests/AgentCompanionUITests`。为 UI 测试设置 `TEST_RUNNER_MC_TEST_COMPANION=1`；减少动态效果场景需先在独立测试模拟器开启系统选项，再设 `TEST_RUNNER_MC_TEST_REDUCED_MOTION=1`。可用 `TEST_RUNNER_MC_SHOT_DIR` 指定截图目录。

场景覆盖：空草稿、打字、轻点宠物、发送、工具执行、流式回答、完成、失败后继续提问、主动停止、键盘位置、加号菜单、减少动态效果与后台恢复。长任务测试检查啃鱼后保持静止、低频眨眼后再次静止、身体位置不变、回到前台不重新啃鱼；错误测试检查表情停止后稳定，以及重新输入时恢复倾听。人工检查截图中的裁切、透明边缘、落脚位置及按钮遮挡。
