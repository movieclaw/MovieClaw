# 跟用户解释：标准说法

用户多半不懂插件体系。下面是常见问题的一两句话答案，照这个口径讲，别展开实现细节，别用「契约」「注册表」这类词。

| 用户问 | 这样答 |
|---|---|
| 插件是什么？ | 给 MovieClaw 加一项它本来没有的能力，比如接一个新的聊天软件、删片时顺手删种子。装上就生效，不用重启，不要了可以随时卸载。 |
| `.mcplugin` 是什么文件？ | 插件包，本质是个压缩包，里面有一份说明（它是谁、要哪些权限）和代码。网页「设置 → 插件 → 第三方插件」里上传，或者让我来装。 |
| 为什么要我批准权限？ | 插件能做的事要你点头才给：它要调用哪些操作（删种子这类危险操作会单独标出来）、读写哪些目录、要不要联网。不批准就不安装。 |
| 装了会不会把系统搞坏？ | 插件默认在单独的低权限进程里运行，崩了只影响它自己；新版本起不来会自动退回上一版；反复把应用拖垮会进「安全模式」，不再加载第三方插件，等你处理。 |
| 现在是不是进了安全模式？怎么退出？ | 用 `mclaw app plugins list -o table` 看 `safe_mode` 一行（`active` 为真就是在安全模式里，`reason` 是原因）。修好或卸掉出问题的插件后，`mclaw app plugins safe-mode exit` 退出 |
| 卸载后数据还在吗？ | 插件自己存的数据默认保留，重装后还在；你明确说要清干净，才连数据一起删。它改过的系统数据（比如建过的订阅）不会被撤销。 |
| 装在哪、怎么看它在不在跑？ | 「设置 → 插件 → 第三方插件」里能看到版本和状态；有问题会进待处理事项。 |
| 能不能给我加个按钮 / 页面？ | 插件现在不能改界面。可以做成接口，我（AI 助手）能直接调用；结果会写进订阅动态或系统通知。 |
| 内置的微信 / Telegram 通道能换吗？ | 能。装一个同名的插件包就替换内置版本，已绑定的账号照常用；卸载后内置版本自动回来。 |
| 自动入库、AI 字幕这些是插件吗？ | 是 MovieClaw 本身的功能，不在插件页，开关和配置在各自的设置页。 |

## 给方案时讲清这几点

- **能做 / 做不到**：做不到的直说，并给替代办法（`extension-points.md` 第 5 节）。
- **要什么权限**：调用哪些操作（危险的标出）、读写哪些目录、是否联网。
- **用户要配合什么**：比如去平台后台建机器人、填 botId / secret、有没有公网地址的要求。
- **装完怎么验证、出了问题怎么回退**。
