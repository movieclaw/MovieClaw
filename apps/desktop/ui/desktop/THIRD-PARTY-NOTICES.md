# Desktop UI QR encoder

`qrcodegen.js` is Project Nayuki's official JavaScript build (compiled from TypeScript), downloaded on 2026-10-11 from https://www.nayuki.io/res/qr-code-generator-library/qrcodegen.js.

SHA-256: `2511bc17f40a3c41d4a0578995db956b38997334d3d20113a5d4dc5c49c69480`.

The file contains the complete MIT license. Library source and documentation: https://github.com/nayuki/QR-Code-generator and https://www.nayuki.io/page/qr-code-generator-library.

It runs locally to encode the public pairing verification URL. Authentication tokens and device codes remain in the native credential layer.
