# 服务器观看动态

MovieClaw Windows 客户端的可选服务端插件。兼容基线：MovieClaw **0.36.0**。在现有服务端主进程内运行，无独立程序、容器或新增依赖。

## 安装

1. 在服务器 Web 设置 → 插件中上传 `MovieClaw-Watch-Presence-1.0.0.mcplugin`。
2. 核对插件名，批准在主进程内运行。此模式与服务端具有相同系统权限。
3. Windows 客户端设置 → 好友与观看隐私，可开启“显示服务器好友列表”。从主界面侧栏或播放器左上角的“正在观看”查看。入口和共享默认关闭。
4. 各成员自行勾选允许共享的媒体库，再开启共享并保存。未勾选或新建的媒体库默认保密。

覆盖已安装的 1.0.0：服务端不接受同版本直接重复上传。先在插件管理中卸载旧插件，保留插件数据（不要勾选删除数据），再上传新版同名安装包并批准。保留的媒体库和共享设置会恢复；卸载期间好友接口暂不可用，普通播放继续可用。

旧版 Web、Mac、手机用户可先在同一服务器 Web 页面登录，再打开：

`/api/v1/plugins/watch-presence/settings`

这里提供当前账号的共享设置，无需安装其他软件。旧播放器必须已向 MovieClaw 上报播放进度，才会出现当前播放；观看列表在 Windows 客户端展示。

## 行为与隐私

- 查看入口与共享授权互不依赖；可查看已公开的好友，同时保持自己隐身。
- 同账号的设备无需开启公开共享即可由自己查看，其他账号仍需授权。各个当前播放会话分别显示，最近历史按账号和影片/单集合并，不把设备拆成新账号。
- 已授权成员停止播放后仍可查看最近观看；自己的账号有最近记录时也保留入口。离线不代表关闭共享，撤销授权后则立即隐藏。
- 白名单按账号保存，当前播放和最近历史使用相同范围。历史展示最近 7 天、最多 20 个不同播放单元。
- 向其他账号共享时，隐藏库、成人库、成人分级内容及观看者无权浏览的内容不返回；成员停用、权限变化及关闭共享立即影响后续查询。自己的设备与历史仅向本人返回可访问的内容。
- 桌面端关闭共享即提交，确认服务器保存成功后才显示“已关闭”。其他已打开的列表最迟在下一次刷新移除；跟随播放前重新验证权限。
- 当前状态超过 45 秒没有播放上报即不展示；列表展开时每 8 秒刷新，收起或离开播放器后停止刷新。
- 同一播放单元同时存在于共享库和未共享库时，因旧版上报/日志无法可靠识别实际文件，保守隐藏该单元。
- “跟上进度”只在进入时定位，不同步对方的暂停、快进，不控制对方设备；自己的观看进度独立保存。
- 使用服务端已有的播放记录，不复制保存公开历史。关闭共享后停止返回历史，但不删除服务端既有记录，也不改变管理员原有管理权限。
- 不向其他成员返回真实设备 ID、文件路径、播放凭据或下载活动。响应禁用缓存。

卸载插件后共享接口消失，普通播放继续可用。重新安装保留的授权会恢复；若需恢复默认隐私，请先关闭共享或卸载时清除插件数据。

## 开发验证

插件使用 0.36.0 的内部媒体投影与访问判定，在更高版本升级前需再次验证兼容性。

```powershell
# 在 MovieClaw v0.36.0 源码目录使用其 Python 测试环境
$env:WATCH_PRESENCE_SOURCE = '此插件源码目录'
# 将 tests/test_presence.py 复制到宿主 tests/api/ 后运行，复用宿主迁移测试配置
python -m pytest tests/api/test_watch_presence_plugin.py
```
